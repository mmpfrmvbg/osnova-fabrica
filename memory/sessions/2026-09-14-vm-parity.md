# Шаг 1 дорожной карты: полный паритет регистрового ядра

Доведены до паритета все недостающие конструкции; **каждая — по одной, с
parity-проверкой**. Критерий соблюдён: `npx tsx src/cli.ts parity <кейс>.osnova`
→ 0.

## Что реализовано (в порядке возрастания сложности)

1. **`пока`** (`emitWhile`) + **`прервать`/`продолжить`** (стеки
   `breakTargets`/`continueTargets`): условие перепроверяется, обратный `jmp`.
2. **`для_каждого`** (`emitForEach`): контракт стекового кодогена —
   `система.итератор.из` → `система.массив.длина` → индекс 0 → цикл
   `индекс < длина` с `система.массив.получить`; элемент, `индекс`, вложенность,
   `прервать`/`продолжить` внутри.
3. **Кортежи и распаковка**: `вернуть a, b` — тот же массив; `пусть x, y = вызов()`
   берёт элементы через `система.массив.получить` по индексу.
4. **Исключения**: `try_begin` несёт адрес обработчика **и регистр переменной
   `иначе_попытка`**; `throw` разворачивает кадры до глубины блока и кладёт
   значение прямо в этот регистр; `ret` снимает осиротевшие обработчики.
   Алиас `поймать` работает (см. прошлый ход).
5. **`цикл`** (бесконечный) — заодно, тем же механизмом, что `пока`.

## Ключевые инварианты (дорого добыты — не ломать)

1. **Глубину служебных ячеек `для_каждого` увеличивает только сам `для_каждого`**
   — ровно как в `buildLocals`. Сиблинги-циклы в разных ветках получают одну
   тройку `__forEach_src/len/i_N`, вложенные — разные. Ни `если`, ни `пока`,
   ни `попробовать` счётчик не трогают.
2. **Замер (`measuring`) не увеличивает глубину** и не эмитит инструкции: иначе
   вложенный цикл внутри чужого замера получал бы другой номер.
3. **Замер бывает вложенным** — флаг `measuring` сохраняется/восстанавливается
   (`previous`), а не сбрасывается в `false`: безусловный сброс выпускал код
   внутреннего пролога в поток внешнего цикла.
4. **Пролог `для_каждого` эмитится ПОСЛЕ замера тела**: пролог пишет в регистры,
   и если мерить тело после него, вложенный цикл успевает выпустить собственный
   пролог во время замера внешнего.
5. **Порядок обхода = порядок `buildLocals`**: условие раньше тела (`пока`),
   `источник` раньше тела (`для_каждого`), `объявить catch` раньше тела и
   обработчика (`попробовать`).

Симптом нарушения любого из них — `Неизвестная переменная: __forEach_src_N`
(номер выше, чем объявил `buildLocals`).

## Оракул: два найденных дефекта

- **Структурное равенство значений**: объекты — ссылки, у каждой VM свой объект.
  Было `Object.is` → ложное расхождение на `task_stats.osnova` (одинаковый JSON).
  Теперь `sameValue` = `Object.is` + структурное сравнение для объектов.
- Замер/генерация циклов (см. инварианты) — ловилось только оракулом, юнит-тесты
  такое не видят.
