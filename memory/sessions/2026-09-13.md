# 2026-09-13 — loop unrolling для VLIW + статические типы (возврат)

## Часть 1 — loop unrolling (src/vliw)

1. **`src/vliw/unroll.ts`** — `unrollForEach`: разворачивает `для_каждого` с известным
   числом итераций в линейный код (убирает `jmp`/`jmp_if_not`). Авто-детект trip count
   по литералу массива в источнике, либо явный `tripCount`.
2. **`runUnrollOracle`** — unroll → пакеты → сверка linear vs scheduled.
3. **Планировщик переведён на in-order упаковку** (прежний list scheduling переставлял
   push/pop и ломал стек-порядок).
4. **`dependencyGraph`** — добавлены `pop`/`dup`, реальный `invokeArgc`/`callArgc`.
5. Обрезка мёртвого кода после первого `ret` в unroll.

## Часть 2 — статические типы: аннотация и вывод типа возврата

Владелец выбрал «строже ловить ошибки» (не «типы в байткод»).

1. **`процедура f(x: Число): Число`** — аннотация типа возврата (`ast.ts` + `parser.ts`).
2. **Вывод типа возврата** из `вернуть` (если все возвраты одного типа) — `compiler.ts`.
3. **Тип вызова** — `inferExprType(вызов)` возвращает тип возврата вызываемой процедуры.
4. **Проверка `вернуть`** против аннотированного/выведенного типа (несовпадение → ошибка).
5. `вернуть` без значения = ранний выход (возврат пусто), не ошибка — совместимо с gradual.
6. `returnType` прокинут через `expandModuleImports` и `compileProgram` (не теряется при импорте).
