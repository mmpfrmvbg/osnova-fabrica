# Coding with Osnova v2

Практический стартовый гид для разработчика и ИИ-агента.  
Полная спецификация не дублируется: канон языка находится в `language-v2.md` и `osnova/language-schema.json`.

## Откуда брать знания о языке

- `docs/language-v2.md` — человекочитаемый канон v2.0.0: синтаксис, ограничения, статусы конструкций.
- `docs/osnova/language-schema.json` — machine-readable канон для инструментов и LLM (конструкции, ключевые слова, операторы, типы, syscalls, статусы).
- `docs/pipeline-v1.md` — актуальный pipeline codegen/repair.
- `docs/traces-v1.md` — актуальный формат трейсов и аналитика.

`docs/legacy/**` — архивные документы. Не использовать как источник истины для проектирования нового кода или настройки промптов.

## Минимальный маршрут для старта

1. Прочитать `docs/language-v2.md` (разделы про конструкции, типы и статусы фич).
2. Открыть `docs/osnova/language-schema.json` и использовать только записи со статусом `stable` (или осознанно `experimental`).
3. Посмотреть живые примеры `.osnova`:
   - `src/runtime/fixtures/`
   - `apps/osnova-todo/`
   - `apps/task-manager/`
4. Для LLM-автоматизации: валидировать генерацию по schema (ключевые слова, syscalls, конструкции) до компиляции.

## Micromodules v2.0

Для практики через реальные задачи используйте референсные микромодули v2.0.  
Они покрывают типичный срез языка (типы, поток управления, коллекции, syscalls) и подходят как маршрут постепенного освоения.

Подробные описания: `docs/micromodules-v2.md`.

## Минимальные примеры

### 1) Модуль, процедура, условие, возврат

```osnova
модуль Пример

процедура главная()
  пусть x = 10
  если x > 5
    вернуть "ok"
  иначе
    вернуть "bad"
  конец
конец
```

Что проверить в каноне:
- в `language-v2.md`: `если/иначе`, `пусть`, `вернуть`;
- в `osnova/language-schema.json`: `constructions` (`if`, `let`, `return`) и `operators` (`>`).

### 2) Цикл для_каждого и индекс

```osnova
модуль ПримерЦикла

процедура главная()
  пусть числа = [10, 20, 30]
  для_каждого значение, индекс в числа
    система.лог.вывести(индекс)
    система.лог.вывести(значение)
  конец
  вернуть пусто
конец
```

Что проверить в каноне:
- в `language-v2.md`: формы `для_каждого`;
- в schema: `for_each`, `for_each_indexed`, syscall `система.лог.вывести`.

### 3) Обработка ошибок

```osnova
модуль ПримерОшибок

процедура главная()
  попробовать
    выбросить "ошибка"
  иначе_попытка е
    система.лог.вывести(е)
  конец
конец
```

Что проверить в каноне:
- в `language-v2.md`: `попробовать/иначе_попытка/выбросить`;
- в schema: `try_catch`, `throw_stmt`.

## Что не использовать

- Не используйте `docs/legacy/**` для проектирования нового кода и настройки LLM.
- Не используйте legacy-пути (например, старый `docs/language-schema.json`) как актуальные.
- Для нового кода всегда сверяйтесь с `docs/language-v2.md` + `docs/osnova/language-schema.json`.
