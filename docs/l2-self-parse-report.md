**Аргумент-выражение во вызове** (Списки.установить(лента, инд + 1 + место, …)), текст разборщика,
строка 11, колонка 36; пропущенный блок — 112 клеток на строку, всего 124 строки / 167 аргументов.

Что уже сделано и зелено (коммит 6a44894f): шаг_закрыть отказывает, если на стеке нет маркера
группы (, а ветвь ) в выразить отказ уважает — то есть машина выражений умеет останавливаться на
) вызова, не потребляя токен. Оракул 73/73 за 2.17 с, проба ф(1 + 2) впервые совпала с эталоном.

Что снято (измерено): вызов выразить из шаг_вызов по признаку «следующий токен — оператор».
Красные ровно **4 формы**, и все — ЗАЦИКЛИВАНИЕ (Max steps exceeded), а не неверная лента:
пусть а = ф(1) + 2, пусть а = 1 + ф(2) * 3, если ф(1) > 0, пусть а = ф(1) + ф(2). Одиночный
ф(1) проходит. Значит нужен признак «мы уже в аргументах вызова» (клетка состояния или отдельная
машина выражений со своим стеком) — объём работы с P2b.
