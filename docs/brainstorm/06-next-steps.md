# Что нужно для loop mode и `spec`: карта (без реализации)

**Сеанс:** 2026-09-19. **Только карта.** Ни одной строки кода в `src/e2k/*` не менялось.
**Опирается на:** `docs/e2k-loop-mode.md` (loop mode), `docs/e2k-spec-bit.md` (`spec`),
`docs/brainstorm/05-step1-measurement.md` (замер шага 1).

## 1. Loop mode: что нужно в коде

| шаг | файл | что именно | почему здесь |
|---|---|---|---|
| 1 | `src/e2k/widePacker.ts` | писать бит `lm` в заголовок при сборке команды | `lm` — бит HS (10), а HS собирает `encodeWideGroup` (`src/e2k/widePacker.ts:131-134`); сейчас там `mdl`/`lng`/`al`/`ale`, бита `lm` нет |
| 2 | `src/e2k/backend.ts` | поле формы команды: «эта команда — тело цикла» | признак относится к **команде**, а не к операции в слоте (см. `docs/e2k-loop-mode.md` §1) |
| 3 | `src/e2k/twoPassLayout.ts` | не менять размер: бит `lm` длины не меняет | `lng` считается по словам (`widePacker.ts:133`), бит 10 в него не входит — проверяемо оракулом |
| 4 | новый проход | найти цикл и пометить его тело | понятия «цикл» в анализах нет: живость линейна (`src/e2k/liveness.ts:39-40`), области — линейные участки |
| 5 | новый проход | собрать `ALC alcf/alct` и определение `LSR` | без предыдущего определения `LSR` режим не даёт счётчиков (`docs/e2k-loop-mode.md` §3) |

**Точка вставки, которой нет:** шаг 4. Всё остальное — расширение существующих мест.

## 3. Какой замер покажет эффект

| что мерить | чем | чего этот замер НЕ даёт |
|---|---|---|
| число команд цикла и слогов в его широких командах | `wideStats` (`src/e2k/widePacker.ts:252`) + новый счётчик пустых слогов | не даёт тактов |
| число тактов модели оболочки для цикла | симулятор оболочки, `TICKS`/`BUB_E2` | это **модель**, не железо (`docs/hardware-debt.md:9`) |
| исполнение | QEMU-e2k: счётчик инструкций и переходов | QEMU считает **инструкции**, а не время (`docs/hardware-debt.md:179`) |
| «стало быстрее» | **нечем** | настоящих тактов нет: железо нужно (`docs/hardware-debt.md:325`) |

**Порядок обязателен:** сначала байты и структура (проверяемо сейчас), затем исполнение в модели
(проверяемо сейчас), затем — и только затем — такты (нечем).

## 4. Риски

| риск | в чём | чем снижается |
|---|---|---|
| **loop mode без перестановки бессмысленен** | замер шага 1: упаковка сама по себе даёт 1.7 % (136 байт на 8152) | сначала снять литеральные барьеры и дать перестановку |
| **`spec` меняет безопасность программы** | отложенное прерывание: неспекулятивная операция, прочитавшая помеченный операнд, **вырабатывает прерывание** (`docs/e2k-spec-bit.md` §2) | оракул на значения через регистровую VM (`runLoweredValues`, `src/e2k/e2kRealRun.ts:966`) |
| **правило «какие операции спекулировать» не найдено** | ограничений в руководстве нет | начать с одного класса (чтение памяти) и мерить |
| **`lm` может потребовать `ALC`/`LSR`** | без определения `LSR` счётчиков нет | либо генерировать `ALC`, либо проверять, что режим не нужен |
| **выдумать семантику** | соблазн «достроить» счётчики по смыслу | запрет: `docs/verification-debt.md:73-84` («ВЫДУМАННЫЕ ИМЕНА») |

## 5. Чего в этой карте нет

- Оценок ускорения: ни одного числа тактов (единственная ГИПОТЕЗА — в §8 `docs/e2k-loop-mode.md`).
- Реализации: шаги 3–4 **не начаты**, как и было велено.
- Работы по спекулятивности **по данным**: это пара операций, а не бит (`docs/e2k-spec-bit.md` §3).

**НЕ ИЗВЛЕЧЕНО** (осталось долгом, чтобы не выглядело забытым): семантика счётчиков `LSR`
(`vlc`/`pcnt`/`ecnt`) при исполнении; полная таблица MOVA ↔ авто-инкремент адресов; правило «какие
операции допустимо поднимать в спекулятивном режиме». Перечень — в `docs/e2k-loop-mode.md` §7 и
`docs/e2k-spec-bit.md` §6. **НЕТ В ИСТОЧНИКЕ** ни одной величины «сколько тактов экономит loop
mode»: руководство МЦСТ описывает механизм, но числа не даёт.
