# Системное API Основа v1

Формальная спецификация системных вызовов `система.*`.
Единый источник истины по именам и арности — [invokeRegistry.ts](../src/runtime/vm/invokeRegistry.ts)
(`INVOKE_ARG_COUNT`). Реализация обработчиков — [vm-runner.ts](../src/runtime/vm-runner.ts) и
[interpreter.ts](../src/runtime/vm/interpreter.ts).

> Список ниже сверен с `INVOKE_ARG_COUNT` вручную. При расхождении верь коду.

---

## 1. Соглашение вызова

Порядок аргументов на стеке: `push arg0; push arg1; ...; invoke "имя"`.
Интерпретатор снимает `argc` значений (по реестру) и кладёт **ровно одно** значение:
результат обработчика или `null`, если обработчик ничего не вернул.

Неизвестный invoke → `InterpreterError("Unknown invoke")`.

## 3. Как добавить новый invoke

1. Добавить запись в `INVOKE_ARG_COUNT` в [invokeRegistry.ts](../src/runtime/vm/invokeRegistry.ts) — имя и argc.
2. Реализовать обработчик в [vm-runner.ts](../src/runtime/vm-runner.ts).
3. Обновить этот документ.
