# Системное API Основа v1

Формальная спецификация системных вызовов `система.*`. Источник: [invokeRegistry.ts](../src/runtime/vm/invokeRegistry.ts). Реализация: [vm-runner.ts](../src/runtime/vm-runner.ts).

---

## 1. Стабильные вызовы v1

Минимальный набор invoke, считающийся стабильным и сохраняющимся между версиями.

| Имя | Арность | Аргументы | Возвращает | Описание |
|-----|---------|-----------|------------|----------|
| `система.лог.вывести` | 1 | значение: любой | null | Вывод в лог |
| `система.хранилище.записать` | 2 | ключ: Строка, значение: Строка | null | Запись в хранилище |
| `система.хранилище.прочитать` | 1 | ключ: Строка | Строка или null | Чтение из хранилища |
| `система.хранилище.удалить` | 1 | ключ: Строка | null | Удаление ключа |
| `система.хранилище.ключи` | 0 | — | массив | Список ключей |
| `система.массив.создать` | 0 | — | массив | Создать пустой массив |
| `система.массив.длина` | 1 | массив | Целое32 | Длина массива |
| `система.массив.получить` | 2 | массив, индекс: Целое32 | любой | Элемент по индексу |
| `система.массив.добавить` | 2 | массив, значение | null | Добавить элемент в конец |
| `система.массив.установить` | 3 | массив, индекс: Целое32, значение | null | Установить элемент по индексу |
| `система.массив.удалить` | 2 | массив, индекс: Целое32 | null | Удалить элемент по индексу |
| `система.массив.срез` | 3 | массив, from: Целое32, to: Целое32 | массив | Срез массива [from, to) |
| `система.объект.получить` | 2 | объект, ключ: Строка | любой | Поле объекта |
| `система.строка.объединить` | 2 | строка1, строка2 | Строка | Конкатенация |
| `система.время.сейчас` | 0 | — | Целое32 (мс) | Текущее время (Date.now()) |
| `система.время.спать` | 1 | мс: Целое32 | null | Пауза |

## 2. Экспериментальные вызовы

Вызовы, связанные с `система.окно.*`, `система.интерфейс.*`, `система.сеть.*`, `система.файлы.*`. Могут быть переработаны или удалены в следующих версиях.

| Имя | Арность | Аргументы | Возвращает | Описание |
|-----|---------|-----------|------------|----------|
| `система.файлы.прочитать_все` [experimental] | 1 | путь: Строка | Строка | Прочитать файл полностью |
| `система.файлы.записать_все` [experimental] | 2 | путь: Строка, данные: Строка | null | Записать в файл |
| `система.файлы.существует` [experimental] | 1 | путь: Строка | Логический | Проверка существования |
| `система.сеть.запрос` [experimental] | 4 | url, метод, заголовки, тело | Строка | HTTP-запрос (требует permissions.network) |
| `система.окно.создать_окно` [experimental] | 3 | заголовок, ширина, высота | Целое32 | Создать окно |
| `система.окно.показать` [experimental] | 1 | id | null | Показать окно |
| `система.окно.скрыть` [experimental] | 1 | id | null | Скрыть окно |
| `система.окно.закрыть` [experimental] | 1 | id | null | Закрыть окно |
| `система.окно.установить_заголовок` [experimental] | 2 | id, заголовок | null | Сменить заголовок |
| `система.окно.получить_события` [experimental] | 0 | — | массив | Очередь событий |
| `система.интерфейс.контейнер` [experimental] | 3 | windowId, parentId, id? | виджетId | Контейнер |
| `система.интерфейс.кнопка` [experimental] | 3 | parentId, текст, id? | виджетId | Кнопка |
| `система.интерфейс.поле_ввода` [experimental] | 3 | parentId, placeholder, id? | виджетId | Поле ввода |
| `система.интерфейс.текст` [experimental] | 3 | parentId, текст, id? | виджетId | Статический текст |
| `система.интерфейс.область_текста` [experimental] | 3 | parentId, строки, id? | виджетId | Многострочная область |
| `система.интерфейс.получить_значение` [experimental] | 1 | виджетId | Строка | Значение виджета |
| `система.интерфейс.установить_значение` [experimental] | 2 | виджетId, значение | null | Записать значение |
| `система.интерфейс.диалог_сообщение` [experimental] | 2 | заголовок, текст | null | Заглушка: логирование |
| `система.интерфейс.диалог_подтвердить` [experimental] | 2 | заголовок, текст | Логический | Заглушка: false |
| `система.интерфейс.диалог_ввод` [experimental] | 3 | заголовок, подсказка, default? | Строка | Заглушка: "" |

## 3. Поведение при ошибках

- **система.хранилище.прочитать:** если ключ не найден — возвращает null
- **система.массив.получить:** если индекс вне границ — поведение не определено (v1)
- **система.объект.получить:** если поля нет — возвращает null

---

## 4. Добавление нового invoke

1. Добавить запись в [invokeRegistry.ts](../src/runtime/vm/invokeRegistry.ts) — имя и argc
2. Реализовать case в `createInvokeHandler` в [vm-runner.ts](../src/runtime/vm-runner.ts)
3. Обновить этот документ

---

## 5. Согласование со стеком

Порядок аргументов на стеке: `push arg0; push arg1; ...; invoke "name"`. Интерпретатор использует [invokeRegistry.ts](../src/runtime/vm/invokeRegistry.ts) для снятия argc значений.
