## 8. Подсистема: Сеть

### 8.1. Стабильные вызовы (v1.7)

| Имя | Арность | Аргументы | Возвращает | Описание |
|-----|---------|-----------|------------|----------|
| `система.сеть.получить` | 1 | url: Строка | Строка | HTTP GET, возвращает тело ответа |
| `система.сеть.пост` | 2 | url: Строка, тело: Строка | Строка | HTTP POST с телом, возвращает тело ответа |

Поведение при ошибках: при сетевой ошибке, таймауте (30 сек) или
HTTP-статусе 4xx/5xx — выбрасывает исключение. Оборачивать в
попробовать / иначе_попытка.

Требования: permission network.outbound: true в манифесте osapp.yaml.

Content-Type для пост: text/plain; charset=utf-8.
Для JSON использовать система.json.создать перед вызовом.

### 8.2. Низкоуровневый вызов [experimental]

Сигнатура:
система.сеть.запрос(метод, url, заголовки, тело) → строка

Параметры:

метод: строка — "GET", "POST", "PUT", "DELETE"

url: строка — полный URL включая протокол

заголовки: объект или null

тело: строка или null

Результат: строка (тело ответа) или null при ошибке

Ограничения v1:

таймаут: 30 секунд

только HTTP/HTTPS

требует permission network.outbound в манифесте
