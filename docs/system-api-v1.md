# Системное API Основа v1

Формальная спецификация системных вызовов `система.*`. Источник: [invokeRegistry.ts](src/runtime/vm/invokeRegistry.ts). Реализация: [vm-runner.ts](src/runtime/vm-runner.ts).

---

## 1. Стабильные вызовы v1

Минимальный набор invoke, который считается стабильным и сохраняется между версиями.

### 1.1. Лог

| Invoke | argc | args[0] | args[1] | Возврат | Описание |
|--------|------|---------|---------|---------|----------|
| `система.лог.вывести` | 1 | строка | — | — | Вывод в консоль |

### 1.2. Файлы

| Invoke | argc | args[0] | args[1] | Возврат | Описание |
|--------|------|---------|---------|---------|----------|
| `система.файлы.прочитать_все` | 1 | путь (строка) | — | строка | Прочитать файл полностью |
| `система.файлы.записать_все` | 2 | путь | данные (строка) | — | Записать в файл |
| `система.файлы.существует` | 1 | путь | — | логический | Проверка существования |

Доступ ограничен sandbox (permissions).

| Invoke | argc | args[0] | args[1] | Возврат | Описание |

## 2. Экспериментальные / дополнительные

Могут быть переработаны или удалены в следующих версиях:

- **Диалоги** (`диалог_сообщение`, `диалог_подтвердить`, `диалог_ввод`) — сейчас только заглушки в Node
- **Окно/интерфейс** — реализация через WebSocket; может смениться на WebView/Tauri

---

## 3. Добавление нового invoke

1. Добавить запись в [invokeRegistry.ts](src/runtime/vm/invokeRegistry.ts) — имя и argc
2. Реализовать case в `createInvokeHandler` в [vm-runner.ts](src/runtime/vm-runner.ts)
3. Обновить этот документ

---

## 4. Согласование со стеком

Порядок аргументов на стеке: `push arg0; push arg1; ...; invoke "name"`. Интерпретатор использует [invokeRegistry](src/runtime/vm/invokeRegistry.ts) для снятия argc значений. См. [stack-convention-v0.1.md](stack-convention-v0.1.md).
