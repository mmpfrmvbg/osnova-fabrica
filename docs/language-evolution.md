## Общие принципы

1. Семантическая обратная совместимость — старый код остаётся рабочим.
2. Добавление, а не передел — новые конструкции не отменяют существующие.
3. Приоритет LLM-читаемости — изменения понятны и воспроизводимы моделями.
4. Маленькие шаги — версии 1.x с короткими циклами.

## Цикл релиза версии

Каждая версия проходит обязательный цикл:

```
реализовать фичу
       ↓
добавить в промпты и реестр
       ↓
прогнать 50+ целевых задач (сценарии с новой конструкцией)
       ↓
накопить трейсы в датасете
       ↓
файн-тюн / валидация golden-тестов
       ↓
следующая версия
```

### Гейт для перехода к следующей версии

Версия считается готовой только при выполнении всех условий:
- фича реализована и задокументирована
- промпты и реестр обновлены
- накоплено 50+ успешных трейсов с новой конструкцией
- golden-тесты покрывают новые сценарии

### v1.5 — Модульность: использовать/экспорт

**Статус: выпущена — стабильная**
**Дата:** 2026-03-19

Фокус: разбиение больших программ на файлы и публикация API модуля.

| Фича | Мотивация |
|------|-----------|
| использовать модуль Имя из "путь" | Подключение других модулей |
| процедура экспорт имя(...) | Выделение публичного API модуля |

#### Контракт модульности v1.5

- **Модуль = файл**: один файл .osnova — один модуль, всегда.
- **Импорт только между файлами**: использовать всегда ссылается на другой файл.
- **Никаких вложенных модулей**: логические единицы внутри файла не вводятся.
- **Один namespace на модуль**: имена процедур не конфликтуют между файлами.

Минимум датасета был: 50+ задач на многомодульные приложения.

## Что не спешить делать

- **VLIW-конструкции** — до появления реального VLIW-бэкенда.
- **Полноценные generics** — начать с конкретных типов структур.
- **Async/await** — пока достаточно синхронной модели.
- **Макросы** — сначала развить базовую выразительность.

## Согласование с платформой

- **v1.1–v1.2**: без изменений OsVbcModule, только новые опкоды при необходимости.
- **v1.3**: при мультимодульности — либо один объединённый модуль,
  либо расширение формата с механизмом загрузки.
- **v1.4+**: метаданные типов в байткоде; без влияния на VM,
  если не потребуется JIT/AOT.
