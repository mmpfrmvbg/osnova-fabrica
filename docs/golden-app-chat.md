# Golden-приложение: Чат-клиент (Chat)

> **Поправка 2026-09-25.** Это описание относится к манифесту `src/runtime/fixtures/chat.osapp.yaml`, и в нём исправлено `entry.module`: было `чат`, стало `chat`. Причина измерена (`.tmp/chat-entry.ts`): `entry.module` — это **имя файла** в каталоге пакета, а не имя модуля внутри байткода: `loadModule` читает `<имя>.osvbc.json` (`src/runtime/vm/interpreter.ts#loadModule`). При значении `чат` рантайм грузил осиротевший `apps/chat/чат.osvbc.json` (3505 б, старее исходника), а свежий и сторожимый `apps/chat/chat.osvbc.json` (3750 б, совпадает со свежей сборкой) не грузился никем. Пример кода ниже оставлен как есть: он описывает другой иллюстративный модуль (`osnova.chat_client`), а не приложение `apps/chat`; канон «файл = модуль» (§13.3 `docs/language-v2.md`) применится к нему, когда его текст перепишут в канонической форме. Метка ⚠ у этого документа в `docs/README.md` снялась **из-за самой этой поправки** (док стал новее исходника), а не потому, что документ сверен заново.

Приложение категории **network** — минимальный клиент для отправки
сообщений на сервер. Golden-пример проверяет системные вызовы
`система.сеть.пост` и `система.json.создать`.

## Идентификация

- **id:** `osnova.chat_client`
- **Категория:** `network`
- **since:** `1.7.0`

## Код модуля

```osnova
модуль Чат

процедура главная()
  пусть сервер = "https://example.com/chat"
  пусть тело = система.json.создать("привет")
  пусть ответ = система.сеть.пост(сервер, тело)
  система.лог.вывести(ответ)
конец

конец
```

## Конструкции языка, которые проверяет

- **`пусть`** — объявление переменных
- **`система.json.создать`** — сериализация аргумента в JSON-строку
  (argc: 1, stable v1.7)
- **`система.сеть.пост`** — HTTP POST-запрос
  (argc: 2, stable v1.7)
- **`система.лог.вывести`** — вывод в лог

## Проверки golden-теста

| Проверка | Ожидаемый результат |
|----------|---------------------|
| Компиляция | Успешно, нет ошибок |
| Байткод содержит | `invoke "система.сеть.пост"` |
| Байткод содержит | `invoke "система.json.создать"` |
| Структура | Модуль Чат, одна процедура главная |

## Зависимости API

- `система.json`: создать (stable, v1.7)
- `система.сеть`: пост (stable, v1.7)
- `система.лог`: вывести (stable, v0.1)
- **Permissions в манифесте:** `network.outbound: true`

## Связь с Android-чатом (задача Инженера А)

Этот тест — минимальный контракт для реализации `система.сеть.пост`
и `система.json.создать` в VM. Инженер А реализует оба invoke в
`vm-runner.ts` так, чтобы данный тест компилировался и выполнялся.
