> Это не план действий и не техспека.

---

## Суть в одной фразе

**Forge — фабрика, которая строит саму себя.**

Днём зарабатывает деньги, пиша код клиентам на любом языке.
Параллельно строит собственную платформу на языке Основа.
Платформа привлекает пользователей.
Пользователи генерируют данные.
Данные обучают модель.
Модель улучшает Forge.
Forge строит платформу лучше.
Цикл ускоряется.

Это не пять отдельных стартапов. Это одна система, где каждый элемент существует потому, что усиливает все остальные.

## Слой 1 — ОСИРИС Creator Edition

Android-приложение создателя. Не «удобный помощник» — **нервная система всей экосистемы, вынесенная в карман**.

Создатель — единственный человек, который видит систему целиком: язык, VM, forge, клиентов, модели, GPU, данные, деньги. ОСИРИС отражает эту полноту.

### Контроль в реальном времени
- Все forge-сессии: статус, прогресс, какая модель, сколько токенов, ожидаемое время
- GPU: загрузка каждой карты, температура, training vs inference, текущий checkpoint, эпоха
- Очередь задач: что ждёт, что в работе, что зафейлило и почему
- Финансы: выручка за день/неделю/месяц, каждая задача = деньги в реальном времени
- Трейсы: сколько накоплено, качество последней эпохи, pass rate по языкам

### Память создателя
- Вся история проекта в векторном хранилище — не логи, а **смысл**
- Каждое архитектурное решение, каждый компромисс, каждая причина сохранены
- «Почему мы не сделали IR-слой в феврале?» → мгновенный ответ с контекстом
- Бесконечная. Не сбрасывается никогда.

### Управление голосом и текстом
- «Запусти новый EPIC: добавь JWT для клиента Иванов» → forge начинает работу
- «Покажи последние 5 фейлов» → аналитика прямо в чат
- «Сколько трейсов за неделю?» → число + тренд + прогноз до 10K
- «Что сейчас самое узкое место?» → ОСИРИС анализирует и отвечает

### Таск-менеджер создателя
Не Todoist. Не Notion. Задачи создателя — это EPICи, архитектурные развилки, стратегические решения. ОСИРИС понимает разницу между «купить хлеб» и «решить: делать IR-слой сейчас или после первого клиента». Второе — помогает думать, предлагает контекст, предупреждает о последствиях для системы.

### Терминал
Полноценный SSH в сервер прямо из приложения. Не упрощённый. Настоящий.

### Алерты уровня ЦУП
- Forge зафейлил задачу клиента → немедленно + контекст
- GPU температура > 85° → алерт
- Клиент открыл/закрыл PR без merge → уведомление + причина
- Training завершил эпоху → метрики в чат
- Новый платящий клиент → уведомление

## Слой 6a — ОСИРИС-клиент (B2C)

Не таск-менеджер и не чат-бот. **Персональная AI-платформа** — Telegram + Notion + AI-помощник в одном, суверенный, на твоём железе.

```
L1 — AI-органайзер
     Слушает диалог → извлекает задачи →
     декомпозирует подзадачи → рекомендует →
     пуш-уведомления в нужный момент

L2 — Мессенджер (E2E шифрование, как Telegram)
     человек ↔ человек
     ОСИРИС → контакт (от имени пользователя, с разрешения)
     бизнес-уведомления: парикмахер → клиенты прямо в чат
     "Напоминаю: вы записаны на завтра в 14:00"

L3 — AI Chief of Staff (72B, долгосрочная память)
     помнит всю историю всех контактов
     связывает контексты: "Петров ещё не оплатил счёт"
     предлагает подготовку к встречам
     подсказывает решения, не просто фиксирует

L4 — Единый аккаунт экосистемы
     один вход → Store + Agent + мессенджер + память
```

**Сетевой эффект:** когда у человека там все контакты, все задачи, вся история переписки — он не уйдёт. Переезд = потеря памяти и связей. Это то, что делает WhatsApp непобедимым. У тебя — сеть контактов + AI-память + суверенность данных.

**Почему лучше Motion/Reclaim/Todoist:**

| | Motion | Reclaim | ОСИРИС-клиент |
|---|---|---|---|
| Интерфейс | Dashboard (забрасывают) | Dashboard | Живой диалог в Telegram |
| Память | ❌ | ❌ | ✅ бесконечная |
| Мессенджер | ❌ | ❌ | ✅ E2E |
| Русский язык | ❌ | ❌ | ✅ нативно |
| Данные | США | США | ✅ локально |
| Цена | ~₽3,200/мес | ~₽1,500/мес | ₽490–990/мес |

## Слой 6b — OSNOVA Agent (B2B, Devin-like)

Автономный агент-разработчик на собственном железе.

### Что видит разработчик
```
Разработчик: "Добавь JWT-аутентификацию в API /users"
      │
      │ ← 3 секунды
      ▼
Агент: "Вижу routes/users.py и middleware/auth.py.
        Добавлю JWT verify в middleware + защищу /users/*.
        Оценка: ~8 минут. Начинаю?"
      │
      │ ← "да" или auto-approve
      ▼
[невидимо: Atomizer → Router → Smith → Reviewer → Courier]
      │
      │ ← 8 минут
      ▼
```

Клиент не видит EPIC, ATM, DAG, forge. Он видит **чат и PR**.

| Суверенность | ❌ | ❌ | ✅ всё локально |

**Экономика:**
Компания 30 человек × 5 задач/день × ₽300 = **₽45K/день = ~₽1M/мес**.

## Data Foundry — слой 2.5

### Universal Execution Sandbox

Единый интерфейс для исполнения и инструментирования любого языка:

```
SandboxSession {
  lang:         "python" | "typescript" | "rust" | "go" | "osnova" | ...
  task:         string
  steps:        AgentStep[]      // полный trajectory: думает, пишет, тестирует
  code_written: Diff
  tests_run:    TestResult[]
  outcome:      "pass" | "fail" | "partial"
  tokens_used:  number
  latency_ms:   number
  pr_url?:      string
}
```

Каждая сессия — не просто `(задача → код)`, а **полный trajectory агента**. Ни у Devin, ни у Cursor нет доступа к своим production-трейсам — у них нет этих данных.

### Типы обучающих данных

| Событие | Тип | Ценность |
|---|---|---|
| Клиент merged PR | Gold SFT | ⭐⭐⭐⭐⭐ |
| Human edit после merge | DPO: «вот как надо было» | ⭐⭐⭐⭐⭐ |
| FAIL → retry → PASS | DPO пара (chosen/rejected) | ⭐⭐⭐⭐ |
| Reviewer PASS | SFT positive | ⭐⭐⭐ |
| Closed PR без merge | DPO negative | ⭐⭐ |

**Human edit — самый ценный сигнал в мире.** Разработчик взял код из PR и поправил — это прямой ответ «что модель сделала не так». Ни у кого этого нет.

### Per-Language Model Pipeline

```
traces.jsonl (lang-tagged)
        ↓
   ┌────┴──────────────────────────────┐
Python/TS/Go/Rust             Основа
LoRA adapters                 Full fine-tune
(база: Qwen3-Coder-72B)       (данных нет нигде, кроме нас)
        ↓                            ↓
Evaluation: pass@1, pass@5    Монополия по определению
        ↓
Лучший adapter → в продакшн как провайдер для этого языка
```

### Скорость накопления данных

| Масштаб | Задач/день | Пар/день | За 6 месяцев |
|---|---|---|---|
| 1 компания (10 devs) | ~40 | ~600 | ~108K |
| 5 компаний | ~200 | ~3,000 | ~540K |
| 20 компаний | ~800 | ~12,000 | ~2.16M |

Через 6 месяцев с 20 клиентами — 2 миллиона обучающих пар в контексте русскоязычных команд, российских кодовых баз, реальных бизнес-задач. **Такой модели не существует нигде в мире.**

## GPU Scheduler

GPU никогда не простаивают.

```python
if queue_depth > 0:
    pause_training(save_checkpoint=True)  # 2 секунды
    run_inference()                        # клиент не ждёт лишнего

elif queue_depth == 0 and new_pairs > 100:
    resume_training_from_checkpoint()     # продолжает с того же места

# Unsloth QLoRA: checkpoint/resume — ключевой инструмент
```

### Паттерн нагрузки

| Время | Нагрузка | GPU делают |
|---|---|---|
| 00:00–09:00 | ~0 задач | 🧠 9 часов чистого training |
| 09:00–11:00 | Разогрев | ⚡ Inference |
| 11:00–13:00 | Пик | ⚡ Полная загрузка |
| 13:00–14:00 | Обед | 🧠 Training на свободных GPU |
| 14:00–18:00 | Второй пик | ⚡ Inference |
| 19:00–00:00 | Спад → 0 | 🧠 5 часов training |
| Выходные | ~0 | 🧠 48 часов training |

**Итого: ~80–100 часов training в неделю. Бесплатно — электричество платишь в любом случае.**

### Три модели — три pipeline

| Модель | Учится | Откуда данные | Частота |
|---|---|---|---|
| 72B (исполнитель) | Писать лучший код | PASS diffs, merged PRs, human edits | Каждую ночь |
| 32B (атомизатор) | Лучше разбивать задачи | (EPIC, DAG, completion_rate) | Раз в 2–3 дня |
| 8B (ревьюер) | Точнее ловить ошибки | (diff, PASS/FAIL, human_override) | Каждую ночь |

## Замкнутый реактор

```
Клиенты платят → задачи → данные копятся
       ↑                        ↓
 больше клиентов         GPU idle → training
       ↑                        ↓
 быстрее PR ←── модель лучше ←──┘

+ ОСИРИС-клиент (B2C):
  10K+ пользователей → русскоязычные диалоги ежедневно →
  модель лучше понимает русский бизнес-контекст →
  forge качественнее на русских задачах →
  больше клиентов forge

+ Free tier ОСИРИС-клиента → воронка:
  часть бесплатных = разработчики = клиенты Agent
  часть = владельцы бизнесов = клиенты B2B ботов
  Cross-sell бесплатно
```

Каждый новый клиент улучшает сервис для всех остальных.
Каждый idle-час GPU бесплатно увеличивает качество.
Конкурент, стартующий через год, начнёт с нуля по всем пяти уровням защиты.

## Правила для планировщика

**Три вопроса к каждой задаче:**

1. **Приближает День D?** → наивысший приоритет
2. **Закрывает стратегическую дверь?** → делать немедленно, даже если не срочно
3. **Костыль или архитектура?** → костыль изолировать за провайдерным интерфейсом

**Что нельзя ломать никогда:**
- Формат `traces.jsonl` с lang-тегом — структура фиксируется сейчас навсегда
- Контракт `SandboxSession` — добавлять языки, не переписывать интерфейс
- GitHub integration — переезд сервера прозрачен для клиента

**Текущие костыли (временные, изолировать):**

| Костыль | Заменяется на | Когда |
|---|---|---|
| Perplexity (планировщик) | остаётся / собственный | по мере роста |
| Cursor CLI | vLLM + Aider / собственный агент | День D |
| Qwen CLI | 72B локально через vLLM | День D |
| Локальная машина | 4× RTX 5090 | День D |

Замена = правка конфига, не рефакторинг. Архитектура провайдерного интерфейса должна это обеспечить уже сейчас.
