# Golden-приложение: Блокнот (Notepad)

Приложение категории **utility** для хранения текстовых заметок. Минимальный golden-пример: хранилище, строки, цикл по заметкам.

## Идентификация

- **id:** `notepad.osn`
- **Категория:** `utility` (реестр приложений, `registry-v0.1.md`)
- **Манифест:** `src/runtime/fixtures/notepad.osapp.yaml`
- **Модуль:** `блокнот.osnova` → `блокнот.osvbc.json`

## Точка входа для golden-теста

- **Текущая:** процедура `запуск()` — минимальная реализация (лог приветствия)
- **Целевая для golden:** процедура `run_golden(заметки)` — принимает массив строк, записывает в хранилище, проверяет чтение

В манифесте заданы `entry.procedure: "запуск"`, `entry.args: []`. Для автоматического golden-теста можно добавить `run_golden` и соответствующие `entry.args` в манифесте.

## Конструкции языка, которые проверяет

- **`для_каждого`** — обход массива заметок (при реализации `run_golden`)
- **`система.хранилище`** — запись и чтение заметок (ключ `notes` или `заметки`)
- **`система.строка.объединить`** — склейка заметок с разделителем `\n`

## Процедуры модуля

| Процедура | Назначение |
|-----------|------------|
| `запуск()` | Точка входа. Текущая реализация: вывод «Привет из Основа» в лог. Целевая: окно, список заметок, добавление/редактирование. |

## Ожидаемые ключи хранилища и значения (golden)

При реализации `run_golden(заметки)` в хранилище приложения `notepad.osn`:

| Ключ | Ожидаемое значение | Пояснение |
|------|--------------------|-----------|
| `notes` | строка, заметки через `\n` | Список заметок, сохранённых из аргумента |

## Зависимости API

- `система.лог`: вывести
- `система.хранилище`: прочитать, записать (целевое использование)
- `система.строка`: объединить (целевое)
- **Permissions в манифесте:** files (read: `~/Документы`, write: `~/Документы/ОСь`), system.clipboard, network: no

## Запуск

**Вручную (текущая реализация):**
```bash
npx tsx src/cli.ts run --manifest src/runtime/fixtures/notepad.osapp.yaml
```
или после сборки:
```bash
npm run build
osnova run --manifest src/runtime/fixtures/notepad.osapp.yaml
```

## Использование в LLM-пайплайне

Блокнот — пример приложения категории **utility** для хранения текста: генерация по спекам «заметки, список, сохранение в хранилище» с опорой на реестр языка (`пусть`, `для_каждого`, `система.хранилище`, `система.строка.объединить`).
