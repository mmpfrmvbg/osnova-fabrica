# ОС-НОВА Center — спека v1

Центр управления ОС-НОВА — единое место где пользователь видит
все приложения, сервисы, права и историю работы системы.
Реализуется как веб-UI (HTTP-сервер) или Основа-приложение.

## Формат реализации

- Отдельное Основа-приложение: osnova.center
- Манифест: src/runtime/fixtures/center.osapp.yaml
- UI: веб-UI (HTTP-сервер + браузер), uiKind: web
- Запуск: npx tsx src/cli.ts run --manifest src/runtime/fixtures/center.osapp.yaml

## Экраны

### Экран «Приложения»
- Список всех записей реестра: id, name, category, версия
- Действия для каждого: «Запустить», «Манифест», «Трейсы»
- Источник данных: docs/registry-v0.1.md / *.osapp.yaml из fixtures/

### Экран «Сервисы»
- Список системных сервисов (notifications, clipboard и др.)
- Статус каждого: активен / неактивен
- Базовая статистика: количество invoke за сессию, последняя ошибка

### Экран «Права»
- Выбор приложения по appId
- Отображение permissions из манифеста
- Таблица: право | значение | описание

### Экран «Трейсы»
- Последние N запусков пайплайна из runs/traces.jsonl
- Фильтр по статусу: success / build_failed / repair_exhausted
- Для каждого трейса: task, status, repairAttempts, timestamp

## Встроенный ассистент

### Интерфейс
- Поле ввода задачи + кнопка «Создать приложение»
- Поток ответов ассистента (статус пайплайна в реальном времени)
- После успеха — ссылка на новое приложение в списке

### Доступный контекст ассистента
- Реестр приложений (registry-v0.1.md)
- Список доступных система.* вызовов (system-api-v1.md)
- Последние трейсы (runs/traces.jsonl)

### Типовые команды ассистента
| Команда | Действие |
|---------|----------|
| «Запусти приложение <id>» | launcher → osnova run |
| «Создай приложение для задачи …» | запуск LLM-пайплайна |
| «Покажи трейсы за последний час» | фильтр traces.jsonl |
| «Какие права у приложения <id>?» | чтение манифеста |

## Сценарии использования (UX-цели Фазы 4)

1. Пользователь устанавливает и запускает приложение через центр управления
2. Пользователь просит ассистента создать приложение — оно появляется в списке
3. Пользователь смотрит что делало приложение (invoke, права, трейсы)
