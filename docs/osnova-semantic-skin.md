# Семантическая шкура ОС-НОВА v0.1 — где кончаются атомы

**Версия:** 0.1
**Дата:** 2026-09
**Статус:** живой документ — продолжает [osnova-apps-roadmap.md](osnova-apps-roadmap.md)

---

## Одна фраза

**Атом = тип/паттерн. Шкура = значение/инстанциирование.** Атом не содержит ни
одной человекочитаемой строки; шкура — вся из строк. Эта граница делает «написать
один раз» выполнимым, а «всех пользователей мира» — разрешимым.

## Главный принцип

Различие атома и шкуры закрыто и механически проверяемо:

- `Документ` — атом (тип). `Заявка{автор, сумма, статус}` — шкура (документ,
  инстанциированный именованными полями).
- CRDT-слияние — атом (операция). *Вот этот* документ сливается с *тем* —
  данные.
- Конечный автомат — атом (паттерн). Состояния `Черновик → Одобрена →
  Отклонена` — шкура.
- Деньги (балансовый инвариант) — атом. Валюта `₽` vs `$`, `1 000,00` vs
  `1,000.00` — шкура.

Операциональная версия того же принципа:

> **Атом не содержит ни одной человекочитаемой строки; шкура — вся из строк.**

Любой видимый пользователю текст, любое доменное имя, любое правило о мире —
это шкура. Проверяется линтером: нашёл литерал в атоме — это баг, литерал
должен быть ссылкой на шкуру.

## Формальный раскол в `.osapp.yaml`

Манифест распадается на две части с жёсткой границей:

```yaml
id: "osnova.approvals"

# ══ АТОМНАЯ ЧАСТЬ — закрытая, безъязыковая, переиспользуемая ══
signature:                     # только ссылки на 27 атомов, ни одного литерала
  states:      [document, log, graph]
  transitions: [command_event, transaction, merge]
  verbs:       [изменить, решить, наблюдать, сообщить, найти]
  trust:       [identity, authz, audit, money]
  lifecycle:   [deploy, scale, observe, migrate]

# ══ СЕМАНТИЧЕСКАЯ ШКУРА — открытая, локализуемая, доменная ══
skin:
  locale: ru-RU
  terms:        # словарь: термин → атомная форма
  labels:       # термин → строки, по локалям
  rules:        # доменные правила (декларативные, не код)
  data:         # факты (не код)
  formats:      # локаль: валюта / дата / число / таймзона
  regulation:   # юрисдикционные требования
```

`signature` конечен и вечен; `skin` бесконечен и растёт. Это физическая граница
«инфраструктура общая → специфика частная» из видения.

## Четыре компонента шкуры

### 1. Термины — словарь домена

Привязывают человеческое имя к атомной форме. Имя — семантическое, форма —
атомная. (Синтаксис ниже — предложение, не факт языка Основа.)

```
термин Заявка: Документ {
  автор:   Идентичность
  сумма:   Деньги
  позиции: Список[Позиция]
  статус:  Перечисление[Черновик, НаСогласовании, Одобрена, Отклонена]
}
```

Компилятор проверяет *атомную форму* (`Документ`, `Деньги`, `Перечисление` —
встроенные типы), а *имя* (`Заявка`, `Позиция`) и *значения перечисления*
(`Черновик`…) — шкура. Сам `Перечисление` — атом, его **члены** — шкура: тип =
атом, значение = шкура, в чистом виде.

### 2. Правила — декларативная доменная логика

Паттерн «когда → требуется» атомный (атом C5 + проверка ограничений);
*содержимое* — шкура:

```
правило "двойное согласование" {
  когда:     Заявка.сумма > 100_000
  требуется: число(Заявка.согласующие) >= 2
}
```

### 3. Данные — факты, не код

Оргструктура, имена согласующих, план счетов. Самая очевидно-некодовая часть —
и именно она чаще всего ошибочно зашивается в атомы.

### 4. Локализация — строки и локаль

```yaml
labels:
  ru: {Заявка: "Заявка",  Одобрить: "Одобрить",  Сумма: "Сумма"}
  en: {Заявка: "Purchase Request", Одобрить: "Approve", Сумма: "Amount"}
formats:
  ru-RU: {валюта: RUB, дата: "DD.MM.YYYY"}
  en-US: {валюта: USD, дата: "MM/DD/YYYY"}
```

## Оракул границы (три механических теста)

Для любого элемента манифеста:

| Тест | Вопрос | Ответ «атом» | Ответ «шкура» |
|---|---|---|---|
| **Строковый** | Содержит видимый литерал? | Нет | Да |
| **Замкнутости** | Одно из 27 / выразимо только через них? | Да | Вводит новый термин |
| **Инварианта** | Корректность проверяется инвариантом, не зависящим от языка/культуры/домена? | Да | Истина зависит от закона/бизнес-правила |

Прошёл все три как «атом» → это атом. Споткнулся хоть об один → шкура.

---

## Как шкура локализуется: один атлас → N локальностей

1. **Термины — стабильные безъязыковые токены.** Код ссылается на `Заявка`
   (токен), UI-проектор разрешает `labels[locale][Заявка]`. Ни одна строка не
   зашита в код.
2. **Атомы не эмитят строки напрямую.** Компилятор гарантирует: проектору,
   которому нужен текст, положено взять его из шкуры. Поэтому «русский
   синтаксис Основы» — *источник*, а не *ограничение*: атомы одинаковы, шкура
   переводится на любой язык.
3. **Правила и регуляции — с областью юрисдикции.** Та же атомная композиция,
   разные наборы правил: медицина в ЕС (GDPR) vs США (HIPAA), разные налоги.
   Правила живут в шкуре и подменяются на юрисдикцию.
4. **Шкуры композируются слоями с перекрытием** (как CSS-специфичность или
   Dhall-merge):
   ```
   skin = base.domain + locale.ru + jurisdiction.eu + client.dentist
   ```
   Базовый домен → локаль → юрисдикция → клиент, каждый слой перекрывает
   предыдущий. Атомы зафиксированы под всеми слоями.

## Почему это делает «всех пользователей мира» разрешимым

- **Атомы масштабируются конечностью** — написал один раз, больше никогда.
- **Шкуры масштабируются тем, что они данные** — новый локаль/домен/клиент =
  новые термины, правила, лейблы, факты. Данные дёшево добавлять, безопасно
  версионировать, и они не угрожают инварианту, потому что закарантинены в шкуре.
- **У Фабрики две чистые работы**: (а) генерировать/проверять *атомы* — закрыто,
  по инвариантам; (б) генерировать/проверять *шкуры* — открыто, но каждая шкура
  это данные+правила, что проверяется на порядок легче произвольного кода.
- **Граница монетизации физическая**: атомы — общая бесплатная инфраструктура,
  шкура — платный продукт.

## Разделение golden-тестов

Граница делит и тестовую нагрузку:

| Golden | Что проверяет | Как часто меняется |
|---|---|---|
| Атом | инвариант: CRDT сходится, лог append-only, транзакция атомарна | один раз, навсегда |
| Шкура | доменное поведение: todo/micro_crm рендерятся и ведут себя верно | растёт с доменами |

---

## Северная звезда

Любое решение оценивается одним вопросом:

> **Держится ли граница: атомы остаются без строк и конечными, а всё
> человеческое и локализуемое закарантинено в шкуре?**

Если да — делаем. Если нет — откладываем.
