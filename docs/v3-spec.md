> итерацию разработки. В продакшене — `docs/spec.md`, без метки. `src/spec/osnova-spec.ts` и

`v2`/`v3` — внутренние метки итераций, **не отдельные языки**. Если v2 и v3 говорят разное,
актуально то, что сказано здесь; v2 — устаревший reference. Это не «v2 говорит одно, v3 другое»,
а «v2 устарело, v3 — актуально».

В реестре документ помечен `active` — это **рабочий фронт**, а не `scratch`-разведка: черновик
единственной спеки, по которому идёт AST 2.0. `scratch` был бы ложью о роли документа.

## 1. Актуальная лексика

Ключевые слова и формы:

```text
процедура действие если иначе «иначе если» пока вернуть пусть
конец если, конец пока, конец <имя>
модуль экспорт подключить как тип
Результат Успех Ошибка поднять
да нет пусто и или не нацело
```

Типы и знаки:

```text
Число Строка Логическое Пусто Список<...> Результат<..., ...> Ошибка
-> == != <= >= + - * / % = : , . ? ( ) [ ] { } | // /* */
```

`модуль`, `экспорт`, `подключить`, `как`, `тип` — **зарезервированы** (см. §3), не входят в
v0.1-грамматику. `.`, `?`, `|`, `{`, `}` — пунктуация/резерв; `{}` **не** литерал `Ошибка` и не
struct literal в v0.1; `.` в AST 2.0 не используется.

`и`/`или`/`не` — ключевые. Текущий v3-парсер их знает: `src/compiler-v3/parser.ts#или`,
`src/compiler-v3/parser.ts#и`, `src/compiler-v3/parser.ts#не`; A3-verify 8/8 на живой E8C2 это
подтвердил. Отдельной правки A4a для них нет.

## 2. Убрано из актуальной лексики — навсегда

| Убрано | Почему | Где осталось |
|---|---|---|
| `защита`, `при ошибке` | скрытый переход = D4; `OSN-PAR-021` — финальный отказ | v2-оракул, A1.5-история |
| `Неудача` | синоним; одна форма на понятие | A1 (названное расхождение, A4a после L2) |
| `Может` | нет в AST/коде; Maybe — после v0.1 | v2-оракул |
| `типа` | ключ без грамматики | v2-оракул |
| `Словарь` (v0.1) | парсер не использует; библиотеки после | v2-оракул |
| `→` | только ASCII `->`; `OSN-PAR-026` | v2-оракул (81), черновик (1) |
| `число`/`строка` как литералы | это не литералы, а имена | внутренние token-kind v2-оракула |
| `попробовать`/`поймать`/`выбросить` | второй механизм ошибок | shared v2-путь (не трогается) |

`защита` — **не** «отложена до v0.2». Её нет ни в v0.1, ни в v0.2. A2/A2-block **не делать**.

| Форма | Когда | Что значит |

| `прервать`/`продолжить` | после v0.1 | управление циклом |

## 4. Модель ошибок — один путь

**`Результат<T, E>` — единственный механизм ошибок на границах.** Внутри процедуры допустимо
голое значение; ошибка, пересекающая границу, — только пара. Исключений в рантайме нет.

- **`Успех(значение)`** — конструктор успеха, ровно один payload.
- **`Ошибка(код, сообщение)`** — конструктор неудачи для `E = Ошибка`; ровно два аргумента:
  `код: Число`, `сообщение: Строка`. `Ошибка` — **встроенный тип**, не struct.
- **`Ошибка{...}`** — **нет**: это не struct literal. `Ошибка(1, "беда")` — вызов конструктора.
- **`поднять <выражение>`** — инструкция (не выражение): разворачивается в ветвь неудачи
  `Результат<T, E>` с payload `<выражение>`. В записи `поднять(значение)` скобки означают
  нагрузку, а не вызов функции; `х = поднять(ф()) + 1` — отказ разбора.
- **`пусть тег, нагрузка = вызов()`** — явный разбор пары; ничего скрытого.
- `Успех`/`Ошибка` допустимы только в процедуре, объявленной `-> Результат<T, E>`; вне —
  `OSN-PAR-022`. Неверная арность — `OSN-PAR-023`. `Ошибка{...}` — `OSN-PAR-024`.
- `Неудача` — **нет**. `защита` — **нет**. Второго пути нет.

## 5. `конец` — explicit

- `конец если`, `конец пока`.
- `конец <имя>` — имя процедуры/действия; обязано совпадать.
- Bare `конец` — **ошибка** `OSN-PAR-025`.
- `иначе если` — цепочка; **один** `конец если` на всю цепочку.

## 6. `->` — только ASCII

`->` — объявление возврата. `→` — **ошибка** `OSN-PAR-026`. Это breaking change для v2-текстов;
v2-оракул не переписывается.

## 7. Типы

- **`Число`** — int64, D52.
- **`Строка`** — последовательность кодпоинтов, D1.
- **`Логическое`**, **`Пусто`**.
- **`Список<T>`** — список.
- **`Результат<T, E>`** — пара; ABI — два регистра (D2/§10.2).
- **`Ошибка`** — встроенный payload-тип: `код: Число`, `сообщение: Строка`.

## 8. Локальные и затенение

- `пусть имя = выражение`
- `пусть имя: Тип = выражение`

Затенение — **запрещено** (`OSN-PAR-027`). Канон v2 §13.10 — названный долг; проверка — A4a/после.

## 9. AST 2.0 — критический путь

Черновик `.tmp/parser-target.osnova` (764 строки) использует: `[` — 179, `+` — 254, `==` — 64,
`!=` — 1, `иначе если` — 3, `нацело` — 4, `пока` — 28, `если` — 123, `пусть` — 18, `вернуть` — 1,
`действие`/`процедура` — по 1, bare `конец` — 2, `→` — 1.

**Не использует:** struct literal (`{`/`}` — 0), `.` — 0, `защита` — 0, `Может` — 0, `типа` — 0,
`Словарь` — 0, `Неудача` — 0, `Успех` — 0.

Поэтому AST 2.0 = **операторы, списки, индексация, `иначе если`, `нацело`**; **без** struct
literal и `.`. Метка `2.0` — внутренняя (версия формата); в продакшене — `docs/ast-format.md` без
«2.0 vs 1.1».
