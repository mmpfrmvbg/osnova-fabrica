### [v1.0.0] — минимальное ядро языка и системного API

**Статус:** текущая стабильная версия, на которую опираются тулчейн, VM и LLM‑пайплайн.

- **Синтаксис:**
  - Один файл = один модуль `модуль Имя`.
  - Блоки на основе ключевого слова `конец` (без `{}`).
  - Процедуры `процедура имя(параметры)` с телом до `конец`.
  - Точка входа: процедура `главная()` или `запуск()` без параметров.
  - Управляющие конструкции: `если` / `иначе` / `иначе_если`, `пока`, `цикл`, `для_каждого` (как experimental).
  - Оператор присваивания только `=`, без `:=`, без `конец_пока`/`конец_процедуры` и других суффиксов.
  - Разделитель операторов — перевод строки.
- **Типы и данные:**
  - Базовые типы: `Целое32`, `Строка`, `Логический`.
  - Литералы массивов и объектов: `[...]`, `{ ключ: значение }` **только однострочные**.
  - Нет пользовательских типов (`тип`), нет `Результат<T,E>`, нет `?Тип`, нет акторов/каналов.
- **Системное API v1:**
  - Стабильные вызовы: `система.лог.*`, `система.хранилище.*`, `система.массив.*`, `система.объект.получить`, `система.строка.*`, `система.время.*`.
  - Experimental: `система.файлы.*`, `система.окно.*`, `система.интерфейс.*`, `система.сеть.запрос`.
- **Тулчейн и VM:**
  - Формат байткода v1 (`bytecode-v1.md`), стековая VM с опкодами `const`, `local.get/set`, арифметикой, сравнениями, `jmp*`, `call`, `invoke`, `ret`.
  - Golden‑приложения (TODO, File Viewer, Notifications, Micro‑CRM, Game Rounds) и VLIW‑пример v2 в виде `.osvbc.json` фикстур.
  - LLM‑пайплайн `intake → spec → codegen → build → golden_check → repair` по `pipeline-v1.md`, трейс‑формат `traces-v1.md`.

### [v0.1.0] — экспериментальная грамматика и расширенный язык

**Статус:** историческая экспериментальная версия, **не реализованная полностью в текущем компиляторе**.  
Спецификация: `grammatika-v0.1.md`, ранние версии `lexer-v0.1.md`, `parser-v0.1.md`, `trace-format-v0.1.md`.

- **Расширенный синтаксис:**
  - Блоки через `{ ... }` и `;` как разделитель операторов.
  - Отдельные `процедура` и `функция` (чистая функция с обязательным возвратом).
  - Вызов как оператор только через ключевое слово `вызвать`.
  - Конструкции высокого уровня: `совпадает` / `когда` (pattern matching), `параллельно`, `предвыбор`, `пакет` / `слот`, `регион`, `цикл (по ... в ...) разворачивать N`, `небезопасно`.
  - Акторы и каналы: `актор`, `канал<Тип>`, `задача`, `ожидать`.
- **Типы и ошибки:**
  - Пользовательские типы `тип Имя { поля }`, видимость `открытый` / `закрытый`.
  - Встроенные типы: `Целое8/16/32/64`, `Вещественное32/64`, `Логический`, `Строка`, `Байт`, `Ничто`.
  - Опциональные типы `?Тип`, ссылки `ссылка Тип`.
  - Алгебраический `Результат<Т,Е>` с конструкторами `Успех(...)` и `Неудача(...)`.
- **Планы по компилятору (не реализовано полностью):**
  - Полноценный типчекер с таблицей символов, выводом типов выражений и проверкой совместимости.
  - Поддержка всех расширенных конструкций в AST и бэкенде.
  - VLIW‑маркировка (`параллельно`, `пакет`, `регион`, `разворачивать`, `предвыбор`) как подсказки для будущего VLIW‑бэкенда.
  - Богатый формат трейсов `trace-format-v0.1.md` с IR, AST, байткод‑гистограммами и пользовательским фидбеком.
