# Language Changelog v2

Версионирование языка:

- **MINOR** (`2.x.0`) — новая фича или совместимое расширение языка.
- **PATCH** (`2.x.y`) — bugfix без изменения спецификации, на которую опирается пользовательский код.
- **MAJOR** (`3.0.0`) — несовместимые изменения языка.

## Unreleased

Версия блока — **2.6.0** (MINOR), выставить при выкладке: закрывающие слова
добавлены, `конец` продолжает работать. Несовместимости нет, поэтому не MAJOR.
Проверено: в корпусе (`grep -r "пусть конец" src/`) переменной с именем `конец`
не было, то есть снятие зарезервированности ничего не ломает — это исправление,
а не поломка. `LANGUAGE_VERSION` пока `2.3.2`: канон-номер поднимается на выкладке
(см. `memory/v2-goal.md` §1 — вопрос названия решается до БЛОКА 3).

### Added
- **Раздел 13 канона: двенадцать пунктов со СТАТУСОМ** (`docs/language-v2.md` §13).
  Закон раздела: канон не пишется раньше проверки; у утверждения ровно один из
  двух статусов — «проверено прогоном» (без оговорок) или «не проверено»
  (постоянный честный статус). Третьего нет. Оракул — `src/compiler/canon.test.ts`
  (**42** проверки, негативные контроли — **9** мутаций исходников, все краснят,
  файлы восстановлены по sha256). Пробы: `.tmp/canon-probes.ts`,
  `.tmp/canon-probes2.ts`, `.tmp/canon-probes3.ts`.
  **Проверено прогоном:** знак остатка по делимому и отсечение частного к нулю;
  `a div b * b + a % b == a` при всех знаках; отрицательный ноль
  (`(0-6) % 3` = `-0`, неотличим от 0 во всех операциях языка); ноль в делителе —
  машинная ошибка, **не ловится** `попробовать` (перехват работает на опкоде
  `выбросить`, отказ арифметики приходит JS-исключением); `пусть` — неизменяемость
  СВЯЗЫВАНИЯ при мутабельных массивах; матрица смешения типов (аннотации в
  арифметике не участвуют: `Целое32 + Число` = 7.5, `Целое32 / Целое32` = 3.5);
  кодировка исходника (LF, CRLF и одиночный CR принимаются, **BOM отвергается**);
  `для ч в коллекция` связывает **ЭЛЕМЕНТ** (различающий опыт: сумма 30, `ч` на
  первой итерации 10).
  **Канон переписан на ИЗМЕРЕННОЕ там, где раньше стояло намерение**
  (2026-09-26, та же сессия): `Целое32` **не обёртывается**
  (`2000000000+2000000000` = 4000000000) — обёртка объявлена **не реализованной**,
  а паритет VM↔e2k по переполнению — названным долгом; строка считается в
  **единицах UTF-16** (`длина("👍")` = 2), а «кодовые точки» вынесены в отдельную
  работу как смена семантики для каждой программы; `->` **удалён из канона**
  совсем (зарезервирован только `: Тип`, и аннотации уже проверяются на
  несовпадение); `Целое64` **введён** аннотацией, сводящейся к `Число`
  (проверено равенством байткода, отдельной 64-битной арифметики нет).
  **Названо расхождением, а не деталью:** `диапазон` — **не существует**
  (решение: реализуется, с оракулом на границы); `для ч в "аб"` даёт ноль
  итераций и **молчит** — решение: отказ с точной причиной; затенение
  **диагностируется, но не запрещено** (сборка не отвергается); правило имён
  файлов **отсутствует** — принимаются дефис, заглавные и цифра в начале;
  `smodx` на e2k даёт `(-7) % 3` = 0 против −1 у VM и руководства
  МЦСТ §10.3.3 — паритет по знаку остатка не подтверждён; `SMODX` при нулевом
  делителе **не проверен**.
  **Трюк `(a - a % b) / b` вычищен** — `f5b6c29` (2026-09-26): ядро
  `tests/dsp/kernels/iir.osnova` возвращает частное через `div`, покрытие пяти
  ядер **464 из 464**, отказов **0** (было 424 из 446 и 22 отказа). Пункт 13.1
  переведён из «нарушен» в «выполнен».
  **§13.12 — матрица статуса понижения на e2k** (VM / e2k / Нет) по девяти
  возможностям: она закрывает риск «библиотека обгоняет рантайм» — окна, сеть и
  интерфейс работают на VM и **не понижены** на цель.
  Машинная плоскость (`src/e2k/**`, `docs/e2k-*`, `docs/hardware-debt.md`) в
  каноне только цитируется и не изменялась.
- **Файл = модуль** (БЛОК 3, пункт 1). Шапка `модуль имя` каноном больше не
  является и **не обязательна**: один файл — один модуль, имя берётся из имени
  файла (`привет.osnova` → модуль «привет»; снимается каталог и расширение
  `.osnova`). Legacy-форма `модуль имя … конец_модуля` **принимается**: имя
  берётся из шапки, а закрытие при шапке остаётся необязательным — как и было.
  **Приём совместим**: множество принимаемых программ только выросло, ни одна
  прежде компилировавшаяся программа не отвергнута.
  **Трактовка развилки — по замеру корпуса** (2026-09-19): из **68** файлов
  `.osnova` шапка есть у **68**, `конец_модуля` — у **11**, то есть **57**
  файлов модуль не закрывают; файлов без шапки — **0**. Объявить «шапка без
  закрытия» ошибкой значило бы обрушить 57 файлов корпуса и 46 файлов оракулов
  сразу — то есть нарушить два критерия блока («legacy принимается», «npm test —
  0 падений») ради буквы формулировки. Решение владельца: это **предупреждение
  по флагу** (`warnDeprecated` / `--warn-deprecated`, по умолчанию молчит — та же
  развязка, что у Стадии 2), а **ошибка ровно одна и обратного рода**:
  `конец_модуля` **без** шапки — закрытие без открытия, с точной причиной и обоими
  способами починки. Прежде такой файл тоже не компилировался, но сообщение было
  «Ожидается 'модуль'» — оно указывало не туда.
  **Почему `конец_модуля` и одиночный `конец` разведены:** `конец_модуля`
  *называет* модуль, то есть утверждает «модуль объявлен шапкой», и в
  файле-модуле это утверждение ложно; одиночный `конец` имени не называет и
  остаётся принимаемым legacy-закрытием (БЛОК 1 v2).
  **Импорт:** имя модуля импортируемого файла берётся из имени **этого** файла, а
  не входного (`parseModuleOrThrow`). Без имени файла модуль называется `вход` —
  то же умолчание, что у входного файла в `compileSource`.
  **Счётчик долга Стадии 2 не затронут:** `npm run report:deprecated-end` считает
  только устаревшие закрытия `конец`, новый вид предупреждения в это число не
  входит — иначе число перестало бы значить написанное в шапке отчёта.
  Оракул: `src/compiler/fileAsModule.test.ts` (**23** проверки, красный до правки;
  негативный контроль — приём без шапки проверяется на имени, которого нет в
  исходнике). Канон: `docs/language-v2.md` §4. Реестр и machine-readable схема
  обновлены (`docs/osnova/language-schema.json`).
  **Self-host (`src/self-host/stage1-16`) не мигрирован** — шапки у него есть,
  `конец_модуля` не используется ни разу, legacy-форма работает. Оракул пересборки
  теперь собирает артефакт с именем файла, как `osnova compile`: до этой правки
  расхождение было деталью диагностики, теперь имя файла — источник имени модуля.
- **`div` — целочисленное деление** (БЛОК 2). `10 div 3` = 3, округление —
  **отсечение к нулю**: `(0 - 7) div 3` = -2; делитель 0 — ошибка исполнения.
  Правило округления согласовано с `%` (тождество `a div b * b + a % b == a`
  выполняется при любых знаках) и совпадает с формой e2k `SDIVs`
  (руководство МЦСТ §10.3.3). Уровень — как у `*`, `/`, `%`; левоассоциативно.
  **`//` оператором не стал:** `//` — комментарий до конца строки, и `10 // 3`
  молча даёт `10`. Замер перед решением (`runs/traces.jsonl`, 3675 исходников):
  `//` после кода — 4 случая, все четыре — пояснения; `div`/`дел`/`цел_деление` —
  ноль. Русское `цел_деление` принимается **алиасом** (`LLM_KEYWORD_ALIASES`).
  Новый носитель `IR.idiv` понижается в `sdivs` (канал только пятый, тот же
  делитель `alu5`), тогда как `IR.div` остаётся **отказом** — он вещественный.
  В байткоде — новый опкод `idiv` (`div` в VM по-прежнему `a / b`).
- **Предупреждение об устаревшем закрывающем `конец`** (Стадия 2 плана v2).
  Язык не меняется: `конец` принимается как прежде. Компилятор умеет сообщать,
  что блок закрыт legacy-словом, и называет канон. Включение —
  `CompileOptions.warnDeprecated` / флаг CLI `--warn-deprecated` (`osnova-compile`
  и `osnova compile`); **по умолчанию выключено**. `CompileResult.warnings` не
  влияет ни на `compilerSuccess`, ни на `BuildReport.success` — это информация,
  а не отказ. На `конец` в позиции имени (`пусть конец = 5`) не срабатывает.
  В CI добавлен информационный шаг `npm run report:deprecated-end`; долг на
  2026-09-23 — **149** закрытий в **19** файлах корпуса. Шаг падает только если
  предупреждение сработало **без** флага (сломанная развязка «по умолчанию
  молчит»), а не из-за ненулевого долга.
- **Реестр синонимов системных вызовов** (пункт 1.5 требований: **41** случай
  `unknown_syscall`). Приём не меняет язык: `SYSCALL_ALIASES` сводит известный
  синоним к канону там, где имя попадает в AST. Карта — по полному имени:
  `система.массив.получить` и `система.сеть.получить` канонические, сегментная
  замена `получить` → `прочитать` их бы сломала.
  `система.хранилище.получить` → `.прочитать`, `.сохранить` → `.записать`,
  `система.окно.вывод` → `система.лог.вывести`, `система.строка.срез` →
  `система.строка.подстрока`.
- **Синонимы системных вызовов пополнены по замеру** (2026-09-23): перекомпилированы
  **3607** сохранённых исходников из `runs/traces.jsonl` (замер воспроизводим:
  `npx tsx src/scripts/traceDiagnosticsReport.ts`). Добавлено **14** пар с
  доказанной целью — `система.вывести`, `система.вывод.текст`,
  `система.окно.вывестиТекст`, `система.окно.отобразить`, `система.окно.создать`,
  `система.окно.ввод`, `система.сеть.отправить`, `система.строка.из`,
  `система.строка.изЧисла`, `система.хранилище.загрузить`,
  `система.хранилище.получить_элемент`, `система.хранилище.удалить_элемент`,
  `система.хранилище.добавить`, `система.число.остаток`. Эффект:
  `unknown_syscall` **34 случая / 20 имён → 16 / 9**. `система.результат.*` ждут
  БЛОКА 3; остальные имена канонической цели не имеют и не переписаны (список и
  причины — §9 канона).
- **Диагностика `пока_не`**: конструкции нет (решение владельца — не добавлять),
  в позиции конструкции выдаётся «нет конструкции 'пока_не'; используйте
  'пока не x'» вместо каскада ошибок. Как имя переменной слово законно.
- `=` как `==` в позиции условия распространяется на все булевы позиции; аудит:
  их ровно три — `если`, `иначе_если`, `пока`.

- Закрывающие слова, называющие свой блок (БЛОК 1 v2): `конец_если`,
  `конец_когда`, `конец_пока`, `конец_для`, `конец_для_каждого`, `конец_цикла`,
  `конец_попробовать`, `конец_процедуры`, `конец_модуля`.
- `конец` перестал быть зарезервированным: в позиции имени работает как обычное
  имя (`тип Объект = { конец: Число }`, `о.конец`, параметр процедуры), в том
  числе в выражении: `вернуть конец`.
- Диагностика несовпадения закрытия: «Закрытие не совпадает: блок «X»
  закрывается 'конец_X' или 'конец', получено: …».
- `else if` (с пробелом) собирается в один токен `иначе_если`; английский алиас
  `end` сохраняет контекст закрытия.
- **`=` как `==` в позиции условия** (пункт 1.1 требований: **52** случая в
  трейсах). В условии после `если`, `иначе_если`, `пока` одиночный `=` читается
  как `==`, включая вложенные вызовы в том же условии. Вне условия `=` остаётся
  присваиванием, а в выражении — ошибкой (граница зафиксирована оракулом).
- **`:=` как алиас `=`** (пункт 1.3 требований: **20** случаев). Лексер сводит
  `:=` к токену `=`; в реестр операторов не добавлен — там инвариант «символ →
  тот же вид токена», а `:=` алиас, как `===` и `!==`.
- **`для` — канон перебора** вместо `для_каждого` (замер цены:
  `docs/token-cost-report.md` §4 — `для_каждого` 6 токенов против 3 у
  естественной формы; одно слово короче обоих). `для_каждого` и `for` — алиасы.
- **`поймать` — канон catch** вместо `иначе_попытка`; `иначе_попытка` и `catch`
  — алиасы к тому же виду токена.

### Changed
- **`когда` — не позиция условия.** Его голова — значение для сопоставления
  (AST-поле `scrutinee`, реестр `match_when`), а ветка `есть` обязана быть
  литералом перечня `Имя.вариант` (иначе `compilerError` «в есть нужен литерал
  перечня»). `=` там не включается: булева сопоставления в `когда` не существует.
- **`::=` в machine-readable каноне** — метаданные оператора `=`
  (`operators[].aliases`), а не отдельный оператор: отдельная запись потребовала бы
  своего вида токена, а лексер сводит `::=` к `=`.
- **Промпт кодогенерации** приведён к канону БЛОК 1 v2: примеры учили
  `для_каждого` и `иначе_попытка`, теперь — `для` и `поймать` (алиасы остались
  только пояснением в списке зарезервированных слов). Добавлены правила
  `redeclare_var` (82 случая, пункт 1.6) и `undeclared_var` (106 случаев, пункт
  1.7) с парой НЕЛЬЗЯ/ПРАВИЛЬНО и few-shot; пример к `undeclared_var` оракул
  компилирует — «похожий на код» текст правилом не считается. Оба правила живут в
  промпте, а не в языке.

- Анти-паттерн `composite_end` перевёрнут: `bad` — закрытие не тем словом,
  `good` — `конец_X` своего блока (реестр). Ранее составные `конец_*` были
  объявлены неподдерживаемыми.
- `поймать` (бывш. `иначе_попытка`) стал опционален: `попробовать …
  конец_попробовать` без catch-блока допустим.
- Вид токена catch переименован в `поймать`, вид токена перебора — в `для`;
  AST-узлы сохранили прежние имена (`для_каждого`) — это внутренние имена, не
  синтаксис.
- **Зарезервированность `для`:** имя переменной ровно `для` теперь даёт
  неблокирующий `keyword_as_identifier` (§12.2 — компиляция проходит). В корпусе
  такого имени нет (grep: `для` встречается только в комментариях); имена,
  начинающиеся с `для`, не затронуты (максимальное сцепление: `для_чего` — имя).

### Fixed
- **Пустой файл компилируется** (следствие «файл = модуль», БЛОК 3, пункт 1).
  Пустой источник, одни переводы строк и одни комментарии давали
  `compilerSuccess = false` при **нуле диагностик во всех фазах**: условие ветки
  «файл = модуль» требовало, чтобы поток не начинался сразу с `конец_файла`,
  модулей получалось ноль, AST был `null`, и `compileSource` отказывал по
  `modules.length === 0`. Теперь это модуль с именем из имени файла и пустым
  телом. Отказ без диагностики — худший вид отказа: по нему нельзя понять, что не
  так. Оракул: `src/compiler/fileAsModule.test.ts` (13 проверок пустого файла,
  включая два негативных контроля — постороннее слово и `конец_модуля`).
- Разбор всегда завершается: во все циклы тел блоков добавлена гарантия
  прогресса. До правки `если` без закрытия в конце файла давал вечный цикл/OOM
  (`parser-robustness`, 22 теста с лимитом 5 с).
- Английский `else if` разбирался как ветка `иначе` + новая инструкция `если`
  внутри неё.
- Канон перестал утверждать несуществующее ограничение: `вернуть конец` был
  описан как неподдержанный, хотя поддержан (долг закрыт, оракул 1.1–1.5).

### Известный долг (не выдаётся за готовое)
- Гарантия прогресса в парсере не покрыта оракулом (замер: 875 входов,
  0 срабатываний) — защита в глубину, реестр `docs/verification-debt.md` п. 5.
- Стопка закрытий в конце файла (`конец` + `конец_модуля`) даёт ошибку с
  указанием строки, но не всегда формулировку «лишний … : модуль закрыт на
  строке N» (отложено владельцем).
