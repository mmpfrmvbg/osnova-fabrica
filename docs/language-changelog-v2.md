# Language Changelog v2

Версионирование языка:

- **MINOR** (`2.x.0`) — новая фича или совместимое расширение языка.
- **PATCH** (`2.x.y`) — bugfix без изменения спецификации, на которую опирается пользовательский код.
- **MAJOR** (`3.0.0`) — несовместимые изменения языка.
