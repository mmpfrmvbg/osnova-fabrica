# Golden-приложение: TODO-лист (ОСи)

> **Поправка 2026-09-25.** Источник `src/runtime/fixtures/todo.osnova` переведён к канону §13.3 (`docs/language-v2.md`): шапка `модуль todo` снята — файл сам является модулем. Программа не менялась: проба `.tmp/fixture-headers.ts` сравнивает все поля регистрового модуля до и после правки и даёт различие только в поле имени модуля, а здесь имя совпадает с именем файла и не меняется вовсе, поэтому артефакт `.osvbc.json` остался побайтово тем же. Метка ⚠ у этого документа в `docs/README.md` снялась **из-за самой этой правки** (док стал новее исходника), а не потому, что документ сверен заново.

Первый «реальный» OS-nova-апп для golden-теста всей ОСи: окно, хранилище, кнопки, цикл обработки событий.

## Поведение

- Окно «TODO» 400×300.
- Поле ввода (подсказка «Новая задача»), кнопка «Добавить», текст «Items:», область текста со списком задач.
- При запуске: загрузка из хранилища ключа `items` (строка, задачи через `\n`), отображение в области.
- По клику «Добавить»: взять значение из поля, дописать к `items` с `\n`, записать в хранилище, обновить область, очистить поле.
- При событии «закрытие» окна: закрыть окно и выйти из процедуры (код выхода 0).

## Зависимости API

- `система.окно`: создать_окно, показать, закрыть, получить_события
- `система.интерфейс`: поле_ввода, кнопка, текст, область_текста, получить_значение, установить_значение
- `система.хранилище`: прочитать, записать
- `система.массив`: длина, получить
- `система.объект`: получить
- `система.строка`: объединить
- `система.время`: спать

## Запуск

**С окном (полное поведение):**
```bash
npx tsx src/cli.ts run --manifest src/runtime/fixtures/todo.osapp.yaml --ui window
```
Откроется браузер с окном «TODO»; добавление задач и закрытие окна завершает процесс (код 0).

**Без окна (проверка загрузки и цикла):**
```bash
npx tsx src/cli.ts run --manifest src/runtime/fixtures/todo.osapp.yaml --ui cli
```
Окно не открывается, `получить_события` возвращает `[]`, цикл крутится (sleep 200 ms). Для автоматического golden-теста можно ограничить число итераций или подставлять мок событий.

## Ожидаемый артефакт для golden-теста

- Манифест: `src/runtime/fixtures/todo.osapp.yaml` (entry: модуль `todo`, процедура `запуск`).
- Байткод: `src/runtime/fixtures/todo.osvbc.json` (модуль `todo`, процедуры `запуск`, `handle_event`, `handle_add`).
- При успешном запуске: процесс выходит с кодом 0; при `--ui window` в браузере видно окно с полем, кнопкой и списком; данные сохраняются в хранилище (ключ `items`).

## Расширения invoke для цикла событий

Для перебора событий и полей объекта добавлены:

- `система.массив.длина(arr)` → число
- `система.массив.получить(arr, index)` → элемент
- `система.объект.получить(obj, key)` → значение
- `система.строка.объединить(a, b)` → a + b
