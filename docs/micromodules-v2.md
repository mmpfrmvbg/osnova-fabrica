# Micromodules for Osnova v2.0

Эти микромодули — референсные "small but real" приложения на языке Основа v2.0.
Их цель: одновременно покрывать репрезентативный срез языка и приносить практическую пользу в реальной работе.

## 1) Micro-CRM

**MVP-цель**  
Небольшой трекер контактов, задач и идей: создание записей, просмотр списков, фильтрация и сортировка по статусу/приоритету, сохранение состояния в простом persistence-слое.

**Конструкции языка (обязательный минимум)**

- пользовательские типы/структуры сущностей,
- коллекции и операции выборки,
- функции, `if/else`, базовые вычисления и агрегации.

**Syscalls**

- чтение/запись в файловую систему или локальное хранилище,
- базовый CLI-ввод/вывод.

**Golden-кейсы**

- добавление/изменение/удаление сущности,
- фильтрация/сортировка по полям,
- сериализация/десериализация состояния (если используется).

## 2) Time-box Planner

**MVP-цель**  
Инструмент раскладки задач по тайм-слотам (дни/часы) с учетом длительности, приоритета и доступного рабочего окна.

**Конструкции языка (обязательный минимум)**

- работа с временем/датами (или с их примитивным представлением),
- циклы и простая алгоритмика планирования (сортировки, размещение),
- композиция функций для расчета расписания.

**Syscalls**

- время/дата (текущая метка и базовые операции),
- ввод/вывод и сохранение расписания.

**Golden-кейсы**

- распределение набора задач по слотам,
- обработка коллизий по времени,
- edge cases: пустой список, задача длиннее доступного окна, переполнение дня.

## 3) Golden Runner Utility

**MVP-цель**  
Утилита для прогона набора `.osnova`-сценариев, сравнения фактического вывода/trace с эталоном и формирования отчета по расхождениям.

**Конструкции языка (обязательный минимум)**

- работа с файлами и наборами сценариев,
- управление процессом прогона и сбором результатов,
- структуры/коллекции для отчета о совпадениях и диффах.

**Syscalls**

- файловая система (чтение кейсов и эталонов, запись отчета),
- при наличии — системный вызов запуска сценария или интеграция с существующим runner.

**Golden-кейсы**

- полный успешный прогон (все тесты совпадают),
- намеренное расхождение и корректный дифф,
- отсутствие эталона/ошибка выполнения отдельного кейса.
