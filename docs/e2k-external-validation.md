# Внешняя валидация кодировки e2k через онлайн-сервисы

**Дата:** 2026-09-15 (вечер)
**Зачем:** кодировка e2k извлечена из четырёх открытых описаний и проверена round-trip
(`docs/e2k-real-run.md`), но **внешней** проверки нет: ни MCST-objdump, ни QEMU в этом окружении
не собраны — нет компилятора C (`docs/e2k-qemu-build.md` §2). Здесь собраны попытки получить
внешнюю проверку **онлайн**, без установки Linux, QEMU и binutils.

**Правило этого документа:** каждое утверждение — с датой, адресом и полученным ответом.
Отрицательный результат — тоже результат, и он записывается так же подробно, как положительный.

---

## 1. Compiler Explorer (godbolt.org)

**Проверено:** 2026-09-15, HTTP-запросами из этого окружения (Node `fetch`).

| что запрошено | ответ |
|---|---|
| `https://godbolt.org` (HEAD) | **200** — сервис доступен |
| `https://godbolt.org/api/compilers` (Accept: application/json) | **200**, `application/json` — **6 277 компиляторов**, **93 языка** |
| `https://godbolt.org/api/languages` | **200** — **97 языков** (некоторые языки без компиляторов) |
| `https://godbolt.org/api/compilers/e2k` | **200** и тело `[]` |
| `https://godbolt.org/api/compilers/elbrus` | **200** и тело `[]` |
| `https://godbolt.org/api/compilers/e2k-gcc` | **200** и тело `[]` |
| `https://godbolt.org/api/compilers/lcc` | **200** и тело `[]` |

**Поиск по формам** (метаправило проекта: искать по всем формам, которыми предмет может быть
назван) — по полям `id`, `name`, `compilerType`, `instructionSet` всех 6 277 записей:

| форма поиска | найдено |
|---|---|
| `e2k` | 0 |
| `elbrus` / `эльбрус` | 0 |
| `mcst` | 0 |
| `vliw` | 0 |

**Наборы инструкций, которые сервис знает** (перечень целиком, для сопоставления):
`amd64 6502 aarch64 llvm arm32 avr ebpf python ptx beam hppa hook kvx loongarch m68k mips
mrisc32 msp430 mpy wdc65c816 powerpc perl riscv32 riscv64 s390x sparc c6x vax wasm32 xtensa
spirv java dex ez80 sh evm x86 z180 z80 eravm`. **e2k в этом перечне нет.**

### 1.1. Найденная ловушка: код ответа не является критерием

`/api/compilers/e2k` отвечает **200**, а не 404: тело — пустой массив. Проверка «сервис ответил
200 на запрос компилятора e2k, значит компилятор есть» дала бы **ложное «найден»**. Критерий —
только поиск по полному списку компиляторов. Это записано здесь потому, что ловушка
воспроизводима и её легко принять за успех.

### 1.2. Результат

> **НЕТ КОМПИЛЯТОРА e2k НА COMPILER EXPLORER**

Ни одного компилятора под e2k/Эльбрус сервис не предоставляет (проверено 2026-09-15).
Следствие: **внешняя валидация кодировки через онлайн-компилятор невозможна** — компилировать
нечем.
