# 10. Модули

Модуль — это файл с исходником. Имя модуля стоит в первой строке и совпадает с
именем файла:

```osnova
модуль касса

процедура главная()
  система.лог.вывести("касса открыта")
конец_процедуры

конец_модуля
```

Файл `касса.osnova` — модуль `касса`. Один файл, один модуль.

## Процедура для других

Чтобы процедуру было видно снаружи, её помечают словом `экспорт`. Есть две
записи, обе одинаковые:

```text
экспорт процедура удвоить(число: Число): Число
процедура экспорт удвоить(число: Число): Число
```

## Два файла

Сделаем модуль с полезными функциями. Файл `математика.osnova`:

```osnova
/* файл: математика.osnova */
модуль математика

экспорт процедура удвоить(число: Число): Число
  вернуть число * 2
конец_процедуры

экспорт процедура сумма_квадратов(а: Число, б: Число): Число
  вернуть а * а + б * б
конец_процедуры

конец_модуля
```

Теперь файл `главная.osnova`, который его использует:

```osnova
/* файл: главная.osnova */
модуль главная

использовать модуль математика из "математика.osnova"

процедура главная()
  система.лог.вывести(математика.удвоить(21))
  система.лог.вывести(математика.сумма_квадратов(3, 4))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
42
25
```

Оба файла лежат рядом. Путь в `из "…"` считается от файла, который подключает.

## Как вызывать чужое

Импортированные процедуры зовутся через имя модуля и точку:

```text
математика.удвоить(21)
```

Просто `удвоить(21)` не сработает: компилятор не знает, из какого модуля имя.
Явное имя модуля убирает путаницу, когда в проекте десяток файлов.

## Несколько модулей

Строк `использовать` может быть сколько нужно:

```text
использовать модуль математика из "математика.osnova"
использовать модуль строки из "строки.osnova"
```

Порядок строк не важен, если модули не зависят друг от друга.

## Что попадает в программу

Компилятор раскрывает импорты до байткода: в готовом файле `.osvbc.json` лежат
все процедуры обоих модулей. Виртуальной машине не нужны исходники — только
байткод.
