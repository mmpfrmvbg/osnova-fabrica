# 12. Целочисленное деление

В языке три похожих операции. Путать их не нужно:

| Операция | Что делает | Пример | Результат |
|---|---|---|---|
| `/` | вещественное деление | `7 / 2` | `3.5` |
| `div` | целочисленное деление, дробная часть отбрасывается | `7 div 2` | `3` |
| `%` | остаток | `7 % 2` | `1` |

```osnova
процедура главная()
  пусть а = 7
  пусть б = 2
  система.лог.вывести(а / б)
  система.лог.вывести(а div б)
  система.лог.вывести(а % б)
конец_процедуры
```
Вывод:
```вывод
3.5
3
1
```

## Куда округляется

`div` отбрасывает дробную часть, то есть округляет **к нулю**. Для
отрицательных это заметно:

```osnova
процедура главная()
  система.лог.вывести((0 - 7) div 3)
  система.лог.вывести((0 - 8) div 3)
  система.лог.вывести(7 div (0 - 3))
конец_процедуры
```
Вывод:
```вывод
-2
-2
-2
```

`0 - 7` равно `-7`. Минус перед числом пишется как `0 - число`: так его читает
компилятор в примерах этого учебника.

Проверить правило просто: `div` и `%` связаны. Частное, умноженное на делитель,
плюс остаток дают исходное число:

```osnova
процедура главная()
  пусть а = 0 - 7
  пусть б = 3
  пусть обратно = (а div б) * б + (а % б)
  система.лог.вывести(обратно)
конец_процедуры
```
Вывод:
```вывод
-7
```

Если бы `div` округлял вниз, до `-3`, эта проверка дала бы `-8`: остаток считается
по знаку делимого, и пара перестала бы сходиться.

## Где применять

`div` нужен всюду, где нужен целый результат: номера, количество страниц, разбивка
на группы, индексы.

```osnova
процедура сколько_страниц(записей: Число, на_странице: Число): Число
  пусть полных = записей div на_странице
  если записей % на_странице > 0
    вернуть полных + 1
  конец_если
  вернуть полных
конец_процедуры

процедура главная()
  система.лог.вывести(сколько_страниц(50, 10))
  система.лог.вывести(сколько_страниц(53, 10))
конец_процедуры
```
Вывод:
```вывод
5
6
```

## Где `div` не нужен

Деление пополам для среднего, проценты и доли — это `/`. Если нужен дробный
результат, целочисленное деление его испортит:

```osnova
процедура главная()
  пусть сумма = 15
  пусть количество = 4
  система.лог.вывести(сумма / количество)
  система.лог.вывести(сумма div количество)
конец_процедуры
```
Вывод:
```вывод
3.75
3
```

## Почему не `//`

В некоторых языках целочисленное деление пишется двумя косыми чертами. В Основе
так писать нельзя: `//` начинает комментарий до конца строки.

```text
пусть а = 10 // 3     ← это 10, а не 3: «// 3» — комментарий
пусть а = 10 div 3    ← правильно
```

Программа с первой строкой не выдаст ошибку. Она молча посчитает `10`, и искать
придётся долго. Поэтому комментарии в примерах этого учебника — блочные,
`/* ... */`, а деление — всегда `div`.

Правило простое: **дробная часть нужна — `/`, целое — `div`, остаток — `%`.**
