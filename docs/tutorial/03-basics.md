# 3. Переменные и типы

## Переменная

Переменная создаётся словом `пусть`. Имя слева, значение справа:

```osnova
модуль переменные

процедура главная()
  пусть имя = "Аня"
  пусть возраст = 30
  система.лог.вывести(имя)
  система.лог.вывести(возраст)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
Аня
30
```

`пусть` пишется **один раз**. Дальше значение меняют присваиванием — знаком `=`:

```osnova
модуль присваивание

процедура главная()
  пусть счётчик = 1
  счётчик = счётчик + 1
  счётчик = счётчик + 1
  система.лог.вывести(счётчик)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
3
```

Второй `пусть` для того же имени — ошибка: компилятор скажет, что переменная уже
объявлена.

## Типы значений

Значения бывают таких видов:

| Вид | Примеры |
|---|---|
| Число | `42`, `3.14`, `0 - 7` |
| Строка | `"привет"`, `""` |
| Логический | `истина`, `ложь` |
| Пусто | `пусто` |
| Массив | `[1, 2, 3]` |
| Объект | `{ имя: "Аня", возраст: 30 }` |

Тип можно назвать явно. Это не обязательно, но помогает читать код:

```osnova
модуль типы

процедура главная()
  пусть количество: Число = 12
  пусть подпись: Строка = "яблок"
  система.лог.вывести(система.строка.объединить(количество, подпись))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
12яблок
```

Свой тип-запись объявляют словом `тип`:

```osnova
модуль записи

тип Товар = { название: Строка, цена: Число }

процедура главная()
  пусть хлеб: Товар = { название: "Хлеб", цена: 40 }
  система.лог.вывести(хлеб.название)
  система.лог.вывести(хлеб.цена)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
Хлеб
40
```

## Арифметика

Работают `+`, `-`, `*`, `/`, `%` и `div`. Сложение, вычитание и умножение — как
везде.

`/` делит вещественно: `7 / 2` равно `3.5`. Целая часть — это `div`: `7 div 2`
равно `3`. Остаток — `%`: `7 % 2` равно `1`.

```osnova
модуль арифметика

процедура главная()
  пусть сумма = 7 + 3
  пусть разность = 7 - 3
  пусть произведение = 7 * 3
  пусть доля = 7 / 2
  пусть целая = 7 div 2
  пусть остаток = 7 % 2
  система.лог.вывести(сумма)
  система.лог.вывести(разность)
  система.лог.вывести(произведение)
  система.лог.вывести(доля)
  система.лог.вывести(целая)
  система.лог.вывести(остаток)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
10
4
21
3.5
3
1
```

Скобки меняют порядок, как в математике:

```osnova
модуль скобки

процедура главная()
  пусть без = 2 + 3 * 4
  пусть со = (2 + 3) * 4
  система.лог.вывести(без)
  система.лог.вывести(со)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
14
20
```

## Строки

Строки складывают через `система.строка.объединить`. Числа при этом сами
становятся текстом.

```osnova
модуль строки

процедура главная()
  пусть приветствие = система.строка.объединить("Привет, ", "мир")
  пусть длина = система.строка.длина(приветствие)
  система.лог.вывести(приветствие)
  система.лог.вывести(длина)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
Привет, мир
11
```

## Комментарии

Комментарий — это текст для человека. Основа понимает два вида: строчный `//` до
конца строки и блочный `/* ... */`. В примерах используется блочный: он не
мешает читать код.

```osnova
модуль комментарии

процедура главная()
  /* ставка налога */
  пусть ставка = 6
  пусть доход = 100
  система.лог.вывести(доход * ставка div 100)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
6
```

Осторожно со строчным `//`: это комментарий, поэтому `10 // 3` — не деление, а
число `10` с отброшенным хвостом строки. Целочисленное деление пишется `div`.

## Как называется значение

Имена переменных пишутся буквами, цифрами и подчёркиванием, начинаются с буквы.
Русские буквы работают: `пусть количество_яблок = 5`. Зарезервированные слова
(`если`, `пока`, `пусть`, `для`, `div` и другие) именами быть не могут — их
список в разделе 14.
