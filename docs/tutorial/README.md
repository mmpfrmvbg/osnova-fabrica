# Учебник языка Основа

Основа — язык программирования с русскими словами. Он компилируется в байткод,
который работает на виртуальной машине проекта, а дальше — на VLIW-процессорах
семейства Эльбрус (e2k).

Этот учебник ведёт с нуля: от запуска первой программы до модулей и системных
вызовов. Каждый пример в нём — рабочая программа, и её вывод показан рядом.

## Что нужно

- Node.js 20 или новее.
- Скопированный репозиторий проекта (в нём лежит компилятор и VM).
- Одна команда установки: `npm install`.

## Как запускать примеры

Любой пример из учебника — это файл `*.osnova`. Сохрани его и выполни две
команды:

```bash
npx tsx src/cli/index.ts compile привет.osnova
npx tsx src/cli/index.ts run привет.osvbc.json
```

Первая команда переводит исходник в байткод (`привет.osvbc.json`), вторая —
исполняет его.

## Первая программа

```osnova
модуль привет

процедура главная()
  система.лог.вывести("Привет, Основа!")
конец_процедуры

конец_модуля
```
Вывод:
```вывод
Привет, Основа!
```

## Проверка

Все 72 примера учебника прогоняются тестом `src/scripts/tutorial.audit.test.ts`:
он компилирует и исполняет каждый блок ```osnova, сверяет вывод с показанным и
запрещает устаревшие формы (`конец` вместо `конец_X`, `для_каждого`,
`иначе_попытка`, `//`). Проверить учебник целиком:

```bash
npx vitest run src/scripts/tutorial.audit.test.ts
```
