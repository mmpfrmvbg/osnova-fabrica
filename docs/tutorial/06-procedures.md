# 6. Процедуры

Процедура — это именованный кусок программы. Объявляется словом `процедура` и
закрывается `конец_процедуры`.

```osnova
процедура поздороваться()
  система.лог.вывести("Привет!")
конец_процедуры

процедура главная()
  поздороваться()
  поздороваться()
конец_процедуры
```
Вывод:
```вывод
Привет!
Привет!
```

## Параметры

Параметры пишутся в скобках через запятую:

```osnova
процедура привет(имя: Строка)
  система.лог.вывести(система.строка.объединить("Привет, ", имя))
конец_процедуры

процедура главная()
  привет("Аня")
  привет("Борис")
конец_процедуры
```
Вывод:
```вывод
Привет, Аня
Привет, Борис
```

Типы параметров указывать не обязательно. С типами компилятор подскажет, если
передал не то.

## Результат

Процедура возвращает значение словом `вернуть`. Тип результата пишется после
скобок через двоеточие:

```osnova
процедура площадь_прямоугольника(а: Число, б: Число): Число
  вернуть а * б
конец_процедуры

процедура главная()
  пусть s = площадь_прямоугольника(3, 4)
  система.лог.вывести(s)
конец_процедуры
```
Вывод:
```вывод
12
```

`вернуть` завершает процедуру сразу:

```osnova
процедура знак(число: Число): Строка
  если число > 0
    вернуть "плюс"
  конец_если
  если число < 0
    вернуть "минус"
  конец_если
  вернуть "ноль"
конец_процедуры

процедура главная()
  система.лог.вывести(знак(5))
  система.лог.вывести(знак(0 - 5))
  система.лог.вывести(знак(0))
конец_процедуры
```
Вывод:
```вывод
плюс
минус
ноль
```

Если процедура ничего не возвращает, `вернуть` пишут без значения — оно просто
заканчивает работу:

```osnova
процедура напечатать_итог(сумма: Число)
  если сумма > 100
    система.лог.вывести("много")
    вернуть
  конец_если
  система.лог.вывести("нормально")
конец_процедуры

процедура главная()
  напечатать_итог(150)
  напечатать_итог(50)
конец_процедуры
```
Вывод:
```вывод
много
нормально
```

## Процедура зовёт себя

Рекурсия работает: процедура может вызывать саму себя, если есть условие выхода.

```osnova
процедура факториал(н: Число): Число
  если н <= 1
    вернуть 1
  конец_если
  вернуть н * факториал(н - 1)
конец_процедуры

процедура главная()
  система.лог.вывести(факториал(5))
конец_процедуры
```
Вывод:
```вывод
120
```

## Переменные внутри процедуры

Переменная, объявленная через `пусть` внутри процедуры, существует только там.
Две процедуры могут использовать одно имя независимо:

```osnova
процедура первая()
  пусть счёт = 1
  система.лог.вывести(счёт)
конец_процедуры

процедура вторая()
  пусть счёт = 100
  система.лог.вывести(счёт)
конец_процедуры

процедура главная()
  первая()
  вторая()
конец_процедуры
```
Вывод:
```вывод
1
100
```

## Чистая процедура

Слово `чистый` перед `процедура` обещает, что процедура не трогает ничего вне
себя: не пишет в хранилище, не печатает. Такие процедуры проще проверять.

```osnova
чистый процедура с_налогом(сумма: Число): Число
  вернуть сумма + сумма * 6 div 100
конец_процедуры

процедура главная()
  система.лог.вывести(с_налогом(1000))
конец_процедуры
```
Вывод:
```вывод
1060
```
