# 14. Справочник по ключевым словам

Здесь собрано всё, что зарезервировано в языке. Ключевое слово нельзя
использовать как имя переменной.

## Ключевые слова

| Слово | Что делает | Пример |
|---|---|---|
| `модуль` | объявляет модуль, имя файла | `модуль касса` |
| `процедура` | объявляет процедуру | `процедура главная()` |
| `экспорт` | открывает процедуру другим модулям | `экспорт процедура удвоить(n: Число): Число` |
| `чистый` | обещает, что процедура не трогает окружение | `чистый процедура сумма(а, б): Число` |
| `тип` | объявляет запись | `тип Точка = { x: Число, y: Число }` |
| `использовать` | подключает другой модуль | `использовать модуль математика из "математика.osnova"` |
| `из` | часть строки импорта | `… из "файл.osnova"` |
| `пусть` | объявляет переменную | `пусть счёт = 0` |
| `вернуть` | возвращает значение и заканчивает процедуру | `вернуть счёт` |
| `если` | начинает условие | `если счёт > 0` |
| `иначе_если` | ещё одна проверка в том же условии | `иначе_если счёт > 10` |
| `иначе` | ветка «во всех остальных случаях» | `иначе` |
| `тогда` | необязательное слово после условия | `если счёт > 0 тогда` |
| `когда` | разбор значения по вариантам | `когда цвет` |
| `есть` | вариант в `когда` | `есть Цвет.красный` |
| `пока` | цикл с условием | `пока счёт < 10` |
| `для` | перебор коллекции | `для число в числа` |
| `в` | часть строки перебора | `для число в числа` |
| `цикл` | бесконечный цикл | `цикл` |
| `прервать` | выйти из цикла | `прервать` |
| `продолжить` | перейти к следующей итерации | `продолжить` |
| `попробовать` | открывает защищённый кусок | `попробовать` |
| `поймать` | ловит выброшенное значение | `поймать ошибка` |
| `выбросить` | сообщает об ошибке | `выбросить "нет данных"` |
| `истина` | логическое «да» | `пусть флаг = истина` |
| `ложь` | логическое «нет» | `пусть флаг = ложь` |
| `пусто` | отсутствие значения | `вернуть пусто` |
| `и` | логическое «и» | `если а > 0 и б > 0` |
| `или` | логическое «или» | `если а > 0 или б > 0` |
| `не` | логическое «не» | `если не готов` |
| `div` | целочисленное деление | `10 div 3` |
| `конец` | старое закрывающее слово | `… конец` |

## Закрывающие слова

Закрывающее слово называет блок, который заканчивает. Так видно, что именно
закрыто, и компилятор ловит перепутанное закрытие.

| Слово | Закрывает |
|---|---|
| `конец_модуля` | `модуль` |
| `конец_процедуры` | `процедура` |
| `конец_если` | `если` / `иначе_если` / `иначе` |
| `конец_пока` | `пока` |
| `конец_для` | `для` |
| `конец_цикла` | `цикл` |
| `конец_когда` | `когда` |
| `конец_попробовать` | `попробовать` |
| `конец_для_каждого` | `для` (полное написание) |
| `конец` | любой блок — устаревшее написание |

Старое `конец` компилятор принимает до сих пор, но в новом коде пишут
`конец_имя_блока`. Примеры в этом учебнике — на новом написании.

## Операторы

| Оператор | Смысл |
|---|---|
| `=` | присваивание; в условии — сравнение |
| `==` | равно |
| `!=` | не равно |
| `<`, `<=`, `>`, `>=` | сравнения |
| `+` | сложение; со строкой — склейка |
| `-` | вычитание; `0 - 5` — минус перед числом |
| `*` | умножение |
| `/` | вещественное деление |
| `div` | целочисленное деление |
| `%` | остаток |
| `+=`, `-=`, `*=`, `/=` | изменить значение на месте |

## Типы

Тип указывают после имени через двоеточие. Имена типов — соглашение, а не
зарезервированные слова.

```text
пусть количество: Число = 12
пусть подпись: Строка = "яблок"
пусть готово: Логический = ложь
пусть дни: [Строка] = ["пн", "вт"]
пусть ответ: ?Число = пусто
тип Точка = { x: Число, y: Число }
```

- `[Тип]` — массив;
- `?Тип` — значение может быть `пусто`;
- `{ поле: Тип, … }` — запись, её объявляют словом `тип`.

Тип можно не писать: значения в Основе знают, кто они.

## Литералы

| Запись | Что это |
|---|---|
| `42`, `3.5` | числа; дробная часть — через точку |
| `"текст"` | строка; экранирование: `\"`, `\\`, `\n`, `\t` |
| `истина`, `ложь` | логические |
| `пусто` | отсутствие значения |
| `[1, 2, 3]` | массив |
| `{ имя: "Аня", возраст: 30 }` | объект |
| `/* … */`, `//` | комментарии |

## Английские и старые написания

Компилятор понимает варианты слов. Пользоваться лучше каноном из таблиц выше.

| Вариант | Канон |
|---|---|
| `module`, `function`, `fn`, `type` | `модуль`, `процедура`, `тип` |
| `let`, `const`, `var` | `пусть` |
| `if`, `else`, `elif`, `elseif`, `else if`, `then` | `если`, `иначе`, `иначе_если`, `тогда` |
| `while`, `for`, `in`, `break`, `continue` | `пока`, `для`, `в`, `прервать`, `продолжить` |
| `return`, `export`, `end` | `вернуть`, `экспорт`, `конец` |
| `true`, `false`, `null` | `истина`, `ложь`, `пусто` |
| `and`, `or`, `not` | `и`, `или`, `не` |
| `when`, `is`, `catch` | `когда`, `есть`, `поймать` |
| `для_каждого`, `for` | `для` |
| `иначе_попытка`, `catch` | `поймать` |
| `цел_деление` | `div` |
| `:=` | `=` |
