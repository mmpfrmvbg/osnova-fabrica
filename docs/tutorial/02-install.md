# 2. Установка и первая программа

## Что понадобится

Node.js версии 20 или новее. Проверить:

```text
node --version
```

## Установка

Скопируй репозиторий и поставь зависимости:

```bash
git clone <адрес-репозитория> osnova
cd osnova
npm install
```

## Первая программа

Создай файл `привет.osnova`:

```osnova
модуль привет

процедура главная()
  система.лог.вывести("Привет, Основа!")
конец_процедуры

конец_модуля
```
Вывод:
```вывод
Привет, Основа!
```

Запусти её одной командой:

```bash
npx tsx src/cli/index.ts run привет.osnova
```

На экране:

```вывод
Привет, Основа!
```

## Что произошло

Компилятор прочитал модуль `привет`, нашёл в нём процедуру `главная` и перевёл
её в инструкции. Виртуальная машина выполнила эти инструкции: вызов
`система.лог.вывести` печатает строку. Компиляция и запуск идут одной командой,
промежуточный файл не нужен.

Главная процедура вызывается сама. Объявлять её особо не нужно — достаточно
имени `главная`.

## Если нужен байткод

Иногда программа нужна отдельно от исходника — например, чтобы запустить её на
другой машине. Тогда две команды:

```bash
npx tsx src/cli/index.ts compile привет.osnova
npx tsx src/cli/index.ts run привет.osvbc.json
```

Первая переводит исходник в байткод (`привет.osvbc.json`), вторая — исполняет
его. Тот же байткод читают планировщик и регистровая машина, о них — раздел 13.

## Программа с вычислением

Строку можно собрать из частей. `система.строка.объединить` склеивает значения,
`система.строка.из_числа` переводит число в текст:

```osnova
модуль счёт

процедура главная()
  пусть яблоки = 3
  пусть груши = 4
  пусть всего = яблоки + груши
  система.лог.вывести(система.строка.объединить("Всего фруктов: ", всего))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
Всего фруктов: 7
```

Если запутался, где ошибка, компилятор скажет номер строки и что он ждал:

```text
[парсер] строка 4: Ожидается ')' , получено: конец_процедуры
```
