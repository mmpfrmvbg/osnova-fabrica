# 7. Массивы

Массив — это список значений по порядку. Литерал массива пишется в квадратных
скобках:

<!-- legacy-form -->
```osnova
модуль список

процедура главная()
  пусть числа = [10, 20, 30]
  система.лог.вывести(числа[0])
  система.лог.вывести(числа[2])
конец_процедуры

конец_модуля
```
Вывод:
```вывод
10
30
```

Первый элемент имеет номер `0`. У массива из трёх элементов номера: `0`, `1`, `2`.

## Длина

<!-- legacy-form -->
```osnova
модуль длина

процедура главная()
  пусть буквы = ["а", "б", "в"]
  система.лог.вывести(система.массив.длина(буквы))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
3
```

Длина пустого массива — `0`:

<!-- legacy-form -->
```osnova
модуль пустой

процедура главная()
  пусть пусто_тут = []
  система.лог.вывести(система.массив.длина(пусто_тут))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
0
```

## Изменить элемент

Элемент меняют по номеру:

<!-- legacy-form -->
```osnova
модуль замена

процедура главная()
  пусть оценки = [3, 4, 5]
  оценки[1] = 4
  оценки[2] = 5
  система.лог.вывести(оценки[0])
  система.лог.вывести(оценки[1])
  система.лог.вывести(оценки[2])
конец_процедуры

конец_модуля
```
Вывод:
```вывод
3
4
5
```

## Добавить и получить

`система.массив.добавить` кладёт значение в конец, `система.массив.получить` —
читает по номеру:

<!-- legacy-form -->
```osnova
модуль добавление

процедура главная()
  пусть покупки = []
  система.массив.добавить(покупки, "хлеб")
  система.массив.добавить(покупки, "молоко")
  система.массив.добавить(покупки, "сыр")
  система.лог.вывести(система.массив.длина(покупки))
  система.лог.вывести(система.массив.получить(покупки, 1))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
3
молоко
```

## Кусок массива

`система.массив.срез(массив, откуда, докуда)` берёт элементы с номера `откуда` и
до `докуда`, не включая `докуда`:

<!-- legacy-form -->
```osnova
модуль срез

процедура главная()
  пусть дни = ["пн", "вт", "ср", "чт", "пт"]
  пусть середина = система.массив.срез(дни, 1, 4)
  система.лог.вывести(система.массив.длина(середина))
  для день в середина
    система.лог.вывести(день)
  конец_для
конец_процедуры

конец_модуля
```
Вывод:
```вывод
3
вт
ср
чт
```

## Удалить

`система.массив.удалить(массив, номер)` убирает элемент, и следующие сдвигаются
влево:

<!-- legacy-form -->
```osnova
модуль удаление

процедура главная()
  пусть очередь = ["Аня", "Борис", "Вера"]
  система.массив.удалить(очередь, 1)
  система.лог.вывести(система.массив.длина(очередь))
  система.лог.вывести(очередь[1])
конец_процедуры

конец_модуля
```
Вывод:
```вывод
2
Вера
```

## Перебор

Массив перебирают словом `для`:

<!-- legacy-form -->
```osnova
модуль перебор

процедура главная()
  пусть температуры = [12, 15, 9]
  пусть самая_низкая = 100
  для температура в температуры
    если температура < самая_низкая
      самая_низкая = температура
    конец_если
  конец_для
  система.лог.вывести(самая_низкая)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
9
```

## Список записей

В массиве могут лежать объекты. Так выглядит таблица:

<!-- legacy-form -->
```osnova
модуль сотрудники

тип Сотрудник = { имя: Строка, оклад: Число }

процедура главная()
  пусть люди: [Сотрудник] = [
    { имя: "Аня", оклад: 100 },
    { имя: "Борис", оклад: 200 }
  ]
  пусть фонд = 0
  для человек в люди
    фонд = фонд + человек.оклад
  конец_для
  система.лог.вывести(фонд)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
300
```
