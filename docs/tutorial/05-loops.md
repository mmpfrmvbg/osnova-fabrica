# 5. Циклы

## Пока условие верно

`пока` повторяет тело, пока условие истинно. Закрывается `конец_пока`:

<!-- legacy-form -->
```osnova
модуль счёт_до_трёх

процедура главная()
  пусть счётчик = 1
  пока счётчик <= 3
    система.лог.вывести(счётчик)
    счётчик = счётчик + 1
  конец_пока
конец_процедуры

конец_модуля
```
Вывод:
```вывод
1
2
3
```

Счётчик объявляется до цикла — внутри тела `пусть` сработает только один раз, а
на второй итерации компилятор скажет, что переменная уже объявлена.

## Обход массива

`для` проходит по всем элементам. Закрывается `конец_для`:

<!-- legacy-form -->
```osnova
модуль обход

процедура главная()
  пусть числа = [3, 1, 4]
  для число в числа
    система.лог.вывести(число)
  конец_для
конец_процедуры

конец_модуля
```
Вывод:
```вывод
3
1
4
```

Внутри цикла переменная `число` — это очередной элемент. Менять её можно, но на
следующей итерации она получит новое значение из массива.

## Накопление

Обычная задача — посчитать сумму:

<!-- legacy-form -->
```osnova
модуль сумма

процедура главная()
  пусть числа = [10, 20, 30, 40]
  пусть сумма = 0
  для число в числа
    сумма = сумма + число
  конец_для
  система.лог.вывести(сумма)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
100
```

## Обход объекта

Объект перебирается по ключам. Ключи даёт `система.объект.ключи`, значение по
ключу — `система.объект.получить`:

<!-- legacy-form -->
```osnova
модуль склад

процедура главная()
  пусть товары = { яблоки: 5, груши: 3, сливы: 2 }
  пусть всего = 0
  для название в система.объект.ключи(товары)
    пусть количество = система.объект.получить(товары, название)
    система.лог.вывести(название)
    всего = всего + количество
  конец_для
  система.лог.вывести(всего)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
яблоки
груши
сливы
10
```

## Бесконечный цикл, `прервать` и `продолжить`

`цикл` повторяется, пока его не остановят. `прервать` выходит из цикла,
`продолжить` переходит к следующей итерации. Закрывается `конец_цикла`:

<!-- legacy-form -->
```osnova
модуль счёт

процедура главная()
  пусть число = 0
  цикл
    число = число + 1
    если число == 2
      продолжить
    конец_если
    если число > 4
      прервать
    конец_если
    система.лог.вывести(число)
  конец_цикла
конец_процедуры

конец_модуля
```
Вывод:
```вывод
1
3
4
```

Двойка пропущена — её отсекло `продолжить`. На пятой итерации сработал `прервать`,
и цикл закончился.

## Цикл внутри цикла

<!-- legacy-form -->
```osnova
модуль таблица

процедура главная()
  для строка в [1, 2, 3]
    пусть линия = ""
    для столбец в [1, 2]
      линия = система.строка.объединить(линия, строка * столбец)
      линия = система.строка.объединить(линия, " ")
    конец_для
    система.лог.вывести(линия)
  конец_для
конец_процедуры

конец_модуля
```
Вывод:
```вывод
1 2 
2 4 
3 6 
```

Пробел в конце строки остаётся: пример печатает то, что получилось, без
украшений. Если он мешает, добавляй разделитель между элементами, а не после
последнего.
