# 4. Условия

Условие начинается словом `если` и заканчивается `конец_если`:

<!-- legacy-form -->
```osnova
модуль условие

процедура главная()
  пусть возраст = 20
  если возраст >= 18
    система.лог.вывести("Доступ разрешён")
  конец_если
конец_процедуры

конец_модуля
```
Вывод:
```вывод
Доступ разрешён
```

Тело условия сдвинуто вправо. Отступы нужны для чтения — компилятор смотрит на
слова `если` и `конец_если`.

## Иначе

<!-- legacy-form -->
```osnova
модуль выбор

процедура главная()
  пусть возраст = 15
  если возраст >= 18
    система.лог.вывести("Взрослый")
  иначе
    система.лог.вывести("Ребёнок")
  конец_если
конец_процедуры

конец_модуля
```
Вывод:
```вывод
Ребёнок
```

Несколько проверок подряд — `иначе_если`:

<!-- legacy-form -->
```osnova
модуль оценки

процедура главная()
  пусть балл = 72
  если балл >= 90
    система.лог.вывести("отлично")
  иначе_если балл >= 70
    система.лог.вывести("хорошо")
  иначе_если балл >= 50
    система.лог.вывести("удовлетворительно")
  иначе
    система.лог.вывести("не сдано")
  конец_если
конец_процедуры

конец_модуля
```
Вывод:
```вывод
хорошо
```

## Сравнения

| Оператор | Значение |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `<` | меньше |
| `<=` | меньше или равно |
| `>` | больше |
| `>=` | больше или равно |

В позиции условия одиночное `=` тоже читается как сравнение. `если балл = 72`
означает то же, что `если балл == 72`. Вне условий `=` — присваивание.

<!-- legacy-form -->
```osnova
модуль равно

процедура главная()
  пусть код = 7
  если код = 7
    система.лог.вывести("семь")
  конец_если
конец_процедуры

конец_модуля
```
Вывод:
```вывод
семь
```

## Логика

Условия соединяются словами `и`, `или`, `не`:

<!-- legacy-form -->
```osnova
модуль логика

процедура главная()
  пусть возраст = 25
  пусть стаж = 3
  если возраст >= 18 и стаж >= 2
    система.лог.вывести("подходит")
  конец_если
  если не (стаж > 5)
    система.лог.вывести("стажа мало")
  конец_если
  если возраст > 60 или стаж > 20
    система.лог.вывести("на пенсию")
  иначе
    система.лог.вывести("работаем")
  конец_если
конец_процедуры

конец_модуля
```
Вывод:
```вывод
подходит
стажа мало
работаем
```

## Условие внутри условия

<!-- legacy-form -->
```osnova
модуль вложенные

процедура главная()
  пусть температура = 5
  пусть дождь = истина
  если температура < 10
    если дождь
      система.лог.вывести("куртка и зонт")
    иначе
      система.лог.вывести("куртка")
    конец_если
  иначе
    система.лог.вывести("легко")
  конец_если
конец_процедуры

конец_модуля
```
Вывод:
```вывод
куртка и зонт
```

## Значение из условия

`вернуть` внутри условия завершает процедуру:

<!-- legacy-form -->
```osnova
модуль допуск

процедура допуск(возраст: Число): Строка
  если возраст < 18
    вернуть "нет"
  конец_если
  вернуть "да"
конец_процедуры

процедура главная()
  система.лог.вывести(допуск(20))
  система.лог.вывести(допуск(12))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
да
нет
```
