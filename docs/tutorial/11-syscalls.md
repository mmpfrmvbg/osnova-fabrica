# 11. Системные вызовы

Всё, что программе даёт окружение, приходит через системные вызовы. Имя вызова
состоит из частей: `система`, группа и действие.

```text
система.лог.вывести("текст")
система.строка.длина("текст")
система.математика.абс(0 - 5)
```

Вызов — обычное выражение: результат можно присвоить, сложить, передать в
процедуру.

## Вывод

`система.лог.вывести` печатает одно значение и переводит строку. Аргумент ровно
один: чтобы напечатать несколько частей, склей их знаком `+`.

<!-- legacy-form -->
```osnova
модуль вывод

процедура главная()
  пусть имя = "Аня"
  пусть возраст = 30
  система.лог.вывести(имя)
  система.лог.вывести(имя + ": " + возраст)
  система.лог.вывести(система.строка.объединить(имя, "!"))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
Аня
Аня: 30
Аня!
```

## Строки

| Вызов | Что делает |
|---|---|
| `система.строка.объединить(а, б)` | склеивает два значения в строку |
| `система.строка.длина(с)` | число символов |
| `система.строка.подстрока(с, начало, конец)` | кусок с `начало` до `конец`, не включая `конец` |
| `система.строка.содержит(с, часть)` | есть ли часть внутри |
| `система.строка.начинается_с(с, часть)` | начинается ли с части |
| `система.строка.заканчивается_на(с, часть)` | заканчивается ли на часть |
| `система.строка.найти(с, часть)` | номер первого вхождения или `-1` |
| `система.строка.заменить(с, что, на_что)` | заменяет все вхождения |
| `система.строка.разделить(с, разделитель)` | массив кусков |
| `система.строка.в_верхний(с)` / `в_нижний(с)` | меняет регистр |
| `система.строка.обрезать(с)` | убирает пробелы по краям |
| `система.строка.из_числа(ч)` | число как текст |

<!-- legacy-form -->
```osnova
модуль строки

процедура главная()
  пусть фраза = "Основа — язык"
  система.лог.вывести(система.строка.длина(фраза))
  система.лог.вывести(система.строка.подстрока(фраза, 0, 6))
  система.лог.вывести(система.строка.найти(фраза, "язык"))
  система.лог.вывести(система.строка.в_верхний("основа"))
  система.лог.вывести(система.строка.заменить(фраза, "—", "это"))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
13
Основа
9
ОСНОВА
Основа это язык
```

Разделить строку и перебрать куски:

<!-- legacy-form -->
```osnova
модуль разбор

процедура главная()
  пусть части = система.строка.разделить("хлеб,молоко,сыр", ",")
  система.лог.вывести(система.массив.длина(части))
  для часть в части
    система.лог.вывести(часть)
  конец_для
конец_процедуры

конец_модуля
```
Вывод:
```вывод
3
хлеб
молоко
сыр
```

## Математика

| Вызов | Что делает |
|---|---|
| `система.математика.абс(ч)` | модуль числа |
| `система.математика.макс(а, б)` / `мин(а, б)` | большее / меньшее |
| `система.математика.округлить(ч)` | ближайшее целое |
| `система.математика.пол(ч)` / `потолок(ч)` | вниз / вверх |
| `система.математика.степень(а, б)` | `а` в степени `б` |
| `система.математика.корень(ч)` | квадратный корень |
| `система.математика.остаток(а, б)` | остаток от деления |

<!-- legacy-form -->
```osnova
модуль математика

процедура главная()
  система.лог.вывести(система.математика.абс(0 - 5))
  система.лог.вывести(система.математика.макс(3, 9))
  система.лог.вывести(система.математика.мин(3, 9))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
5
9
3
```

## Проверки

Сравнения дают `истина` или `ложь`. Так проверяют строку:

<!-- legacy-form -->
```osnova
модуль проверки

процедура главная()
  пусть адрес = "почта@пример.рф"
  система.лог.вывести("собака: " + система.строка.содержит(адрес, "@"))
  система.лог.вывести("домен: " + система.строка.заканчивается_на(адрес, ".рф"))
  система.лог.вывести("имя: " + система.строка.начинается_с(адрес, "почта"))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
собака: истина
домен: истина
имя: истина
```

Логическое значение печатается словом — и само по себе, и в склейке:

<!-- legacy-form -->
```osnova
модуль флаг

процедура главная()
  система.лог.вывести(10 > 3)
  система.лог.вывести(1 > 3)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
истина
ложь
```

## Массивы и объекты

Это те же вызовы, что в разделах 7 и 8: `система.массив.длина`, `получить`,
`добавить`, `установить`, `удалить`, `срез`; `система.объект.получить`,
`установить`, `ключи`.

## JSON

`система.json.создать` переводит значение в текст JSON, `система.json.разобрать`
— обратно:

<!-- legacy-form -->
```osnova
модуль json

процедура главная()
  пусть текст = система.json.создать([1, 2, 3])
  система.лог.вывести(текст)
  пусть обратно = система.json.разобрать("{\"имя\": \"Аня\"}")
  система.лог.вывести(система.объект.получить(обратно, "имя"))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
[1,2,3]
Аня
```

## Хранилище

Хранилище хранит значения по ключам и живёт, пока работает программа:

<!-- legacy-form -->
```osnova
модуль память

процедура главная()
  система.хранилище.записать("визиты", 3)
  пусть визиты = система.хранилище.прочитать("визиты")
  система.лог.вывести(система.строка.объединить("визитов: ", визиты))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
визитов: 3
```

## Время

`система.время.сейчас` возвращает текущее время в миллисекундах. Печатать его
целиком в примере смысла нет — число каждый раз новое, поэтому сравним его с
нулём:

<!-- legacy-form -->
```osnova
модуль время

процедура главная()
  пусть сейчас = система.время.сейчас()
  система.лог.вывести("время идёт: " + (сейчас > 0))
конец_процедуры

конец_модуля
```
Вывод:
```вывод
время идёт: истина
```

## Чего пока нет

Файлы, сеть и окна описаны в реестре языка, но в виртуальной машине не
реализованы. Вызов такого имени ничего не печатает и возвращает `пусто`:

```text
система.файлы.прочитать_все("файл.txt")
система.сеть.запрос("https://пример.рф", "GET", "", "")
система.окно.создать_окно("Заголовок", 400, 300)
```

Дальше — целочисленное деление.
