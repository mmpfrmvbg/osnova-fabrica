# 9. Обработка ошибок

Иногда программе нужно самой сообщить о проблеме: данных нет, значение не то,
порядок нарушен. Для этого есть `выбросить`, а ловит его `поймать`.

```osnova
модуль ошибка

процедура главная()
  попробовать
    выбросить "что-то сломалось"
  поймать ошибка
    система.лог.вывести(система.строка.объединить("поймали: ", ошибка))
  конец_попробовать
конец_процедуры

конец_модуля
```
Вывод:
```вывод
поймали: что-то сломалось
```

Что здесь происходит:

- `попробовать` открывает защищённый кусок;
- `выбросить` прерывает его и передаёт управление в `поймать`;
- `поймать ошибка` получает выброшенное значение в переменную `ошибка`;
- `конец_попробовать` закрывает всю конструкцию.

После `поймать` программа работает дальше. Можно вернуть запасное значение:

```osnova
модуль запасной

процедура безопасно(а: Число, б: Число): Число
  если б == 0
    выбросить "делить на ноль нельзя"
  конец_если
  вернуть а div б
конец_процедуры

процедура главная()
  попробовать
    система.лог.вывести(безопасно(9, 3))
  поймать ошибка
    система.лог.вывести(система.строка.объединить("ошибка: ", ошибка))
  конец_попробовать
  попробовать
    система.лог.вывести(безопасно(9, 0))
  поймать ошибка
    система.лог.вывести(система.строка.объединить("ошибка: ", ошибка))
  конец_попробовать
конец_процедуры

конец_модуля
```
Вывод:
```вывод
3
ошибка: делить на ноль нельзя
```

## Бросить в одной процедуре, поймать в другой

`выбросить` работает через границу процедур:

```osnova
модуль проверка_возраста

процедура проверить(возраст: Число)
  если возраст < 0
    выбросить "возраст не может быть отрицательным"
  конец_если
  система.лог.вывести("возраст принят")
конец_процедуры

процедура главная()
  попробовать
    проверить(25)
    проверить(0 - 3)
  поймать ошибка
    система.лог.вывести(система.строка.объединить("отказ: ", ошибка))
  конец_попробовать
конец_процедуры

конец_модуля
```
Вывод:
```вывод
возраст принят
отказ: возраст не может быть отрицательным
```

## Чего `попробовать` не ловит

Ошибки самой машины — не то же самое, что `выбросить`. Деление на ноль
останавливает программу, и `поймать` его не перехватывает. Этот пример специально
падает: так выглядит ошибка исполнения.

```osnova
/* ожидается ошибка: Integer division by zero */
модуль деление_на_ноль

процедура главная()
  попробовать
    система.лог.вывести(10 div 0)
  поймать ошибка
    система.лог.вывести("сюда управление не придёт")
  конец_попробовать
конец_процедуры

конец_модуля
```

Правильный вывод из этого: проверяй делитель сам, до деления. Так и сделано в
примере с процедурой `безопасно` выше.

## Без `поймать`

Если `выбросить` никто не ловит, программа останавливается — печатает сообщение и
завершается с ненулевым кодом.

```osnova
/* ожидается ошибка: останов */
модуль падение

процедура главная()
  система.лог.вывести("до")
  выбросить "останов"
  система.лог.вывести("после")
конец_процедуры

конец_модуля
```

На экран попадёт `до`, а дальше — сообщение о необработанном исключении.

## Итог

- `выбросить` — сообщить о проблеме.
- `попробовать` / `поймать` — перехватить её и продолжить работу.
- Проверки до опасной операции надёжнее, чем надежда на перехват.

Дальше — модули.
