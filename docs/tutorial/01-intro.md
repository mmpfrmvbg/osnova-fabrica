# 1. Введение

Основа — язык, в котором ключевые слова русские: `если`, `пока`, `процедура`,
`вернуть`. Читается как обычный текст, а компилируется в байткод.

Программа на Основе состоит из модулей. В модуле живут процедуры. Одна из них —
`главная` — точка входа: с неё начинается запуск.

Вот программа, которая считает сдачу:

```osnova
модуль сдача

процедура главная()
  пусть цена = 250
  пусть оплата = 500
  пусть сдача = оплата - цена
  система.лог.вывести(сдача)
конец_процедуры

конец_модуля
```
Вывод:
```вывод
250
```

## Как читать учебник

Разделы идут по порядку: каждый следующий опирается на предыдущий. Примеры можно
копировать и запускать. Если пример печатает что-то на экран, вывод показан
сразу под ним — сравни со своим.

Код в примерах закрывается словом, которое называет блок: `конец_процедуры`
закрывает процедуру, `конец_модуля` — модуль, `конец_если` — условие. Так видно,
что именно заканчивается, и компилятор ловит перепутанное закрытие.

## Что уже работает

- Числа, строки, логические значения, массивы, объекты.
- Условия, циклы, процедуры, модули, обработка ошибок.
- Системные вызовы: вывод, строки, математика, массивы, объекты, JSON.
- Компиляция в байткод и исполнение на виртуальной машине.

## Что пока не работает

Основа — pre-alpha. Часть системных вызовов описана, но не реализована: файлы,
сеть, окна. Компилятор в e2k-код есть, но не весь язык в него переводится. Если
пример из учебника не запускается — это ошибка учебника, а не твоя.
