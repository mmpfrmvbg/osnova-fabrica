# 8. Объекты и записи

Объект хранит значения по именам полей. Литерал объекта — в фигурных скобках:

```osnova
процедура главная()
  пусть человек = { имя: "Аня", возраст: 30 }
  система.лог.вывести(человек.имя)
  система.лог.вывести(человек.возраст)
конец_процедуры
```
Вывод:
```вывод
Аня
30
```

Поле читается через точку: `человек.имя`. Так же и записывается:

```osnova
процедура главная()
  пусть счёт = { баланс: 100 }
  счёт.баланс = счёт.баланс + 50
  система.лог.вывести(счёт.баланс)
конец_процедуры
```
Вывод:
```вывод
150
```

## Имя поля приходит извне

Иногда имя поля известно только во время работы. Тогда нужны
`система.объект.получить` и `система.объект.установить`:

```osnova
процедура главная()
  пусть анкета = { имя: "Аня" }
  система.объект.установить(анкета, "город", "Минск")
  пусть поле = "город"
  система.лог.вывести(система.объект.получить(анкета, поле))
конец_процедуры
```
Вывод:
```вывод
Минск
```

Список полей даёт `система.объект.ключи`:

```osnova
процедура главная()
  пусть настройки = { тема: "тёмная", язык: "русский" }
  пусть имена = система.объект.ключи(настройки)
  для имя в имена
    система.лог.вывести(имя)
  конец_для
конец_процедуры
```
Вывод:
```вывод
тема
язык
```

## Записи

Если объект всегда одной формы, её описывают словом `тип`. Такой тип называют
записью:

```osnova
тип Точка = { x: Число, y: Число }

процедура главная()
  пусть начало: Точка = { x: 0, y: 0 }
  пусть финиш: Точка = { x: 3, y: 4 }
  пусть dx = финиш.x - начало.x
  пусть dy = финиш.y - начало.y
  система.лог.вывести(dx)
  система.лог.вывести(dy)
конец_процедуры
```
Вывод:
```вывод
3
4
```

Поля записи можно передавать в процедуру:

```osnova
тип Точка = { x: Число, y: Число }

чистый процедура манхэттен(а: Точка, б: Точка): Число
  вернуть система.математика.абс(а.x - б.x) + система.математика.абс(а.y - б.y)
конец_процедуры

процедура главная()
  пусть а: Точка = { x: 1, y: 2 }
  пусть б: Точка = { x: 4, y: 6 }
  система.лог.вывести(манхэттен(а, б))
конец_процедуры
```
Вывод:
```вывод
7
```

## Объект внутри объекта

Поле может быть объектом или массивом:

```osnova
процедура главная()
  пусть заказ = {
    номер: 17,
    покупатель: { имя: "Аня", город: "Минск" },
    позиции: ["хлеб", "сыр"]
  }
  система.лог.вывести(заказ.покупатель.имя)
  система.лог.вывести(заказ.позиции[1])
  система.лог.вывести(система.массив.длина(заказ.позиции))
конец_процедуры
```
Вывод:
```вывод
Аня
сыр
2
```

## Объект как словарь

Объект годится и как таблица «ключ → значение». Ключи — имена полей:

```osnova
процедура главная()
  пусть цены = { хлеб: 40, молоко: 60 }
  пусть корзина = ["хлеб", "молоко", "хлеб"]
  пусть итог = 0
  для товар в корзина
    итог = итог + система.объект.получить(цены, товар)
  конец_для
  система.лог.вывести(итог)
конец_процедуры
```
Вывод:
```вывод
140
```
