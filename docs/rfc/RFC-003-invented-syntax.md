# RFC-003 / Anti-RFC A-7: invented syntax — структура, данные, система.типы

**Тип:** anti-rfc
**Статус:** draft
**Risk:** medium
**Автор:** lang-agent
**Создан:** 2026-03-21

---

## Проблема

LLM изобретает несуществующие конструкции при сложных задачах (TODO-лист,
CRM, объектные модели):

- `структура(...)` — несуществующий конструктор
- `данные имя = значение` — несуществующее объявление
- `система.типы.создать("Тип")` — несуществующий syscall
- `система.хранилище.установить_поле(...)` — несуществующий syscall

Все 3 примера exhausted содержат эти конструкции. Это объясняет
почему exhausted=83, unknown=79: компилятор падает на неизвестном
токене и не может дать осмысленный kind.

## Гипотеза

Явный список INVENTED_SYNTAX в FORBIDDEN_PATTERNS + примеры
"как правильно делать объектную модель через {}" снизят invented_syntax
до <5% без добавления новых конструкций.

## Данные

- repair_exhausted: 83
- unknown kind: 79 (95.2%)
- Паттерн: задачи типа "сделай TODO-лист" → LLM изобретает ООП

## Phase A (план)

- [ ] Добавить в buildOsnovaPrompt FORBIDDEN блок invented_syntax:
      структура(...) → { поле: значение }
      данные имя = → пусть имя =
      система.типы.создать → пусто + объект-литерал
- [ ] 3 few-shot: сложная задача (TODO, CRM) → правильный объектный код
- [ ] Golden-тест: todo_with_objects — только { } литералы
- [ ] Canary: замерить unknown_kind rate до/после

## Критерий закрытия

unknown в repair_exhausted < 30% на 50+ трейсах после Phase A

## Связь с A-2

A-2 (unknown=95%) частично объясняется этим паттерном.
После Phase A A-7 → перемерить A-2.
