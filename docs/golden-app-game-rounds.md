# Golden-приложение: Игровые раунды (Game Rounds)

Приложение категории **game** для golden-теста: агрегация по массиву раундов (результат, очки), условия с логическим **`и`**, сравнения. Без нового рантайм-API.

## Идентификация

- **id:** `osnova.game_rounds`
- **Категория:** `game` (реестр приложений, `registry-v0.1.md`)
- **Манифест:** `src/tools/osnova-runtime/fixtures/game_rounds.osapp.yaml`
- **Модуль:** `game_rounds.osnova` → `game_rounds.osvbc.json`

## Точка входа для golden-теста

- **Процедура:** `run_golden(раунды)`
- **Аргументы:** один массив объектов; каждый объект — поля `результат` (например `"победа"`, `"поражение"`), `очки` (число).

В манифесте заданы `entry.procedure: "run_golden"` и `entry.args`: массив из трёх раундов (победа 15, поражение 5, победа 10).

## Конструкции языка, которые проверяет

- **`для_каждого`** — обход массива событий в `запуск()` и обход массива раундов во всех процедурах.
- **`и`** — составное условие в `бонусные_победы`: «результат == "победа" и очки >= 10».
- **Сравнения** — `==`, `>=`.
- **Работа с объектами** — `система.объект.получить(р, "результат")`, `система.объект.получить(р, "очки")`.
- **Хранилище** — запись результатов через `система.хранилище.записать`.

## Процедуры модуля

| Процедура | Назначение |
|-----------|------------|
| `запуск()` | Окно, цикл по событиям через `для_каждого э в события`. |
| `сумма_очков(раунды)` | Сумма поля `очки` по всем раундам. |
| `количество_побед(раунды)` | Счётчик раундов с `результат == "победа"`. |
| `бонусные_победы(раунды)` | Счётчик раундов с `результат == "победа" и очки >= 10`. |
| `run_golden(раунды)` | Вызывает все три агрегации и записывает результаты в хранилище. |

## Ожидаемые ключи хранилища и значения (golden)

При запуске с тестовыми данными манифеста (3 раунда: победа 15, поражение 5, победа 10) после `run_golden(раунды)` в хранилище приложения `osnova.game_rounds` должны быть:

| Ключ | Ожидаемое значение | Пояснение |
|------|--------------------|-----------|
| `total_points` | `"30"` | 15 + 5 + 10 |
| `wins` | `"2"` | два раунда с результатом «победа» |
| `bonus_wins` | `"2"` | обе победы с очками >= 10 (15 и 10) |

Проверка выполняется в `goldenApps.ts` функцией `runGameRoundsApp()`.

## Зависимости API

- `система.окно`: создать_окно, показать, закрыть, получить_события
- `система.интерфейс`: текст
- `система.хранилище`: записать
- `система.массив`: длина, получить
- `система.объект`: получить
- `система.строка`: объединить
- `система.время`: спать

## Запуск

**Golden-тест:** `npm run osnova-golden:apps` (вызывается `runGameRoundsApp()`).

**Вручную:**
```bash
npx tsx src/tools/osnova-runtime/cli.ts run \
  --manifest src/tools/osnova-runtime/fixtures/game_rounds.osapp.yaml \
  --ui cli
```

## Использование в LLM-пайплайне

Пример категории **game**: логика раундов, подсчёт очков и побед по массиву объектов. Можно использовать как few-shot для спек «игровая статистика», «подсчёт побед/бонусов».
