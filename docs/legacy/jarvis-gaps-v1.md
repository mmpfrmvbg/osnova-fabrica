# Gaps языка v1 для Jarvis / todo-service

Обнаружены при компиляции `apps/osnova-todo/todo-service.osnova`  
Дата: 2026-03-22  
Реестр языка: v1.6.0  

---

## Блокирующие (нужны для полноценного todo-сервиса)

### GAP-001: Пользовательские типы с полями (тип / поле)

**Нужно:**
```
тип Задача
  поле ид текст
  поле заголовок текст
  поле статус текст
конец
```
**Ошибка компилятора:** `Ожидается '{' после имени типа, получено: идентификатор (поле)`  
**Примечание:** ключевое слово `тип` есть в реестре с `since: "1.6.0"`, но парсер не поддерживает синтаксис `поле`.  
**Статус:** запланировано в v1.1  
**RFC:** нужен RFC-004 «Пользовательские типы»

---

### GAP-002: Типизированные параметры процедур

**Нужно:**
```
процедура создать(заголовок текст, проект текст) текст
```
**Ошибка компилятора:** `Ожидается ')', получено: идентификатор (текст)` — парсер не
разбирает аннотации типов в параметрах.  
**Обходной путь (v1):** параметры без типов — `процедура создать(заголовок, проект)`  
**Статус:** запланировано в v1.1  
**RFC:** нужен RFC-005 «Типизация параметров»

---

### GAP-003: Тип список и методы коллекций

**Нужно:**
```
пусть задачи = список[]
задачи.добавить(задача)
пусть н = задачи.длина
```
**Проблема:** `список[]` не является синтаксисом реестра; методы `.добавить()`, `.длина`,
`.взять()` не существуют — вместо них syscalls `система.массив.*`.  
**Обходной путь (v1):** `система.массив.создать()` + `система.массив.добавить(arr, el)`  
**Статус:** запланировано в v1.2  
**RFC:** нужен RFC-006 «Коллекции и методы»

---

## Некритические (обходятся в v1)

### GAP-004: система.хранилище.ключи(префикс)

**Нужно:** `система.хранилище.ключи("задача:")` — фильтрация по префиксу  
**Текущий API:** `система.хранилище.ключи()` — argc=0, без фильтра  
**Обходной путь:** получить все ключи → фильтровать через `система.строка.начинается_с`  
**Статус:** улучшение stable API, v1.1

---

### GAP-005: система.утилиты.уид()

**Нужно:** `система.утилиты.уид()` — генерация уникального идентификатора  
**Текущий API:** нет в реестре  
**Обходной путь:** `система.время.сейчас()` как суррогатный id  
**Статус:** новый syscall, v1.1

---

### GAP-006: Объектные литералы Тип{поле: значение}

**Нужно:**
```
пусть задача = Задача{ ид: "1", заголовок: "тест" }
```
**Проблема:** блокируется GAP-001 (нет пользовательских типов).  
**Обходной путь (v1):** хранить данные как строку с разделителем `|`  
**Статус:** решается вместе с GAP-001 в v1.1
