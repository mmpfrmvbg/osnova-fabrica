# Язык «Основа» — Грамматика v0.1

> **⚠️ Статус:** formal grammar design document. Описывает целевую грамматику языка Основа,
> включая конструкции Phase 2 (`{ }` блоки, `совпадает/случай`, `канал`, `актор`).
> Текущий парсер реализует подмножество: см. `docs/language-v1.md`.

**status: deprecated** — не синхронизирована с реализацией. Конструкции `{ }`, `вызвать`, `функция` отсутствуют в MVP. Актуальная спецификация: `language-v1.md`.

Минимальное ядро языка. Достаточно для генерации кода фабрикой и первых экспериментов с компилятором.

## Типы и структуры

```основа
тип Задача {
    идентификатор:  Целое32;
    приоритет:      Целое8;
    активна:        Логический;
    контекст:       ссылка КонтекстПроцессора;
}

тип Вектор3 {
    х: Вещественное32;
    у: Вещественное32;
    з: Вещественное32;
}
```

### Встроенные типы

| Тип | Аналог |
|---|---|
| `Целое8/16/32/64` | i8/i16/i32/i64 |
| `Вещественное32/64` | f32/f64 |
| `Логический` | bool |
| `Строка` | str |
| `Байт` | u8 |
| `Ничто` | void |
| `?Тип` | Option\<T\> |
| `ссылка Тип` | &mut T |

## Процедуры и функции

```основа
// процедура — меняет состояние, нет возврата
процедура сбросить(з: ссылка Задача) {
    з.активна = ложь;
    з.приоритет = 0;
}

// функция — чистая, всегда возвращает значение
функция максимум(а: Целое32, б: Целое32): Целое32 {
    если а > б { вернуть а; }
    вернуть б;
}
```

## Управление потоком

```основа
// ветвление
если здоровье <= 0 {
    вызвать смерть();
} иначе_если здоровье < 30 {
    вызвать тревога();
} иначе {
    вызвать обновить();
}

// цикл пока (вызов процедуры в операторе — только с маркером "вызвать")
пока задача.активна {
    вызвать обработать(задача);
}

// цикл для
для каждого юнит в юниты {
    юнит.обновить(дельта);
}

// совпадение (pattern matching)
совпадает загрузить("файл.кфг") {
    когда Успех(данные) { применить(данные); }
    когда Неудача(ошибка) { вывести(ошибка.текст); }
}
```

## VLIW-специфичные конструкции

```основа
// явный параллельный блок — подсказка компилятору
параллельно {
    юнит.позиция = юнит.позиция + юнит.скорость * дельта;
    юнит.анимация.обновить(дельта);
    юнит.эффекты.обновить(дельта);
}

// предикативное ветвление вместо if/else
предвыбор {
    когда юнит.здоровье < 30:  юнит.режим = Бежать;
    когда юнит.в_атаке:        юнит.режим = Атаковать;
    когда иначе:               юнит.режим = Патруль;
}

// явный пакет команд — ручное управление слотами
пакет {
    слот0: юнит.здоровье -= 10;
    слот1: юнит.выносливость -= 5;
    слот2: звук_удар().проиграть();
}

// разворачивание цикла
цикл (по юнит в юниты) разворачивать 4 {
    обновить_юнита(юнит);
}

// регион — гарантия регистровой локальности
регион вычисление {
    пусть а = позиция.х * скорость.х;
    пусть б = позиция.у * скорость.у;
    пусть результат = а + б;
}

// небезопасный блок — интринсики и прямое железо
небезопасно {
    вернуть vliw_смешать(вектор_а, вектор_б);
}
```

## Реализованный синтаксис MVP (текущий компилятор)

Текущий компилятор (`src/tools/osnova-compiler`) поддерживает подмножество языка с **разделителем операторов по новой строке** (без `;` и без `{}`). Блоки ограничиваются ключевым словом **`конец`**.

### Модуль и процедуры

```основа
модуль имя_модуля

процедура имя(параметр1, параметр2)
  оператор_1
  оператор_2
конец
```

### Операторы

| Конструкция | Синтаксис |
|------------|-----------|
| Локальная переменная | `пусть имя = выражение` |
| Присваивание | `имя = выражение` |
| Ветвление | `если выражение` … `иначе` … `конец` |
| Цикл по условию | `пока выражение` … `конец` |
| Цикл по коллекции | `для_каждого переменная в выражение` … `конец` |
| Бесконечный цикл | `цикл` … `конец` |
| Возврат | `вернуть выражение` или `вернуть` |
| Вызов (оператор) | `имя(аргументы)` или `система.модуль.метод(аргументы)` |

### Выражения

- Литералы: числа, строки в кавычках, `истина`, `ложь`, `пусто`.
- Переменные и вызовы: `имя`, `имя(аргументы)`, `система.массив.длина(массив)`.
- Сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`.
- Арифметика: `+`, `-`, `*`, `/`, `%`.
- **Логические операторы (с short-circuit):**
  - **`не выражение`** — отрицание (на вершине стека остаётся булево).
  - **`выражение и выражение`** — если левый операнд ложь, правый не вычисляется.
  - **`выражение или выражение`** — если левый операнд истина, правый не вычисляется.
- Приоритет: `или` (низший) &lt; `и` &lt; `не` &lt; сравнения &lt; сложение/вычитание &lt; умножение/деление &lt; унарный минус.

### Пример

```основа
модуль t
процедура main(arr)
  пусть sum = 0
  для_каждого x в arr
    sum = sum + x
  конец
  вернуть sum
конец
```

## Полный список ключевых слов

В v0.1 объявление типа данных — только через **`тип`**. Ключевое слово **`структура`** не используется (зарезервировано на будущее; лексер и парсер его не обрабатывают).

**Реализовано в MVP-компиляторе:**

```
модуль    процедура   пусть   если    иначе   пока   для_каждого   в   цикл   конец   вернуть
истина    ложь        пусто   и       или     не
```

**Планируется / в спеке грамматики:**

```
использовать    тип         функция
иначе_если      для         каждого
совпадает       когда       параллельно
предвыбор       пакет       слот
разворачивать   регион      небезопасно   актор
задача          канал       ожидать       ссылка
Успех           Неудача     Результат     вызвать
открытый        закрытый    по
```

**Вызов в контексте оператора:** в целевом языке вызов как оператор допускается с префиксом `вызвать`. В **реализованном MVP** вызов задаётся просто как `имя(аргументы)` с новой строки.

**Логические операторы:** в MVP реализованы **`и`**, **`или`**, **`не`** с short-circuit семантикой (см. раздел «Реализованный синтаксис MVP» выше).

## Философия языка

- **Пишется как структурированный русский текст** — читается без знания синтаксиса
- **Последовательный по умолчанию** — параллелизм только там где явно указан
- **Честный с компилятором** — `параллельно`, `предвыбор`, `регион`, `разворачивать` это разговор с планировщиком, не магия
- **Строгий в горячем коде** — никаких скрытых зависимостей, никакого неявного захвата контекста
- **Расслабленный в прикладном коде** — чем дальше от железа, тем больше сахара
