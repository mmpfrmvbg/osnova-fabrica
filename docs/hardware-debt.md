# Реестр долга перед железом

**Дата:** 2026-09-15
**Зачем:** одно место, где перечислено всё, что **нельзя проверить без реального
Эльбруса**. Каждый факт — с датой и формулировкой. Правило проекта: непроверенное
не выдаётся за проверенное.

**Состояние доступа (ответ владельца, 2026-09-15): НИ ЖЕЛЕЗА, НИ СИМУЛЯТОРА.**
**Уточнение 2026-09-15 (вечер): исходники официального QEMU-порта e2k получены** (МЦСТ,
`qemu-e2k.tar.gz`, QEMU 11.0.1 — `docs/e2k-sources-raw.md`), **но не собраны**: в окружении нет
POSIX-оболочки и C-инструментов (`docs/e2k-qemu-build.md` §2). Доступа к симулятору по-прежнему
нет; изменилось другое — **кодировка e2k больше не «НЕТ В ДОКУМЕНТЕ»** (§3.7).
Значит всё, что ниже, закрывается **не в этом проекте и не сейчас**. Прямое
следствие для плана: критерии приёмки Фаз 3–4 должны быть переформулированы в
терминах **внешнего** эталона (опубликованные примеры кодировки, независимый
дизассемблер, опубликованные результаты) — иначе они доказывают только
самосогласованность. Это записано в `docs/vliw-phases-plan.md`, чтобы не выяснилось
через полгода.

**Критический путь — не железо, а ISA-справочник** (уточнено владельцем 2026-09-15,
раздел 3.6). **Уточнение 2026-09-15 (вечер):** часть этого пути пройдена **без письма в МЦСТ** —
кодировка извлечена из открытых источников (§3.7). Железо нужно для тактов; справочник нужен
для того, чтобы всё построенное перестало быть моделью. Даже без покупки Эльбруса он снимает
долг 3.6 целиком и большую часть 3.1/3.2.

## 3.2. Кластеры АЛУ

| | |
|---|---|
| **долг** | **величина штрафа** за передачу между кластерами АЛУ неизвестна |
| **откуда факт** | руководство МЦСТ, стр. 194: каналы 0,1,2 — один кластер, 3,4,5 — другой; «байпас не может работать между кластерами, работая в каждом отдельно» |
| **чем заменено** | в модели задержек штраф **не добавлен вообще**. В коде это сказано прямо: `src/vliw/e2kDevices.ts:120` — «Наша модель задержек этого не учитывает (нет величины штрафа), и пока не учитывает, пересечения нужно хотя бы считать». То есть эффективно штраф = 0, но **отдельной константы с таким именем в коде нет** — есть функция `crossClusterEdges`, которая считает пересечения, и предпочтение кластера как baseline-переключатель |
| **что сломает долг** | если штраф не нулевой, часть расписаний невыполнима за посчитанное время; измеренный ранее вывод «кластеры на корпусе не дают ничего» (идентичные расписания при `respectClusters: false` и `true`) остаётся верным **для этой модели**, но не для железа |
| **как закрыть** | замер на железе: время зависимой пары с байпасом внутри кластера против пары через границу кластеров |
| **дата записи** | 2026-09-15 |

## 3.6. Слой замены покрывает только кодировку

Записано по прямому указанию владельца 2026-09-15: **это два долга, а не один.**

| | |
|---|---|
| **долг 1** | swap-слой (`docs/e2k-backend.md`) заменяет **кодировку**, но **не модель устройства** |
| **что не покрыто заменой** | `src/vliw/e2kDevices.ts` и `docs/vliw-e2k-model.md` остаются допущением: длительности по классам операций (глава 6, стр. 71–72), состав кластеров АЛУ (стр. 194), штраф за передачу между кластерами (принят нулевым — см. 3.2), классы передачи операндов (таблица 12.2, стр. 199–200, извлечена с допущением о порядке столбцов) |
| **следствие** | когда появится реальный e2k, менять придётся **два** слоя: кодировку И модель устройства. Замена `src/e2k/e2k.ts` второй слой не закрывает |
| **долг 2** | **сам интерфейс `Encoder` не проверен на соответствие e2k** |
| **что в нём предположено** | форма обмена (ассемблерная форма, стр. 19 — документ говорит «большинство операций»), размер инструкции, набор полей и соответствие «список операндов ↔ поля» (наше соглашение) |
| **чем это грозит** | если у реального e2k другая форма обмена или другой набор полей, менять придётся не только `shell.ts`, но и `backend.ts`, а за ним — эмиттер. Утверждение «замена — один файл» верно **только** для замены на другую реализацию **того же** интерфейса |
| **что проверяет тест и чего не проверяет** | `src/scripts/e2kBackend.audit.test.ts` проверяет замену реализации и правило изоляции. Соответствие интерфейса e2k он **не проверяет** и не может: сравнивать не с чем |
| **общий источник риска** | оба долга опираются на **один и тот же** документ — руководство МЦСТ (выпуск 1.2, 28.02.2024). Это **не два независимых риска**, а один источник риска, размноженный на два слоя: ошибка чтения или пробел в документе бьёт по кодировке и по модели устройства **одновременно**, и закрытие одного долга второй не уменьшает |
| **критический путь** | **ISA-справочник, а не железо.** Справочник превращает модель в реальность даже без доступа к Эльбрусу: он закрывает долг 2 целиком (интерфейс переписывается по нему) и большую часть долга 1 — длительности, кластеры, классы передач становятся фактами со страницами. Железо остаётся нужным для того, что не закрывает и справочник: реальных тактов |
| **как закрыть** | получить ISA-справочник (письмо в МЦСТ) либо опубликованное описание кодировки; затем — железо для 3.1–3.3 и 3.5 |
| **дата записи** | 2026-09-15 |

### Действие с наибольшей отдачей: письмо в МЦСТ

Записано по указанию владельца 2026-09-15: это **самый дешёвый шаг с самым большим
потенциалом**, и он **не конкурирует** с эмиттером — оба идут параллельно.

| свойство | почему так |
|---|---|
| **не блокирует эмиттер** | эмиттер идёт **на оболочке** (`docs/e2k-emitter-plan.md`): кодировка e2k ему не нужна, конвейер строится в любом случае |
| **не требует железа** | нужен документ, а не машина |
| **может закрыть долг 2 целиком** | кодировка перестаёт быть «НЕТ В ДОКУМЕНТЕ»: интерфейс `Encoder` сверяется со справочником, а не с нашими предположениями |
| **закрывает большую часть долга 1** | длительности, кластеры и классы передач становятся фактами со страницами, а не чтением одного документа |
| **дёшево** | один вечер |

**Что именно просить:** описание формата команд (бинарной кодировки) и справочные таблицы
главы 12 (`relative_latency`, классы передачи операндов) — либо ссылку на открытую публикацию
с ними. Если такой публикации нет, это **тоже ответ**: он снимает ожидание «вот-вот
появится» и переводит планирование в режим «оболочка — единственная опора, и её границы
известны».

**Чего в этом пункте нет:** адресатов, каналов и текста письма — это действие владельца, а не
проектной части; здесь зафиксированы предмет запроса и цена шага.

## 3.7. Кодировка e2k извлечена — долг 2 закрыт ЧАСТИЧНО

**Дата записи:** 2026-09-15 (вечер). **Что изменилось:** кодировка e2k перестала быть
«НЕТ В ДОКУМЕНТЕ» — она извлечена из **открытых** источников, без письма в МЦСТ и без железа.

| | |
|---|---|
| **что извлечено** | таблица опкодов МЦСТ (`opcodes/e2k-opc.h`, 4 271 запись, 3 096 имён), битовая раскладка слогов (HS/ALS/ALES), длина команды |
| **откуда** | четыре независимых описания: binutils-gdb (MCST-патч), LLVM-порт (`e2k-dev`), QEMU-порт МЦСТ 11.0.1, реверс `elbrus-docs` — `docs/e2k-sources-raw.md` |
| **что реализовано** | `src/e2k/e2k-real.ts`: 23 операции в трёх формах (ALF1, ALF2, ALES/ALOPF11), короткая форма 8 байт и длинная 16 байт; `getEncoder("e2k")` |
| **что проверено** | round-trip на 132 образцах; сквозной прогон пяти ядер: 268 из 517 инструкций понижены и закодированы, расхождений 0 — `docs/e2k-real-run.md` |
| **чего это НЕ доказывает** | что байты примет MCST-objdump или QEMU: **ни то, ни другое не собрано** — компилятора C в окружении нет (`docs/e2k-qemu-build.md` §2). Совпадение четырёх **описаний** — свидетельство, а не замер |
| **что осталось долгом** | приёмка кодировки независимым инструментом; формы, не реализованные (LTS-литералы, CS/SS-управление, AAS-адресация, предикаты, MAS) |

### Долг 2 «интерфейс `Encoder` не проверен на соответствие e2k»: что выяснилось

Извлечение **позволило** впервые приложить интерфейс к реальной кодировке — и это дало
конкретные находки, а не общее «надо проверить»:

| находка | следствие |
|---|---|
| **`instructionSize` — одно число, а команды e2k кратны 8 и занимают 8 или 16 байт** | шлюз `auditEncoder` рассчитан на одну длину: он покрывает короткую форму и **не покрывает длинную**. Это названо в паспорте `REAL_E2K_DESCRIPTION.limitation` и проверено отдельным оракулом |
| мнемоники оболочки (`ADDs/d`) и таблицы МЦСТ (`adds`) — **разные пространства имён** | ключ `e2k` отдан реальной кодировке, заглушка сохранена под ключом `e2k-stub`; реальный бэкенд обязан отвергать мнемоники оболочки, иначе потребитель не отличил бы одно от другого |
| у интерфейса **нет способа выразить предикат** (результат `cmp*`), литерал (LTS), передачу управления (CS/SS), MAS/AAU | понижение пяти ядер останавливается на 249 из 517 инструкций (`docs/e2k-real-run.md` §2) — **это и есть цена пробела интерфейса, измеренная** |
| поле канала `0..23` руководства ↔ индекс слога ALS `0..5` | в кодировке слогов ALS шесть (`allowed_channels[6]` в таблице МЦСТ); `e2k-real` принимает 0..5 и отвергает 6..23 с названной причиной |

**Вывод:** долг 2 закрыт **частично** — интерфейс приложен к реальной кодировке и выдержал её на
подмножестве из 23 операций, но **не выражает** четыре класса операций, и один его параметр
(размер) оказался неверным для переменной длины. Утверждение «замена — один файл» этим
**опровергнуто**: пришлось менять `backend.ts` (реестр), `backend.test.ts` (оракул) и добавлять
два модуля.

## 3.8. QEMU-прогон не заменяет железо

**Дата записи:** 2026-09-15 (вечер). **Состояние: прогона не было.**

| | |
|---|---|
| **долг** | QEMU — **модель**, а не e2k; и он **не собран** |
| **почему не собран** | нет POSIX-оболочки и C-инструментов; `configure` — shell-скрипт — `docs/e2k-qemu-build.md` §2 |
| **почему нечего запускать** | конвейер проекта выдаёт поток команд (`osnova-shell-image`), а не ELF; нужен `e_machine = 175` (`EM_E2K`), компоновщик, стартовый код и libc — `docs/e2k-qemu-run.md` §2 |
| **что нельзя делать, если QEMU однажды соберётся** | называть такты QEMU тактами e2k: QEMU считает **инструкции и переходы**, а не время железа. Числа QEMU — такая же модель, как наши, только чужая. Сравнивать их с нашими можно **как две модели**, нельзя — как замер |
| **что QEMU всё же даёт** | приёмку **кодировки**: если MCST-дизассемблер прочитает наши байты как ту же инструкцию — это внешняя проверка, которой сейчас нет |
| **как закрыть** | собрать QEMU на Linux-хосте, собрать кросс-binutils, написать ELF-обёртку и стартовый код — `docs/e2k-qemu-run.md` §4 |
| **дата записи** | 2026-09-15 |

### 3.9.2. Свой MCST-objdump: внешняя проверка ПОЛУЧЕНА

| | |
|---|---|
| **что сделано** | в WSL (дистрибутив `e2k`, WSL1, Alpine 3.24.1, **без прав администратора**) собран binutils МЦСТ с `--target=e2k-linux`; получен `objdump` `GNU Binutils 2.41.0-29.023` |

### 3.10.3. Минимальный ELF: собран, разобран и **ДЕЛАЕТ `exit(42)`**

| | |
|---|---|
| **что сделано** | `src/e2k/elfMinimal.ts`: ELF64 (`ELFCLASS64`, `ELFDATA2LSB`, `e_machine = 175`, машина `8c` в `e_flags`), один `PT_LOAD` `R|X`, `.text` 40 байт, точка входа `_start` |
| **что проверено** | `objdump -f` → `elf64-e2k`, `elbrus-8c:64`, `start address 0x100000`; `objdump -d` разбирает все три инструкции; `readelf -S` — 5 секций; `objdump -t` — символ `_start` (`docs/e2k-minimal-elf.md` §3) |
| **прогон БЕЗ шима** | **не состоялся**: ошибка `guest_base`. Контроли: на файле не-ELF `qemu-e2k` отвечает `Exec format error` (значит файл читается), на прежнем `e2k-samples.elf` — та же ошибка; `qemu-x86_64` в том же окружении отвечает кодом 0 |
| **прогон С шимом** | **состоялся**: шим через `LD_PRELOAD` возвращает `MAP_FIXED_NOREPLACE` смысл, которого QEMU ждёт (адрес — подсказка, затем сверка; ничего не затирается), и эмулятор **исполняет** наши байты: обе `movts` проходят, остановка на `ct %ctpr1` (`0x100020`) — `docs/e2k-minimal-elf.md` §4.1, `docs/e2k-qemu-run.md` §2.8 |
| **что это дало нового** | **исполнение** — проверка сильнее дизассемблера: опыт с передачей управления (`disp` CS0 + `ct` SS) перебрасывает управление по вычисленному адресу — смещение 3 → остановка в ловушке `0x100018`, смещение 2 → `0x100010`. Положительный и отрицательный контроль: адрес следует за смещением, а не совпадает случайно (`src/e2k/e2kQemuExec.test.ts`) |
| **почему остановка на `ct`** | `%ctpr` на входе нуль (`cpu-sregs.h:149`), ноль — тег `CTPEW`, `ct` по такому ctpr — исключение (`translate-ct.c:840-844`) |
| **чем шим НЕ является** | не правкой эмулятора e2k: трансляция и семантика инструкций не тронуты, меняется только способ узнать у хоста, свободен ли диапазон. Отличие одно — проверка перестаёт быть **атомарной** (при загрузке linux-user однопоточен, диапазон резерва остаётся замапленным) |
| **отдельно измерено** | при отказе загрузки `qemu-e2k` завершается **кодом 0** — судить о прогоне по коду возврата нельзя |
| **точная причина отказа без шима (уточнена)** | WSL1 не поддерживает `MAP_FIXED_NOREPLACE` — флаг, на котором стоит поиск гостевого резерва (`linux-user/elfload.c:792`): зонд на C в том же дистрибутиве даёт `errno=95` (ENOTSUP), тогда как `MAP_FIXED` и обычный `mmap` адрес выдают. Флаг добавлен в Linux 4.17, WSL1 — слой трансляции, а не ядро (`docs/e2k-qemu-run.md` §2.5) |
| **что это значит для выбора окружения** | годится **любое окружение с настоящим ядром Linux ≥ 4.17** (WSL2, VM, отдельная машина) — и оно **не обязательно**: тот же результат получен шимом на месте. Отдельная установка Linux не нужна. WSL2 на этой машине, к слову, **не поднимается**: `wsl --import --version 2` → `Wsl/Service/RegisterDistro/CreateVm/HCS/ERROR_INVALID_DATA`, хозяин — Windows 11 Insider **Dev 22543** |
| **`exit(42)`** | **ВЫПОЛНЯЕТСЯ**: программа из пяти инструкций (setbn, два `movts` в оконные `%r8`/`%r9`, `sdisp`, `call`) даёт код возврата **42** (`docs/e2k-minimal-elf.md` §7). Достигнуто тремя правками кодировщика (`sdisp`, файл регистров в `Operand`, `setbn`) и двумя послаблениями хоста (шим `mmap`, правка полей `WD._d` в порте QEMU — `docs/e2k-qemu-run.md` §2.9) |
| **чего это не доказывает** | что так поведёт себя **железо** (QEMU — модель) и что правки хоста не нужны на настоящем ядре: там `WD._d` заполняет ядро, а `MAP_FIXED_NOREPLACE` есть с Linux 4.17 |
| **что это значит для 3.8** | QEMU по-прежнему **модель**, а не железо; исполнение получено **в модели** и на минимальном ELF, а не на пяти ядрах. Отказ без шима — свойство **хоста** (WSL1), а не эмулятора |
