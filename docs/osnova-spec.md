# Основа: исполняемая спецификация синтаксиса (проект)

**Дата:** 2026-10-01
**Статус:** проект, не канон. Канон языка v2 — `docs/language-v2.md` и код `src/compiler/**`.
**Оракул:** `src/spec/specification.test.ts` — 49 проб прогоняются в общем `npm test`.

Этот документ описывает **предлагаемый** синтаксис языка Основа: тот, который
получился после разбора канона v2 по двум вопросам — «так говорит русский?» и
«это одна форма или две?». Ничего в компиляторе не менялось: спецификация живёт
рядом, отдельным исполняемым контуром.

## Зачем это лежит в дереве, а не в переписке

Спецификация без оракула умирает молча. В этом проекте так уже случилось:
`docs/token-cost-report.md` замерил, что естественная русская форма
(`для каждого`) **вдвое дешевле** склеенной через `_` (`для_каждого`) и прямо
назвал `при ошибке` заменой для `иначе_попытка`, — но в компиляторе живёт
`иначе_попытка`, а `при ошибке` не появилось. Измерение было, решения не было.

Поэтому здесь иначе: **49 проб исполняются оракулом в `npm test`**. Проба — либо
работающая программа с ожидаемым выводом, либо программа, которая обязана быть
отвергнута **с названной причиной**. Расхождение документа и языка краснеет.

## Что зафиксировано

| Правило | Как | Почему так |
|---|---|---|
| Составные слова — через пробел | `для каждого`, `конец пока`, `при ошибке` | `_` дороже вдвое (замер) и читается хуже |
| Булевы значения | `да` / `нет` | `и` — это союз AND; `истина`/`ложь` — существительные в роли значений |
| Логика словами, сравнение знаками | `и`, `или`, `не`; `==`, `!=`, `<`, `<=`, `>`, `>=` | слов-дублей знаков нет: одна форма на понятие |
| Деление | `нацело` и `%` | `%` — только остаток; `//` занято комментарием |
| Закрытие блока | повторяет открывающее слово: `конец если`, `конец пока`, `конец для`, `конец разбор`, `конец защита`, `конец повторять`, `конец цикла` | у процедуры и действия — просто `конец`: тело процедуры не блок внутри блока |
| Точка | «взять часть»: цепочка **полей** любой глубины (`ж.адрес.город`), цепочка **имён** запрещена (`система.массив.длина`) | у модуля нет подмодуля; вызов пишется `имя(…)` или `Модуль.имя(…)` |
| Сбои | `защита` … `при ошибке как причина`, `поднять` | не `попробовать/поймать`: ловят предмет, а не сбой |
| Проверка | `проверить УСЛОВИЕ, "сообщение"` | это **конструкция** со своей грамматикой, а не операция с исключением |
| Аргумент операции | операнд: `длина числа - 1` = `(длина числа) - 1`; у действий — выражение: `вывести "а" + счёт` | у операции и действия разная природа аргумента, и это записано, а не угадано |
| Действие и вычисление | `действие имя(…)` против `процедура имя(…) → Тип` | сегодня они пишутся одинаково, а различие спрятано в том, съел ли компилятор результат |
| Присваивание | только `=` | `:=` — второй знак для одного действия |
| `=` в условии | ошибка с подсказкой | смысл знака не должен зависеть от места |

## Чего в проекте нет

- Английских алиасов (`let`, `if`, `else if`, `for`, `catch`, `end`) — второй язык внутри языка.
- `конец_X` через подчёркивание, `иначе_попытка`, `для_каждого`, `цел_деление`.
- `тогда` — слово, которое можно не писать, не значит ничего.
- `чистый` — пометка, которая никак не проверялась.
- `вернуть(x)`, `вернуть 1, 2` — скобки вокруг значения и скрытое построение массива.
- Цепочек сравнений `a < b < c` (в каноне v2 середина вычисляется дважды — проверено прогоном).
- Цепочек из трёх точек `система.массив.длина`.

## Границы (названы, а не умолчаны)

- `защита` ловит **только** явно поднятое: сбой машины (деление на ноль) проходит насквозь.
- `поднять` вне `защита` — сбой программы с названной причиной, а не отказ компиляции.
- `Может Может Т` и `Может Пусто` — ошибка; `Может` идемпотентно.
- Поиск возвращает `-1`, сравнение с ним записывается как `0 - 1` (отдельного литерала `-1` нет).
- Импорт (`подключить`) **разбирается, но не исполняется**: вызов `Модуль.имя(…)` в этом
  контуре даёт названный отказ. Правило точки проверено синтаксически, не семантически.
- Типы проверяются в местах привязки (аргументы, `пусть` с аннотацией, поля записи,
  тип возврата), а не полным выводом.

## Чего этот документ не делает

Не является каноном и не меняет компилятор. Переход к канону — отдельная работа:
перенос правил в `language-registry`, `src/compiler/**`, `language-schema.json` и
golden-тесты, по `docs/language-contributing-v2.md`. Пока правила живут только
здесь — компилятор описывает язык v2, а не этот проект.

## Как прогнать

```
npx vitest run src/spec/specification.test.ts
```

Оракул держит два утверждения о **самом наборе** — иначе набор можно «починить»
удалением неудобных проб: положительных не меньше двадцати, названных отказов не
меньше пятнадцати.
