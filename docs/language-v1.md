# Язык Основа — LLM-карточка v1.0
> Компактный справочник для генерации кода. Используй ТОЛЬКО конструкции из этого документа.

---

## Структура модуля

```osnova
модуль имя_модуля

процедура имя(параметр1, параметр2)
  // тело
конец
```

- Один файл = один модуль.
- Блоки закрываются словом `конец` (не фигурными скобками).
- Операторы разделяются переводом строки (не `;`).

---

## Операторы

| Конструкция             | Синтаксис                                  |
|-------------------------|--------------------------------------------|
| Переменная             | `пусть имя = выражение`                    |
| Присваивание           | `имя = выражение`                          |
| Составное присваивание | `имя += выражение` / `-=` / `*=` / `/=`    |
| Ветвление              | `если условие … иначе … конец`             |
| Цикл по условию        | `пока условие … конец`                     |
| Цикл по коллекции      | `для_каждого перем в коллекция … конец`    |
| Бесконечный цикл       | `цикл … конец`                             |
| Возврат                | `вернуть выражение` или просто `вернуть`   |
| Вызов системы          | `система.модуль.метод(аргументы)`          |

---

## Выражения

- Литералы: `42`, `3.14`, `"строка"`, `истина`, `ложь`, `пусто`.
- Арифметика: `+`, `-`, `*`, `/`, `%`.
- Сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`.
- Логика (short-circuit):
  - `выражение и выражение` — правый не вычисляется, если левый `ложь`.
  - `выражение или выражение` — правый не вычисляется, если левый `истина`.
  - `не выражение` — логическое отрицание.

Приоритет (от низшего к высшему):

```text
или < и < не < сравнения < +/- < * /// % < унарный минус
```

## Пример: типичная процедура

```osnova
модуль пример

процедура подсчитать(элементы)
  пусть итог = 0
  для_каждого э в элементы
    если э > 0 и э < 100
      итог = итог + э
    конец
  конец
  вернуть итог
конец
```

## Системный API (реализовано в рантайме)

### Хранилище

```osnova
система.хранилище.записать(ключ, значение)   // сохранить строку
система.хранилище.прочитать(ключ)            // → строка или пусто
система.хранилище.удалить(ключ)
система.хранилище.ключи()                    // → массив строк
```

### Файлы

```osnova
система.файлы.прочитать_все(путь)            // → строка
система.файлы.записать_все(путь, данные)
система.файлы.существует(путь)               // → логический
```

### Окно и интерфейс

```osnova
система.окно.создать_окно(заголовок, ширина, высота)  // → окно_id
система.окно.показать(окно_id)
система.окно.закрыть(окно_id)
система.окно.получить_события(окно_id)       // → массив событий (argc=0 в байткоде!)

система.интерфейс.кнопка(родитель_id, текст, id?)     // → виджет_id
система.интерфейс.поле_ввода(родитель_id, подсказка?, id?)
система.интерфейс.текст(родитель_id, содержимое, id?)
система.интерфейс.получить_значение(виджет_id)         // → строка
система.интерфейс.установить_значение(виджет_id, значение)
```

### Массивы и объекты

```osnova
система.массив.длина(массив)                 // → число
система.массив.получить(массив, индекс)      // → элемент
система.объект.получить(объект, ключ)        // → значение
```

### Строки

```osnova
система.строка.объединить(а, б)              // → строка (конкатенация)
```

### Время и лог

```osnova
система.время.сейчас()                       // → число (мс)
система.время.спать(мс)
система.лог.вывести(сообщение)
```

### Сеть (только при `permissions.network.outbound: true`)

```osnova
система.сеть.запрос(url, метод?, заголовки?, тело?)  // → строка
```

## Конвенция стека (для кодогена)

- Бинарные операции: `push a; push b; op` → вычисляет `a ∘ b`.
- `invoke`: аргументы пушатся в порядке объявления (`push arg1; push arg2; invoke "имя"`).
- Число аргументов должно точно совпадать с сигнатурой.

## Паттерн приложения с окном

```osnova
модуль моё_приложение

процедура запуск()
  пусть окно = система.окно.создать_окно("Заголовок", 400, 300)
  система.окно.показать(окно)
  цикл
    пусть события = система.окно.получить_события(окно)
    для_каждого э в события
      // обработка события
    конец
    система.время.спать(16)
  конец
конец
```

## Не используй (не реализовано в компиляторе v0.1)

- ❌ `тип`, `функция`, `актор`, `канал`, `ожидать`
- ❌ `совпадает / когда`
- ❌ `параллельно`, `пакет`, `регион`, `предвыбор`
- ❌ `иначе_если` (используй вложенные `если … иначе`)
- ❌ Типовые аннотации (`: Целое32` и т.п.)
- ❌ Точка с запятой как разделитель
