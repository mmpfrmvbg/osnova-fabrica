# Язык Основа v1

Основа v1 — минимальный язык для создания приложений ОС-НОВА, спроектированный для генерации кодом LLM-агентов и исполнения на VM с байткодом. Текущее состояние: стабильное ядро, активная разработка системных сервисов. Версия `v1.1.0` выпущена, `v1.2.0-alpha` — обработка ошибок, `v1.3.0-alpha` — для_каждого, `v1.4.0-alpha` — вызов процедур.

---

## Структура модуля

- **Объявление модуля:** `модуль имя`
- **Объявление процедур:** `процедура имя(параметр1, параметр2)` … `конец`
- **Главная процедура:** точка входа — процедура `главная()` / `главная(аргументы)` или `запуск()`
- **CLI-аргументы:** в варианте `главная(аргументы)` параметр `аргументы` получает массив строк (`process.argv.slice(2)`).
- ⚠️ Не использовать `конец` как имя параметра — это зарезервированное ключевое слово.
  Пример неверно: `процедура сумма(начало, конец)` — `конец` зарезервировано.
  Пример верно:   `процедура сумма(от, до)`

```основа
модуль имя_модуля

процедура главная()
  // тело
конец

конец
```

Завершающий `конец` модуля — опциональный. Оба варианта валидны:

**Вариант А (с конец):**
```основа
модуль главный
процедура главная()
  система.лог.вывести("привет")
конец
конец
```

**Вариант Б (без конец):**
```основа
модуль главный
процедура главная()
  система.лог.вывести("привет")
конец
```

- Один файл = один модуль.
- Блоки закрываются словом `конец` (не фигурными скобками).
- Операторы разделяются переводом строки (не `;`).

## Типы

Поддерживаемые типы v1 (только то, что реально работает сейчас):

| Тип | Описание |
|-----|----------|
| **Целое32** | Целое число |
| **Строка** | Строковое значение |
| **Логический** | `истина` / `ложь` |
| **массив** | Литерал `[a, b, c]`, доступ через `система.массив.*` и sugar-индексацию `массив[индекс]`. Поддерживаются одно- и многострочные объявления |
| **объект** | Объектный литерал: `{ имя: "Иван", возраст: 30 }`. Доступ: `объект.поле` или `система.объект.получить`. Поддерживаются одно- и многострочные объявления |
| **пусть** | Динамическое объявление переменной (тип выводится из значения; повторное `пусть` трактуется как переприсваивание) |

**Литералы — однострочные и многострочные:**

Оба варианта допустимы:
```основа
пусть числа = [1, 2, 3]         // однострочный — ✓
пусть числа = [                 // многострочный — ✓
  1,
  2,
  3
]
пусть точка = { х: 1, у: 2 }    // однострочный — ✓
пусть точка = {                 // многострочный — ✓
  х: 1,
  у: 2
}
```

## Управляющие конструкции

- **если / иначе / иначе_если** — ветвление. После условия можно опционально писать `тогда`.
- ❌ Неверно: `если x > 0 то` — слово `то` не используется
- ✅ Верно:   `если x > 0` или `если x > 0 тогда`
- **пока** — цикл по условию
- ❌ Неверно: `пока i < 10 то` — слово `то` не используется
- ✅ Верно:   `пока i < 10` или `пока i < 10 тогда`
- **цикл** — бесконечный цикл
- **для_каждого** — итерация по массиву (стабильная с v1.3.0).
- Имена переменных `элемент` и `индекс` — произвольные идентификаторы.
- После выражения массива можно опционально писать `тогда`.
- Вложенные `для_каждого` поддерживаются.

Два допустимых варианта:

```основа
// Форма 1 — только элемент
для_каждого элемент в массив
  система.лог.вывести(элемент)
конец

// Форма 2 — элемент и индекс
для_каждого элемент, индекс в массив
  система.лог.вывести(индекс)
  система.лог.вывести(элемент)
конец
```

### Операторы

| Оператор | Назначение | Пример |
|----------|------------|--------|
| `=` | Присваивание переменной | `сумма = сумма + 1` |
| `==` | Сравнение на равенство | `если х == 0` |
| `!=` | Не равно | `если статус != "активен"` |
| `<` `>` `<=` `>=` | Сравнения | `если баланс > 0` |
| `+` `-` `*` `/` | Арифметика | `пусть итог = а + б` |
| `-(унарный)` | Отрицание числа | `пусть x = -5` |
| `и` | Логическое И | `если а == 1 и б == 2` |
| `или` | Логическое ИЛИ | `если а == 1 или б == 2` |
| `не` | Логическое НЕ | `если не флаг` |

## Операторы

| Конструкция | Синтаксис |
|-------------|-----------|
| Переменная | `пусть имя = выражение` |
| Присваивание | `имя = выражение` |
| Составное присваивание | `имя += выражение` / `-=` / `*=` / `/=` |
| Возврат | `вернуть выражение` или `вернуть` |
| Вызов системы | `система.модуль.метод(аргументы)` |

## Точка входа

- Допустимы оба варианта:
  - `процедура главная()`
  - `процедура главная(аргументы)` — `аргументы` это массив строк CLI.
- Для runtime из CLI в `аргументы` передаётся `process.argv.slice(2)`.
- Для пайплайна и тестов передаётся пустой массив `[]`.

---

## Массивы

- `массив[индекс]` — синтаксический сахар над `система.массив.получить(массив, индекс)`.
- `массив[индекс] = значение` — сахар над `система.массив.установить(массив, индекс, значение)`.

## Выражения

- Литералы: `42`, `3.14`, `"строка"`, `истина`, `ложь`, `пусто`, `[a, b, c]`, `{ ключ: значение }`.
- Арифметика: `+`, `-`, `*`, `/`, `%`.
- Сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`.
- Логика (short-circuit): `и`, `или`, `не`.

## Ограничения v1

Явно перечислено, чего в языке пока **нет**:

- Строковые операции доступны через `система.строка.*` (стабильные: объединить, длина, содержит, разделить, заменить, обрезать, в_верхний, в_нижний и др.)
- Нет обработки ошибок / `попробовать` / `Результат<T,E>`
- Нет дженериков
- Нет пользовательских типов / структур
- Нельзя использовать ключевые слова языка как имена переменных: `если`, `иначе`, `пока`, `цикл`, `для_каждого`, `вернуть`, `пусть`, `истина`, `ложь`, `и`, `или`, `не`, `модуль`, `процедура`, `конец`
- Оператор присваивания — только `=`, не `:=`:
  ```основа
  пусть х = 5       // ✓ верно
  х = х + 1         // ✓ повторное присваивание
  пусть х := 5      // ✗ запрещено
  ```
- Первое использование переменной — обязательно через `пусть`:
  ```основа
  пусть счётчик = 0      // ✓ объявление
  счётчик = счётчик + 1  // ✓ повторное присваивание
  счётчик = 0            // ✗ запрещено без предварительного пусть
  ```
- Один модуль на один spec/файл:
  ```основа
  модуль Калькулятор   // ✓ один модуль
  ...
  конец
  модуль Утилиты       // ✗ запрещено — два модуля в одном файле
  ```
- Ключевое слово `то` — запрещено (не часть синтаксиса `если`/`пока`):
  ```основа
  если х > 0        // ✓ верно
    ...
  конец
  если х > 0 то     // ✗ запрещено — используйте "тогда" или ничего
  ```
- Процедуры высшего порядка (передача процедур как аргументов) — запрещены в v1:
  ```основа
  вызвать(моя_процедура, аргумент)    // ✗ запрещено
  // вместо этого — явная итерация или условия
  ```
- Импорт между модулями (using `использовать/из`) доступен с v1.5.0-alpha; один модуль = один файл.
- Нет функций конвертации типов (`система.строка.из_числа`, явного приведения). Для вывода числа как строки — используй `система.строка.объединить("", число)`, `объединить` принимает любой тип.

## Примеры

### Пример 1 — арифметика и если

```основа
модуль главный

процедура главная()
  пусть х = 10
  если х > 5
    система.лог.вывести("больше пяти")
  иначе
    система.лог.вывести("не больше пяти")
  конец
конец

конец
```

### Пример 2 — цикл пока

```основа
модуль главный

процедура главная()
  пусть сумма = 0
  пусть счётчик = 1
  пока счётчик <= 10
    сумма = сумма + счётчик
    счётчик = счётчик + 1
  конец
  система.лог.вывести(сумма)
конец

конец
```

### Пример 3 — объектный литерал и доступ к полю

```основа
модуль главный

процедура главная()
  пусть человек = { имя: "Иван", возраст: 30 }
  система.лог.вывести(человек.имя)
  человек.возраст = 31
  система.лог.вывести(человек.возраст)
конец
```

### Пример 4 — остаток и составное присваивание

```основа
модуль главный

процедура главная()
  пусть i = 0
  пока i < 6
    если i % 2 == 0
      система.лог.вывести("чётное")
    конец
    i += 1
  конец
  вернуть i
конец

конец
```

## Системный API (реализовано в рантайме)

### Хранилище

```основа
система.хранилище.записать(ключ, значение)   // сохранить строку
система.хранилище.прочитать(ключ)            // → строка или пусто
система.хранилище.удалить(ключ)
система.хранилище.ключи()                    // → массив строк
```

### Файлы

```основа
система.файлы.прочитать_все(путь)            // → строка
система.файлы.записать_все(путь, данные)
система.файлы.существует(путь)               // → логический
```

### Окно и интерфейс

```основа
система.окно.создать_окно(заголовок, ширина, высота)  // → окно_id
система.окно.показать(окно_id)
система.окно.закрыть(окно_id)
система.окно.получить_события()              // → массив событий

система.интерфейс.кнопка(родитель_id, текст, id?)     // → виджет_id
система.интерфейс.поле_ввода(родитель_id, подсказка?, id?)
система.интерфейс.текст(родитель_id, содержимое, id?)
система.интерфейс.получить_значение(виджет_id)         // → строка
система.интерфейс.установить_значение(виджет_id, значение)
```

### Массивы и объекты

```основа
система.массив.длина(массив)                 // → число
система.массив.получить(массив, индекс)      // → элемент
система.объект.получить(объект, ключ)        // → значение (альтернатива объект.поле)
```

### Строки

```основа
система.строка.объединить(а, б)              // → строка (конкатенация)
система.строка.длина(строка)                // → Целое32
система.строка.содержит(строка, подстр)     // → Логический
система.строка.начинается_с(строка, преф)  // → Логический
система.строка.заканчивается_на(стр, суф)  // → Логический
система.строка.подстрока(стр, нач, кон)    // → строка [нач, кон)
система.строка.в_верхний(строка)           // → строка (UPPERCASE)
система.строка.в_нижний(строка)            // → строка (lowercase)
система.строка.обрезать(строка)            // → строка (trim)
система.строка.заменить(стр, что, на)      // → строка
система.строка.разделить(стр, разд)         // → массив
```

### Время и лог

```основа
система.время.сейчас()                       // → число (мс)
система.время.спать(мс)
система.лог.вывести(сообщение)
```

### Сеть (только при `permissions.network.outbound: true`)

```основа
система.сеть.запрос(url, метод?, заголовки?, тело?)  // → строка
```

## Конвенция стека (для кодогена)

- Бинарные операции: `push a; push b; op` → вычисляет `a ∘ b`.
- `invoke`: аргументы пушатся в порядке объявления (`push arg1; push arg2; invoke "имя"`).
- Число аргументов должно точно совпадать с сигнатурой.
