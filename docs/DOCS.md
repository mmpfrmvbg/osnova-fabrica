# DOCS.md — конвенция документации

> Система, которая не даёт документации расползаться. Источник истины —
> `docs/manifest.yaml`; сторож — `src/scripts/doc-guardian.ts`. Два генерируемых
> артефакта (руками не редактируются): индекс `docs/README.md` и штампы
> `<!-- doc-status: … -->` в шапке каждого дока.

## Как это работает

Три файла-механизма:

| Файл | Роль |
|---|---|
| `docs/manifest.yaml` | Единый реестр: статус каждого дока, ссылки на исходники и указатели |
| `src/scripts/doc-guardian.ts` | Оракул: проверяет полноту реестра, валидность статусов, свежесть и целостность указателей |
| `docs/README.md` | Индекс всех доков, генерируется сторожем (`--fix`) |
| `<!-- doc-status: … -->` | Штамп в шапке каждого дока (статус + source-files), генерируется сторожем |

В индексе протухшие доки (чей `source-files` менялся позже самого дока) помечены ⚠ —
так ИИ видит «отстал ли док от кода», не открывая каждый файл.

## Статусы

| Статус | Смысл | Требования |
|---|---|---|
| `active` | Фронтир, живёт сейчас | — |
| `stable` | Канон, не меняется | — |
| `frozen` | Пауза, вернёмся | рекомендуется `rework-plan` |
| `superseded` | Заменено навсегда | обязателен `superseded-by` |
| `deprecated` | Мёртво, к удалению | — |
| `scratch` | Разведка/сырьё/план, не канон | — |

## Поля записи

- `status` — обязателен.
- `source-files` — файлы кода, которые документ описывает; сторож ругается, если файла
  нет, и предупреждает, если исходник менялся **позже самого дока** (по mtime).
  Свежесть не хранится в реестре — эталоном служит mtime самого `.md`.
- `superseded-by` / `rework-plan` — путь к документу-преемнику/плану; сторож
  проверяет, что он существует.

## Как добавить документ

1. Создай `.md` в `docs/`.
2. Занеси его в `docs/manifest.yaml` со статусом.
3. `npm run docs:check` — должен стать зелёным.
4. `npm run docs:index` — перегенерировать `docs/README.md` и штампы `doc-status` в доках.

Док, не занесённый в реестр, — ошибка (`docs:check` падает). Это намеренно:
так ничего не теряется без следа.

## Как вывести / заменить документ

- Заморозить → `status: frozen` + `rework-plan`.
- Заменить → `status: superseded` + `superseded-by`.
- В архив → перенести в `docs/legacy/` (автоматически `deprecated`).

## Команды

```bash
npm run docs:check   # проверка (CI)
npm run docs:index   # перегенерировать индекс docs/README.md
```
