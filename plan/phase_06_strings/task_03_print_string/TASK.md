# TASK-06-03 — Печать строки и `вывести`

**Статус:** частично сделано; остаток зависит от TASK-06-01 (алиасы) и TASK-06-02 (рантаймовая длина).

## Что уже есть

- `stringWriteInstructions({ address, byteLength })` — `src/e2k/stringRuntime.ts`; подключена в
  `src/e2k/programImage.ts` и `src/e2k/twoPassLayout.ts`;
- `система.лог.вывести(строка)` понижается для **статических** строк (длина известна на сборке);
- **железо:** кит `tools/e2k-hardware/expected.tsv` — `04-строки` → вывод `Привет, мир\n11\n`;
  `49-склейка-арена` → `01234567890123456789яя\n21\n` — в прогоне **38/38**.

## Что остаётся

- алиас `Строка.печать` для v3 (см. ATOM-06-01б);
- печать строки с **рантаймовой** длиной — зависит от ATOM-06-02 (`byteLength` берётся из заголовка
  блока арены);
- интеграция `вывести` на v3 и сверка sha256 на E8C2.

## Найдено при разборе (не тронуто, отдельный проход)

`docs/verification-debt.md`, случай 69, утверждает «печати строк в языке нет». Как **буква** это
неверно: статические строки печатаются и сверены на железе (кит `04`/`49`, 38/38). Верно другое: нет
печати строки с **рантаймовой** длиной. Класс тот же, что у случая 67 (ложная буква в шапке), и его
правка — отдельным проходом, а не внутри среза 6.

## Порядок

Алиас → печать рантайм-строки → модель → железо E8C2 → sha256 → коммит + push.
