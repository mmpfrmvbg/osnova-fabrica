# git-discipline

## Mandatory rule (без исключений)
После каждого `git commit` — немедленно выполнить `git push origin <текущая ветка>`. Без исключений. Не спрашивать подтверждения. Не откладывать "на потом".

## Дополнительные обязательные условия перед любым докладом
Перед любым докладом о выполненной работе:
1. Проверить что `git log --oneline -3` совпадает с тем что видно в remote.
2. Выполнить `git fetch`.
3. Выполнить проверку по remote-ветке:
   - `git status` или
   - `git log origin/main..HEAD` (или эквивалент для текущей ветки).
4. Если есть расхождение локал vs remote — пуш выполнить ДО доклада о результатах.

## Формат подтверждения после каждого commit+push
После каждого успешного `git commit` + `git push` всегда выводить строку:
`Коммит <sha> запушен в remote: <ветка>`.

## Definition of done
Файл сохранён, затем сделан commit и сразу push по правилу выше.
