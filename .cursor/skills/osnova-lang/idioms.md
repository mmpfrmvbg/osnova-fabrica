# Osnova — идиомы из пакетов Dviglo

Эталон: `D:\PROJECTS\Dviglo\games\поймай-квадрат`, `районы`, `колонизация`, `citybussines` — файлы `игра.osnova`. Не выдумывать «красивый» диалект поверх них.

## 1. Каркас пакета: запуск / кадр / сводка

Хост вызывает процедуры пакета (не обязательно `главная`).

```osnova
модуль Игра

тип Мир {
  счет: Число,
  конец: Логический
}

процедура запуск()
  если игра.сейв.есть("мир")
    вернуть игра.сейв.читать("мир")
  конец
  пусть мир: Мир = { счет: 0, конец: ложь }
  вернуть мир
конец

процедура сводка(мир)
  если мир.конец
    вернуть "конец · счёт " + мир.счет
  конец
  вернуть "счёт " + мир.счет
конец

процедура кадр(дт, мир)
  // ввод → логика → отрисовка игра.* → вернуть мир
  вернуть мир
конец

конец
```

- Мир — объект (часто с `тип Мир`); **возвращать** из `запуск`/`кадр`, не глобал.
- `сводка(мир)` — короткая строка для карточки полки; клиент мир не читает.
- `игра.*` — host API из schema (`игра.json` / `колония.json`), не LANGUAGE_REGISTRY.

## 2. Процедуры вместо HOF

Плохо (JS-мышление):

```osnova
// НЕТ: map/filter/колбэк-процедура как значение
пусть результат = фильтровать(список, предикат)
```

Хорошо (citybussines / колонизация): именованные процедуры + явный обход.

```osnova
процедура всего_аи(мир)
  вернуть мир.аи_север + мир.аи_восток + мир.аи_запад + мир.аи_юг
конец

процедура имя_района(н)
  если н == 1
    вернуть "север"
  конец
  если н == 2
    вернуть "восток"
  конец
  вернуть "?"
конец
```

Логику дробить на мелкие `процедура`, вызывать по имени. Рекурсия пользовательских процедур допустима; передача процедуры аргументом — нет.

## 3. Обход вложенного если / пока

Плохо: одна «простыня» из 8 уровней `если`.

Хорошо:

- ранний `вернуть` / ранний выход из ветки;
- вынести ветку в процедуру (`открыть_клетку`, `вес_я_в`);
- для сетки — счётчики `пока ряд < 5` / `пока столбец < 5` (колонизация), не HOF;
- цепочка `иначе_если` только когда ветки взаимоисключающие и короткие.

Пример сетки (идея из колонизации):

```osnova
процедура заполнить_цвета(мир, цвета)
  пусть ряд = 0
  пока ряд < 5
    пусть столбец = 0
    пока столбец < 5
      система.массив.добавить(цвета, цвет_клетки(мир, столбец, ряд))
      столбец = столбец + 1
    конец
    ряд = ряд + 1
  конец
  вернуть цвета
конец
```

Счётчик **не** называть `и` (ключевое слово).

## 4. Ввод и UI (immediate-mode)

Из живых пакетов:

- касание: `пусть т = игра.касание()` → `т.нажато`, `т.x`, `т.y`
- хитбокс: `игра.нажато(x, y, w, h)`
- меню: `пусть н = игра.выбор(x, y, w, ["а", "б"])` — пункты литералом массива
- ход/кнопка: `игра.ход("…")`, `игра.кнопка(…)`
- сейв: `игра.сейв.есть` / `читать` / `писать` с ключом пакета

Литерал массива в аргументе `игра.выбор` — норма; не городить ручной `создать`+`добавить`, если литерал читается.

## 5. Строки и весть

- Склейка `"неделя " + мир.неделя` — ок (`+` со строкой).
- Длинную весть собирать по шагам (`пусть удар = ""` → дописывать), как `удар_по_спросу` в citybussines.
- `система.строка.подстрока` — для «карты» как строки символов (колонизация).

## 6. Плохо → хорошо (три эталона)

### A. HOF → процедура

Плохо:

```osnova
вернуть список.map(x => x * 2)
```

Хорошо:

```osnova
процедура удвоить_все(список)
  пусть i = 0
  пусть н = система.массив.длина(список)
  пока i < н
    список[i] = список[i] * 2
    i = i + 1
  конец
  вернуть список
конец
```

### B. Глубокое если → ранняя процедура

Плохо: вся логика клетки внутри `кадр` на 6 уровней `если`.

Хорошо:

```osnova
процедура известна(мир, столбец, ряд)
  если столбец < 0
    вернуть ложь
  конец
  если столбец > 4
    вернуть ложь
  конец
  // ...
  вернуть истина
конец
```

### C. JS-цикл / bad end → канон

Плохо:

```osnova
for (let i = 0; i < n; i++) { ... }
конец_пока
вернуть(сумма)
```

Хорошо:

```osnova
пусть i = 0
пока i < н
  // ...
  i = i + 1
конец
вернуть сумма
```

## 7. Пакет кормит язык, не копирует хост

Паттерн UI/движка (`игра.кнопка`, спрайт) ≠ новое ключевое слово — это хост.

Дыра языка в живом пакете (флаги вместо вариантов, `тип` не ловит ложь, стек syscall) → патч Фабрики, не лесенка `если` «пока выражается». См. [evolve.md](evolve.md).
