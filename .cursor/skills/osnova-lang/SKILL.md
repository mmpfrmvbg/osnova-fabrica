# osnova-lang

Канон языка Основа для агентов: писать валидный `.osnova` с первого раза; дыра в живом пакете → патч Фабрики, не обход.

Детали: [reference.md](reference.md) · идиомы: [idioms.md](idioms.md) · эволюция: [evolve.md](evolve.md) · цель: [цель.md](цель.md)

## A. Источник истины

| Приоритет | Где |
|-----------|-----|
| 1 (канон) | `src/compiler/language-registry.ts` + compiler + `src/runtime/vm/**` |
| 2 | `docs/language-v2.md` — только то, что подтверждено кодом |
| конфликт | побеждает **код** |

- Host-API игр (`игра.*`, `колония.*`) **не** в `LANGUAGE_REGISTRY` — только `extraSyscalls` / `extraInvokes` схемы хоста (Dviglo).
- Компилятор **не копировать** в Dviglo. Правки языка — только в `OSNOVA-FABRIKA`.
- Не выдумывать синтаксис из JS/Python/Pascal. Не считать «красивый диалект» каноном.

Перед генерацией при сомнении: открой `language-registry.ts` (keywords, constructs, syscalls, `forbiddenPatterns`, `LLM_KEYWORD_ALIASES`).

## B. Как писать `.osnova` (чеклист)

До выдачи кода:

1. **Русский канон** ключевых слов в файле. Алиасы `let`/`if`/`true`/`&&` лексер принимает (`LLM_KEYWORD_ALIASES`) — в итоге в файле канон: `пусть`/`если`/`истина`/`и`.
2. Каркас: `модуль Имя` … `процедура …` … `конец` … `конец`. Все блоки закрываются только `конец` (не `конец_пока` / `конец_процедуры`).
3. `вернуть значение` / `вернуть` — **без скобок** как канон (даже если `вернуть(x)` иногда проходит).
4. Нет HOF, классов, generics, глобалов «как в JS», колбэков-процедур.
5. Ключевые слова не имена (`и`, `в`, `если`, `конец`, …) — ни переменные, ни параметры, ни счётчики.
6. Массивы/объекты: литералы `[…]` / `{…}`, сахар `arr[i]` / `obj.поле`, иначе `система.массив.*` / `система.объект.*` — **сверять argc и эффект на стек** (см. reference: `добавить` не возвращает массив).
7. Повтор: `пусть x = 1` один раз; дальше `x = …`. Сравнение в условии: `==`, не `=`.
8. Перед сдачей: `npx tsx src/cli.ts compile <файл>.osnova` / тесты Фабрики, либо check пакета в Dviglo.
9. Эталон стиля — живые пакеты Dviglo (`games/*/игра.osnova`), не выдуманный диалект.

Мини-каркас (CLI/библиотека):

```osnova
модуль Пример
процедура главная()
  вернуть 0
конец
конец
```

Пакет Dviglo: `запуск` / `кадр` / `сводка` — см. [idioms.md](idioms.md).

## C. Эволюция языка (игра кормит канон)

1. Живой пакет врёт данными, тип не ловит ложь, syscall ест стек, лесенки `если` вместо вариантов → **патч Фабрики**, не обход в пакете.
2. Кнопка / спрайт / жест / физика / сцена → **хост** Dviglo (`extraSyscalls`), не `LANGUAGE_REGISTRY`.
3. Патч: только нужное; **сразу коммит** (правило fabrika-commit в Dviglo); не трогать `.qwen/`, `forge/`, ATM yaml, `Fabrika2.0/`, секреты. Не ждать «да», если дыра уже в пакете.
4. Не тащить: HOF, глобалы, английский второй канон, `система.сеть` в пакеты Dviglo, «ютуб в API», «как в TypeScript» без живой дыры.
5. После патча: registry + тесты compiler; `docs/language-v2.md` — только если факт уже в коде; не плодить расхождение v1/v2.
6. Куда идти: [цель.md](цель.md). Пакет говорит честно; типы отвергают ложь; не «похоже на знакомый язык».

Полная таблица и порядок: [evolve.md](evolve.md).

## D. Песочница (пакеты Dviglo)

- Пакету нельзя: сырая сеть, файлы телефона, контакты, гео, камера, SMS; неизвестный invoke — отказ.
- Сейвы/хранилище — на хосте с **префиксом пакета**.
- `система.сеть` / `система.файлы` в игровом пакете не использовать (даже если есть в реестре Фабрики).
- Мультиплеер/аккаунт/мессенджер — клиент; игра видит только то, что даёт `игра.*` / схема хоста.

## Быстрые запреты

| Плохо | Хорошо |
|-------|--------|
| `конец_пока` | `конец` |
| `вернуть(x)` в каноне | `вернуть x` |
| `система.вывести` | `система.лог.вывести` |
| `пусть x := 1` | `пусть x = 1` |
| `arr.forEach(...)` | `для_каждого эл в arr` … `конец` |
| `фильтр(список, fn)` | отдельная `процедура` + цикл |
| `пусть и = 0` | `пусть индекс = 0` |
| `игра.*` в LANGUAGE_REGISTRY | `extraSyscalls` хоста |

## Definition of done

Код компилируется; стиль совпадает с живыми пакетами; при патче языка — registry + тест + коммит.
