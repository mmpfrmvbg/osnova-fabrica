# debug-osnova-errors

## Что делает
Находит причину ошибки по её тексту и делает минимальный точечный фикс.

## Правило минимального фикса
Исправляй только то, что сломано. Не переписывай файл целиком.

## Таблица диагнозов

| Ошибка компилятора | Причина | Фикс |
|--------------------|---------|------|
| `Ожидается 'модуль'` | Нет шапки файла | Добавь `модуль Имя` в первую строку |
| `Ожидается ')'` | Использована форма `вернуть(...)` | Замени на `вернуть значение` |
| `Неизвестная инструкция: конец_пока` | Запрещённый закрыватель блока | Замени на `конец` |
| `Неизвестная инструкция: конец_процедуры` | Запрещённый закрыватель | Замени на `конец` |
| `Неизвестный идентификатор: система.вывести` | Устаревший системный вызов | Замени на `система.лог.вывести` |
| `Ожидается выражение, получено: процедура` | Сломана структура блока | Найди незакрытый `если`/`пока`/`процедура` |
| `Переменная уже объявлена` | Повторный `пусть` для существующей переменной | Убери `пусть` при переприсваивании |
| `Ожидается идентификатор` | Ключевое слово использовано как имя | Переименуй переменную |

## Алгоритм отладки

1. Прочитай точный текст ошибки и номер строки
2. Найди строку в коде
3. Сопоставь с таблицей диагнозов
4. Сделай минимальный фикс только в этой строке
5. Перекомпилируй: `node src/cli.js compile <файл>.osnova`
6. Повтори до чистой компиляции

## Anti-patterns

- ❌ Переписывать весь модуль из-за одной ошибки
- ❌ Менять логику программы при синтаксических ошибках
- ❌ Добавлять конструкции не из `docs/language-v1.md`
- ❌ Считать задачу решённой без успешной компиляции

## Definition of done
`node src/cli.js compile <файл>.osnova` завершается без ошибок.
