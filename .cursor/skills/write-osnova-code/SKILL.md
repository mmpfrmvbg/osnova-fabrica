# write-osnova-code

## Что делает
Генерирует синтаксически корректный код на языке Основа с первого раза.

## Authoritative sources
Перед генерацией прочитай:
- `docs/language-v1.md` — полная спецификация
- `docs/system-api-v1.md` — системные вызовы

## Обязательная структура любого модуля

```
модуль Имя

процедура главная()
  ...
конец

конец
```

## Запрещённые конструкции (НИКОГДА не использовать)

| Запрещено | Правильно |
|-----------|-----------|
| `конец_пока` | `конец` |
| `конец_процедуры` | `конец` |
| `конец_модуля` | `конец` |
| `вернуть(значение)` | `вернуть значение` |
| `система.вывести` | `система.лог.вывести` |
| `:= значение` | `пусть имя = значение` |
| `тогда` как ключевое слово | не используется |
| `массив[i]` индексация | итерация через цикл |
| Ключевые слова как имена переменных | переименовать |
| Многострочные литералы массива/объекта | одна строка |

## Чеклист перед выдачей кода

- [ ] Файл начинается с `модуль Имя`
- [ ] Есть `процедура главная()`
- [ ] Все блоки закрыты только через `конец`
- [ ] Нет запрещённых конструкций из таблицы выше
- [ ] Системные вызовы есть в `docs/system-api-v1.md`
- [ ] Один модуль = один файл

## Anti-patterns

- ❌ Писать синтаксис по аналогии с Python/JS/Pascal
- ❌ Использовать конструкции не из `docs/language-v1.md`
- ❌ Изобретать системные вызовы без проверки `system-api-v1.md`
- ❌ Выдавать код не прошедший чеклист

## Definition of done
Код проходит компилятор без ошибок. Если есть доступ к терминалу — запусти:
`node src/cli.js compile <файл>.osnova`
Исправь все ошибки до выдачи результата.
